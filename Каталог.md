# Каталог репозитория Sigmawillow

Навигатор по математическим концепциям и проектам.

## Контентные папки

- **Adifa** — исследования степенных башен, системы счисления, величина Adifa.
- **Digit Weights** — теория цифровых весов (БУС/ПУС), гипотеза одинокого бегуна, Радиципланум.
- **Lowbml** — спецификация низкоуровневой модели.
- **equation-systems** — решения систем уравнений.
- **Bepsoray** — проект межзвёздной связи, линк-бюджеты.
- **Задачи Тысячелетия** — P ≠ NP и связанные гипотезы.
- **Матеша** — коллизии величины W, асимметрия перекрёстной разности, эмпирические закономерности.
  - (Теоремы об асимметрии перенесены в 12-Теорема; таблицы и код верификации — в 05-Эмпирика.)
- **Сценарии для кино** — сценарии, промты, концепты визуализации.

Все контентные папки находятся в директории `more/`.

## Статусные папки

Математические утверждения рассортированы по статусам:

- **01-Определение** — соглашения о терминах.
- **02-Обозначение** — соглашения о символах.
- **03-Обнаружено** — замечено в данных, без точной формулировки.
- **04-Сформулировано** — точное утверждение, не проверено.
- **05-Эмпирика** — проверено перебором до границы n.
- **06-Гипотеза** — сформулировано, доказательства нет.
- **07-Частично** — доказано для части случаев.
- **08-Доказано** — есть полное доказательство.
- **09-Опровергнуто** — найден контрпример.
- **10-Открыто** — ни доказано, ни опровергнуто.
- **11-Контрпример** — конкретный опровергающий случай.
- **12-Теорема** — главное доказанное утверждение раздела.
  - Включает: Теоремы об асимметрии перекрёстной разности для n=2, 3, 4 (Асим2, Асим3, Асим4).
- **13-Лемма** — вспомогательное доказанное утверждение.
- **14-Следствие** — вывод из теоремы.
- **Тривиальные** — короткие тривиальные случаи с ID ≤17 символов.

Статусные папки также находятся в директории `more/`.
