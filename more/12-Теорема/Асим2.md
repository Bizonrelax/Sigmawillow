# Теорема о полном числе решений T(K)

## Определение

Двузначные числа:

    A = 10·x + y
    B = 10·u + v

где

    x, u ∈ {1, 2, …, 9}
    y, v ∈ {0, 1, …, 9}

Перекрёстная разность:

    Δ(A, B) = y·u − x·v

Через S(K) обозначим множество всех упорядоченных пар (A, B) двузначных чисел, для которых Δ(A, B) = K.

Через Sₗₜ(K) обозначим подмножество пар с A < B:

Sₗₜ(K) = { (A, B) ∈ S(K) : A < B }

**Определение.** Полное число решений:

T(K) = |Sₗₜ(K)|

То есть T(K) — это число пар (A, B) с A < B и Δ(A, B) = K. Для K = 10 это в точности число строк в таблице.

## Формулировка

**Теорема.** Пусть K — целое.

**1. Точная формула (конечная сумма).**

T(K) = сумма по x от 1 до 9, по y от 0 до 9 от c(x, y, K)

где c(x, y, K) — число u ∈ {1, …, 9}, для которых одновременно выполнены три условия:

    g = НОД(x, y) делит K
    v = (y·u − K) / x есть целое из {0, 1, …, 9}
    10·u + v > 10·x + y

**2. Симметрия.**

T(K) + T(−K) = |S(K)|

для всех K. В частности, при K = 0:

2·T(0) + 90 = |S(0)|

поскольку диагональных пар (A, A) ровно 90, и они все лежат в S(0).

**3. Сохранение.**

Сумма T(K) по всем целым K равна 4005:

сумма по K от T(K) = 4005 = C(90, 2)

где C(90, 2) — число всех пар двузначных чисел с A < B.

**4. Носитель.**

T(K) = 0 при |K| > 81.

**5. Явные значения.**

T(0) = 100

T(10) = 60

T(−10) = 46

**6. Асимметрия.**

T(K) не равно T(−K) в общем случае. Равенство T(K) = T(−K) имеет место тогда и только тогда, когда |Sₗₜ(K)| = |S<sub>gt</sub>(K)|, где S<sub>gt</sub>(K) — подмножество пар с A > B.

В частности, T(10) = 60, а T(−10) = 46, то есть они различаются на 14.

**7. Открытая проблема.**

Замкнутая формула для T(K) через K (в терминах элементарных функций, делителей или сумм Гаусса) неизвестна. Формула пункта 1 является точной, но алгоритмической: она требует перебора 90 значений (x, y) и для каждого — до 9 значений u. Замкнутое выражение, которое давало бы T(K) без перебора, не найдено.

## Доказательство

**Пункт 1.** Прямое следствие горизонтальной теоремы. Для фиксированного A = 10·x + y решения по B существуют только если g = НОД(x, y) делит K. При этом u пробегает один класс вычетов по модулю x / g, а v = (y·u − K) / x. Условия v ∈ {0, …, 9} и A < B выделяют конечное подмножество. Суммируя по x и y, получаем T(K).

**Пункт 2.** По теореме о симметрии, отображение swap (A, B) → (B, A) биективно переводит Sₗₜ(K) в S<sub>gt</sub>(−K). Значит, |Sₗₜ(K)| = |S<sub>gt</sub>(−K)|. Но S(K) разбивается в дизъюнктное объединение:

S(K) = Sₗₜ(K) ∪ S<sub>gt</sub>(K) ∪ S<sub>eq</sub>(K)

При K ≠ 0 множество S<sub>eq</sub>(K) пусто, поэтому

|S(K)| = |Sₗₜ(K)| + |S<sub>gt</sub>(K)| = T(K) + T(−K)

При K = 0: S<sub>eq</sub>(0) состоит из 90 пар (A, A), а Sₗₜ(0) и S<sub>gt</sub>(0) равномощны по swap. Значит, |S(0)| = 2·T(0) + 90.

**Пункт 3.** Каждая пара (A, B) с A < B имеет ровно одно значение Δ(A, B). Значит, множество всех пар с A < B разбивается в дизъюнктное объединение по K множеств Sₗₜ(K). Число всех пар с A < B равно C(90, 2) = 90·89/2 = 4005. Суммируя мощности, получаем сумму T(K) = 4005.

**Пункт 4.** По теореме о диапазоне, |S(K)| = 0 при |K| > 81. Значит, и T(K) = 0 при |K| > 81.

**Пункт 5.** Значение T(10) = 60 берётся из таблицы: в ней 60 строк, все с A < B. Значение T(0) = 100 вычислено прямым подсчётом: |S(0)| = 290, откуда T(0) = (290 − 90) / 2 = 100. Значение T(−10) = 46 вычислено через симметрию: |S(10)| = 106, T(−10) = |S(10)| − T(10) = 106 − 60 = 46.

**Пункт 6.** Из пункта 5: T(10) = 60, T(−10) = 46, разность 14. Значит, равенства нет. Общее утверждение: T(K) = T(−K) тогда и только тогда, когда |Sₗₜ(K)| = |S<sub>gt</sub>(K)|, что следует из пункта 2 и определения T(−K) = |Sₗₜ(−K)| = |S<sub>gt</sub>(K)|.

**Пункт 7.** Это утверждение об отсутствии результата, а не математическое утверждение. Оно фиксирует текущее состояние: замкнутой формулы нет.

## Вычисление |S(10)| = 106

Для проверки пункта 5 приведём разбиение |S(10)| по десяткам x. Здесь считаются все пары (A, B) с Δ = 10, без фильтра A < B.

    x   |S(10)| по x
    -----------------

    2   23
    3   8
    4   12
    5   15
    6   10
    7   8
    8   8
    9   5
    -----------------
    Σ   106

Из них 60 пар имеют A < B (это T(10) = 60, строки таблицы), а 46 пар имеют A > B (это T(−10) = 46).

Проверка для x = 1: все 17 решений имеют A < B, поскольку A = 12, …, 19, а B = 20, …, 98. Для x = 9: все 5 решений имеют A > B, поскольку A = 92, …, 98, а B = 20, …, 86. Для промежуточных x решения делятся между Sₗₜ и S<sub>gt</sub>.

## Почему нет замкнутой формы

Три причины.

**Первая.** Формула пункта 1 — это сумма по 90 парам (x, y). Каждое слагаемое c(x, y, K) зависит от K через разрешимость сравнения y·u ≡ K (mod x) и через неравенства v ∈ {0, …, 9} и 10u + v > 10x + y. Эти неравенства режут класс вычетов по u на конечный интервал, длина которого зависит от K нелинейно.

**Вторая.** Задача эквивалентна подсчёту числа целых точек на гиперплоскости y·u − x·v = K внутри четырёхмерного ящика [1, 9] × [0, 9] × [1, 9] × [0, 9]. В общем случае такие задачи не имеют замкнутой формы: число решений ведёт себя как сумма функций делителей с поправками, зависящими от арифметики K.

**Третья.** Асимметрия T(K) ≠ T(−K) означает, что T(K) не является чётной функцией K. Любая замкнутая формула должна была бы отражать эту асимметрию, что исключает простые симметричные выражения.

## Что здесь ново, а что стандартно

**Стандартно:**

- Разбиение множества решений по значению Δ — общий приём.
- Связь T(K) + T(−K) = |S(K)| — следствие кососимметричности.
- Сохранение суммы T(K) = 4005 — следствие того, что каждая пара имеет ровно одно значение Δ.

**Относительно ново (в контексте):**

- Явная формула для T(K) как конечной суммы c(x, y, K).
- Конкретные значения T(0) = 100, T(10) = 60, T(−10) = 46.
- Обнаружение асимметрии T(10) ≠ T(−10) с разностью 14.
- Формулировка открытой проблемы: замкнутая формула для T(K).

**Вывод.** Это **самостоятельная теорема**, но с открытым концом. Она даёт точную алгоритмическую формулу, несколько явных значений и conservation law, но не даёт замкнутого выражения. Для банка теорем её стоит хранить как «теорему с открытой проблемой» — это редкий и ценный тип: он фиксирует не только результат, но и границу знания.

## Практическая польза

1. Даёт **алгоритм** вычисления T(K) для любого K: перебор 90 пар (x, y) и для каждой — до 9 значений u.
2. Даёт **проверку** для программ: сумма T(K) по всем K должна равняться 4005, а T(K) + T(−K) должно равняться |S(K)|.
3. Фиксирует **асимметрию**: нельзя предполагать T(K) = T(−K); это неверно уже при K = 10.
4. Ставит **открытую проблему**: найти замкнутую формулу для T(K). Это законная математическая задача, а не риторический вопрос.
