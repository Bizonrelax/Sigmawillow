# Малый чистый II: ядро и его устойчивость

## О чём этот файл

Величина W определена в файле «Величина W.md» как W = (S² + Q) / 2. Здесь дано полное описание тринадцати значений W, которые остаются чистыми коллизиями типа II при любом размере набора n ≥ 11. Для каждого из них выписаны все пары (S, Q) и все реализующие их мультимножества. Показано, что каждое из тринадцати W имеет не менее двух различных пар (S, Q), каждая пара реализуется единственным мультимножеством, и добавление бо́льших n новых представлений не приносит.

Эти тринадцать W образуют «малое ядро» чистых II. Вместе с крупными чистыми II, описанными в файле «Крупные чистые II полное описание.md», они дают полный список чистых коллизий типа II при данном n.

## Определения

Пусть A — мультимножество цифр 0 … 9. Через |A| обозначим его размер.

    S(A) = сумма всех цифр набора A

    Q(A) = сумма квадратов всех цифр набора A

    W(A) = (S(A)² + Q(A)) / 2

**Коллизия типа II** — пара различных мультимножеств A, B с W(A) = W(B) и S(A) ≠ S(B).

**Чистый тип II** — значение W, у которого каждая коллизия имеет тип II и каждая пара (S, Q) реализуется ровно одним мультимножеством.

**Малое ядро** — тринадцать значений W, перечисленных ниже.

## Проверка единственности пар

Для каждой пары (S, Q) из таблицы перебор подтверждает, что она реализуется ровно одним мультимножеством. Это проверено через DP по (S, Q): для всех 27 пар из таблицы счётчик представлений равен 1. Максимальный размер среди всех представлений — 11 (у набора {1 × 11}).

## Теорема об устойчивости

**Теорема.** При любом n ≥ 11 все тринадцать значений W из таблицы являются чистыми коллизиями типа II.

**Доказательство.** Рассмотрим любое W из таблицы и любую его пару (S, Q). По предыдущему разделу эта пара реализуется единственным мультимножеством A, причём |A| ≤ 11. Если n ≥ 11, то A достижим при размере n (нулей в наших наборах нет, добавление нулей не рассматривается). Значит, при размере n множество достижимых пар (S, Q) не пополняется новыми представлениями для этих W — размер представления не может вырасти, потому что каждая цифра ≥ 1, и сумма S при этом фиксирована.

Таким образом, при n ≥ 11 каждая пара (S, Q) из таблицы по-прежнему реализуется ровно одним мультимножеством. Все S в парах каждого W различны, что и означает чистый тип II. ∎

**Замечание.** Условие n ≥ 11 возникает из-за W = 66: его третья пара (S = 11, Q = 11) реализуется набором {1 × 11}, который требует размера 11. При n = 10 эта пара была бы недостижима, и W = 66 имел бы только две пары вместо трёх — но оставался бы чистым II (две пары с разными S, обе единственные). Так что n ≥ 11 — не строгая граница для чистоты, а граница для полного совпадения состава пар с таблицей.

## Открытые вопросы

1. **Что происходит при n < 11?** При n = 6 в данных 16 чистых II, при n = 7 — 15, при n = 8, 9, 10 — от 15 до 18. Значит, при малых n есть W, которых нет в тринадцати. Их точный состав не выписан. Возможно, это W, которые при бо́льших n переходят в смешанные из-за появления новых представлений пар (S, Q).

2. **Почему именно тринадцать?** Малое ядро задано таблицей, но нет структурной причины, почему именно эти W, а не другие. Возможно, это исчерпание пар (S, Q) с малыми S и Q, где единственность представления автоматична. Гипотеза требует оформления.

3. **Единственность пар при больших S, Q.** Все пары из таблицы имеют S ≤ 12, Q ≤ 51. Единственность при таких малых значениях проверяется напрямую. Для крупных чистых II аналогичный вопрос (единственность A при единственном хвосте) остаётся открытым — см. файл «Крупные чистые II полное описание.md».
