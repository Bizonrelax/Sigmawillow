# Крупные чистые коллизии типа II: полное описание

## О чём этот файл

Здесь дано полное описание крупных чистых коллизий типа II для величины W. Все они имеют фиксированную структуру: второй набор B состоит только из семёрок и шестёрок, первый набор A — из девяток и короткого хвоста из цифр 1 … 8. Хвост удовлетворяет одному уравнению, зависящему только от числа шестёрок q в B. Все допустимые хвосты выписаны явно, и каждый работает только при одном остатке n по модулю 9. Это определяет число и структуру крупных чистых II при любом n. Всё проверено полным перебором для n от 20 до 100.

## Определения

Пусть A — мультимножество цифр 0 … 9. Положим:

    S(A) = сумма всех цифр набора A

    Q(A) = сумма квадратов всех цифр набора A

    W(A) = (S(A)² + Q(A)) / 2

**Коллизия типа II** — пара различных мультимножеств A, B с W(A) = W(B) и S(A) ≠ S(B).

**Чистый тип II** — значение W, у которого каждая коллизия имеет тип II и каждая пара (S, Q) реализуется ровно одним мультимножеством.

**Крупное чистое II** — значение W, у которого все пары (S, Q) имеют S ≥ 6n, где n — размер набора.

## Структура крупной пары

Для любой крупной чистой II при n от 20 до 100 выполнено:

    A = {9 × a} ∪ T

    B = {7 × p} ∪ {6 × q}

где q = n − p, a, p, q — неотрицательные целые, T — мультимножество цифр 1 … 8 (хвост). В наборе B ровно q шестёрок и p = n − q семёрок. В наборе A ровно a девяток и |T| цифр меньших 9.

Суммы через n и q:

    S(B) = 7n − q

    Q(B) = 49n − 13q

Суммы через a и T:

    S(A) = 9a + S(T)

    Q(A) = 81a + Q(T)

## Теорема о хвосте

**Теорема 1.** В крупной паре с параметрами n, q и хвостом T выполнено

    9S(T) − Q(T) = 6q − 8

**Доказательство.** Условие W(A) = W(B) вместе с S(B) = S(A) + 1 (что эмпирически верно для всех крупных чистых II) даёт

    Q(A) − Q(B) = S(A) + S(B) = 2S(A) + 1

Подставим S(A) = 9a + S(T), Q(A) = 81a + Q(T), S(B) = 7n − q, Q(B) = 49n − 13q:

    81a + Q(T) − 49n + 13q = 2(9a + S(T)) + 1

    63a = 49n − 13q − Q(T) + 2S(T) + 1

С другой стороны, S(B) = S(A) + 1 даёт a = (7n − q − S(T) − 1) / 9, откуда

    63a = 441n − 63q − 63S(T) − 63

Приравнивая правые части, получаем после сокращений

    9S(T) − Q(T) = 6q − 8

∎

**Следствие (модульное условие).** Если A = {9 × a} ∪ T — крупная чистая II с параметром q, то

    S(T) ≡ 7n − q − 1 (mod 9)

и, эквивалентно,

    n ≡ 4 · (S(T) + q + 1) (mod 9)

**Доказательство.** Из a = (7n − q − S(T) − 1) / 9 числитель делится на 9, откуда первое сравнение. Для второго умножим обе части на 4 с учётом 4·7 ≡ 1 (mod 9). ∎

Каждый хвост работает только при одном остатке n по модулю 9.

## Критерий чистого II

**Теорема 2.** Крупное W с параметрами (n, q) является чистым типом II тогда и только тогда, когда в карте для q есть ровно один хвост T с остатком S(T) ≡ 7n − q − 1 (mod 9).

**Доказательство.** Если хвостов 0 — A не существует, крупной пары нет. Если ≥ 2 — пара (S, Q) реализуется несколькими мультимножествами, W смешанный. Если ровно 1 — A единствен по теореме 3 (ниже), а B = {7 × p, 6 × q} единствен тривиально. ∎

Дополнение к теореме 2:

При ≥ 2 хвостах пара (S, Q) одна и та же: S(A) = 7n − q − 1 и Q(A) = 63n − 15q − 1 не зависят от выбора T. Разные T дают разные A с одной и той же парой (S, Q), то есть коллизию типа I.

## Теорема единственности A

**Вспомогательный функционал.** Для мультимножества X цифр 1 … 9 положим Φ(X) = 9·S(X) − Q(X). Он аддитивен, и для любой цифры d ∈ {1, …, 9} выполнено 9d − d² ≥ 0, причём равенство только при d = 9. Значит, Φ(X) ≥ 0, и Φ(X) = 0 тогда и только тогда, когда все цифры X равны 9.

**Теорема 3 (единственность A).** Пусть q ∈ {4, 5, 6, 7, 9}, T — хвост из карты для q, a = (7n − q − 1 − S(T)) / 9, A = {9 × a} ∪ T. Пусть в карте для q нет других хвостов с S(T') ≡ S(T) (mod 9). Тогда любое примитивное A' с S(A') = S(A) и Q(A') = Q(A) совпадает с A.

**Доказательство.** Разложим A' = {9 × a'} ∪ T' с хвостом T' из цифр 1 … 8. Тогда Φ(A') = Φ(T') (девятки не дают вклада). С другой стороны, Φ(A') = Φ(A) = Φ(T) = 6q − 8 (теорема 1). Значит, T' — хвост из карты для q. Из S(A') = S(A) следует S(T') ≡ S(T) (mod 9), откуда по условию T' = T и a' = a. Следовательно, A' = A. ∎

## Ограничение на q

Все описанные результаты относятся к q ∈ {4, 5, 6, 7, 9}. Для q = 8, 10, 11 … в карте тоже есть валидные хвосты (например, для q = 8 подходят T = {1, 1, 1, 1, 1} и T = {7, 6, 1}, оба с остатком n ≡ 2 mod 9). Однако при данном n сразу несколько таких хвостов дают целое a, и A не единствен. Поэтому такие q не дают чистого II. Эмпирически при n ≤ 100 крупных чистых II с q = 8 или q ≥ 10 не встречается. Формального доказательства нет.

## Открытые вопросы

1. **Почему q ∈ {4, 5, 6, 7, 9}?** Для q = 8 и q ≥ 10 валидные хвосты существуют, но при данном n их несколько. Есть ли среди q ≥ 10 такие, где хвост ровно один? Проверено до n = 100, не найдено. Открыто.

2. **Конечность карты.** Хвосты перечислены до S(T) = 39. Расширение до S(T) = 100 новых хвостов не выявило. Существует ли бесконечное семейство хвостов при S(T) → ∞? Открыто.
