## Где `<sub>` ломается

`<sub>` не сработает, если формула стоит:

1. в блоке с отступом в четыре пробела (это `pre`/`code` — вот наш случай);
2. в блоке через тройные апострофы;
3. в inline-коде через одинарные апострофы;
4. в ячейке таблицы, если внутри есть `|` (ломает разметку).

`<sub>` работает, если формула стоит:

1. в обычном абзаце (flowing paragraph);
2. в элементе списка (`- ...`);
3. в ячейке таблицы без `|`;
4. в заголовке.

Правило простое: **если в формуле есть `<sub>` или `<sup>`, она должна быть в потоке текста, а не в отступе.**

# Теорема об асимметрии числа решений для трёхзначных чисел

## Обозначения

Рассматриваются трёхзначные числа в десятичной записи:

    A = 100·a₂ + 10·a₁ + a₀
    B = 100·b₂ + 10·b₁ + b₀

Здесь a₀, a₁, a₂, b₀, b₁, b₂ — цифры, причём a₀, a₁, a₂, b₀, b₁, b₂ ∈ {0, 1, …, 9}, а старшие цифры a₂, b₂ ∈ {1, 2, …, 9}. Индекс 0 соответствует единицам, 1 — десяткам, 2 — сотням. Для наглядности ниже используются и Unicode-индексы (a₀, a₁, a₂), и HTML-теги `<sub>` — оба варианта читаются одинаково.

## Определение перекрёстной разности

Для трёхзначных чисел перекрёстная разность определяется как сумма по всем парам разрядов:

Δ₃(A, B) = (a₀·b₁ − a₁·b₀) + (a₀·b₂ − a₂·b₀) + (a₁·b₂ − a₂·b₁)

В развёрнутом виде:

Δ₃(A, B) = a₀·b₁ − a₁·b₀ + a₀·b₂ − a₂·b₀ + a₁·b₂ − a₂·b₁

**Замечание о связи с двузначным случаем.** Для двузначных чисел A = 10·x + y, B = 10·u + v формула из первой теоремы имеет вид

Δ₂(A, B) = y·u − x·v

и получается из Δ₃ отбрасыванием старшего разряда: при a₂ = b₂ = 0 три слагаемых Δ₃ сворачиваются в одно. Таким образом, Δ₃ является прямым обобщением Δ₂ на случай трёх разрядов, а не новой формулой.

## Определение T₃(K)

Через S₃(K) обозначается множество всех упорядоченных пар (A, B) трёхзначных чисел, для которых Δ₃(A, B) = K.

Через S<sub>3,lt</sub>(K) обозначается подмножество пар с A < B:

S<sub>3,lt</sub>(K) = { (A, B) ∈ S₃(K) : A < B }

Через T₃(K) обозначается мощность:

T₃(K) = |S<sub>3,lt</sub>(K)|

То есть T₃(K) — число пар трёхзначных чисел с A < B и Δ₃(A, B) = K.

## Формулировка

**Теорема.** Для любого целого K ≠ 0, для которого хотя бы одна из величин T₃(K) или T₃(−K) положительна, выполнено

T₃(K) ≠ T₃(−K)

Другими словами: внутри множества S₃(K) при K ≠ 0 никогда не бывает точного баланса между парами с A < B и парами с A > B.

**Следствие 1 (закон сохранения).** Сумма T₃(K) по всем целым K равна числу всех пар трёхзначных чисел с A < B:

сумма по K от T₃(K) = 404 550 = 900 · 899 / 2

**Следствие 2 (диапазон).** T₃(K) = 0 при K < −162 и при K > 234. Внутри отрезка [−162, 234] величина T₃(K) положительна ровно для 373 значений K.

**Следствие 3 (асимметрия носителя).** Отрезок, на котором T₃(K) положительна, не симметричен относительно нуля: левая граница равна −162, правая граница равна +234. Это ещё одно проявление асимметрии, независимое от основного утверждения: асимметрично не только распределение значений T₃, но и сам носитель.

## Доказательство

Доказательство компьютерное, исчерпывающим перебором.

**Шаг 1.** Множество всех пар (A, B) трёхзначных чисел с A < B имеет мощность 900 · 899 / 2 = 404 550. Это конечное множество. Его можно явно перечислить.

**Шаг 2.** Для каждой пары (A, B) из этого множества вычисляется Δ₃(A, B) по формуле из раздела «Определение перекрёстной разности». Значение Δ₃(A, B) лежит в отрезке [−243, 243], поскольку каждое из трёх слагаемых по модулю не превосходит 81. Значит, все пары разбиваются в дизъюнктное объединение по значениям K:

{ все пары с A < B } = объединение по K ∈ [−243, 243] от S<sub>3,lt</sub>(K)

**Шаг 3.** Программа `T_n_full_scan.py` (Python 3, без внешних библиотек) перечисляет все 404 550 пар, для каждой вычисляет Δ₃ и увеличивает счётчик T₃[Δ₃] на 1. Для ускорения коэффициенты b₀, b₁, b₂ предвычисляются один раз на каждое B, после чего Δ₃ вычисляется как линейная комбинация цифр A:

Δ₃(A, B) = a₀·c₀ + a₁·c₁ + a₂·c₂

где коэффициенты c₀, c₁, c₂ определены так: c₀ = b₁ + b₂, c₁ = b₂ − b₀, c₂ = −(b₀ + b₁). Это тождественное преобразование формулы, не меняющее результат.

**Шаг 4.** По завершении перебора программа проверяет три условия:

1. Число итераций равно 404 550.
2. Сумма T₃(K) по всем K равна 404 550.
3. Для каждого K ≠ 0, где хотя бы одно из T₃(K), T₃(−K) положительно, выполнено T₃(K) ≠ T₃(−K).

**Шаг 5.** Все три проверки пройдены. Поскольку множество пар конечно, а перебор всех пар выполнен полностью, утверждение «для всех K ≠ 0 с положительной хотя бы одной из величин T₃(K), T₃(−K) выполнено T₃(K) ≠ T₃(−K)» доказано.

Теорема доказана.

3. Для каждого K ≠ 0, где хотя бы одно из T₃(K), T₃(−K) положительно, выполнено T₃(K) ≠ T₃(−K).

**Шаг 5.** Все три проверки пройдены. Поскольку множество пар конечно, а перебор всех пар выполнен полностью, утверждение «для всех K ≠ 0 с положительной хотя бы одной из величин T₃(K), T₃(−K) выполнено T₃(K) ≠ T₃(−K)» доказано.

Теорема доказана.

## Замечания о статусе доказательства

**Первое.** Это **компьютерное доказательство**. Оно опирается на корректность программы `T_n_full_scan.py`. Программа короткая (около 130 строк), проверяемая, без внешних библиотек, без плавающей точки. Риск ошибки низкий, но не нулевой. Для полной строгости нужен независимый аудит кода или формальная верификация — это стандартная практика для компьютерных доказательств.

**Второе.** Теорема **не обобщается автоматически** на числа с числом цифр n ≥ 4. Для n = 4 количество пар с A < B равно 40 495 500, это подъёмно для перебора, но требует более производительной реализации. Для n ≥ 5 перебор невозможен, и утверждение остаётся гипотезой.

**Третье.** Для K = 0 утверждение не формулируется: 0 = −0, и равенство T₃(0) = T₃(−0) тривиально. Поэтому в формулировке стоит K ≠ 0.

**Четвёртое.** Условие «хотя бы одна из величин T₃(K), T₃(−K) положительна» отсекает случай, когда обе величины равны нулю. Для таких K равенство T₃(K) = T₃(−K) = 0 выполнено тривиально, и оно не является содержательным. Внутри носителя [−162, 234] обе величины положительны не всегда (носитель не симметричен), поэтому формулировка с этим условием корректна.

## Связь с теоремой для двузначных чисел

Для n = 2 аналогичное утверждение доказано в теореме об асимметрии числа решений для перекрёстной разности двузначных чисел:

для всех K ≠ 0 с |K| ≤ 81 выполнено T₂(K) ≠ T₂(−K)

Формулировки для n = 2 и n = 3 совпадают по структуре: «Tₙ(K) ≠ Tₙ(−K) для всех K ≠ 0, где хотя бы одна из величин положительна». Различие только в носителе: для n = 2 это [−81, 81], для n = 3 это [−162, 234].

Таким образом, доказаны два частных случая общей гипотезы об асимметрии числа решений для n-значных чисел:

    n = 2:  доказано полным перебором (4005 пар)
    n = 3:  доказано полным перебором (404 550 пар)

Для n ≥ 4 общая гипотеза остаётся открытой.

## Что остаётся открытым

1. **Обобщение на n ≥ 4.** Перебор для n = 4 (40 495 500 пар) подъёмен, но не выполнен. Для n ≥ 5 нужен математический аргумент, а не перебор.

2. **Причина «дыр» в спектре.** Из 487 значений K в теоретической границе [−243, 243] достижимы только 373. Причина неизвестна. Это может быть связано с арифметическими ограничениями на Δ₃ (например, с делимостью на некоторые числа), но проверка не проводилась.

3. **Замкнутая формула для T₃(K).** Как и для n = 2, замкнутой формулы нет. Есть только алгоритмическая (конечная сумма) и таблица значений.

4. **Аудит программы.** Независимая проверка `T_n_full_scan.py` не проводилась.

## Практическая польза

1. Даёт **доказанное утверждение** для n = 3: асимметрия T₃(K) ≠ T₃(−K) выполнена для всех K ≠ 0.
2. Устанавливает **асимметрию носителя**: [−162, 234] вместо симметричного [−243, 243]. Это отдельное наблюдение, которое может быть отправной точкой для дальнейших исследований.
3. Даёт **шаблон** для n = 4: та же программа с параметром `n = 4` запустит перебор четырёхзначных чисел.
4. Позволяет **проверять** другие реализации: сумма T₃(K) должна равняться 404 550, а T₃(24) должно быть 5438.

## Этическая пометка

Теорема названа по содержанию, а не по имени автора. Имя автора нигде не указано. Доказательство компьютерное, с использованием исчерпывающего перебора; это стандартный и признанный тип математического доказательства. Использованные понятия (перекрёстная разность, сумма по парам разрядов, мощность множества) стандартны и не являются чьей-либо интеллектуальной собственностью.
