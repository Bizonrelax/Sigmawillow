## Теорема о совпадениях величины W для двузначных чисел

**Определение.** Пусть A — двузначное число, A = 10·x + y, где x ∈ {1, …, 9}, y ∈ {0, …, 9}. Определим величину

    W(A) = x² + x·y + y²

Назовём два двузначных числа **эквивалентными**, если одно получается из другого перестановкой цифр: A ~ B, если B = 10·y + x и при этом B остаётся двузначным (то есть y ≠ 0). Если y = 0, класс эквивалентности состоит только из A.

**Утверждение.** Отображение A ↦ W(A) инъективно на классах эквивалентности, за следующими двумя исключениями:

1. Класс {35, 53} и число 70 дают одно и то же значение: W(35) = W(53) = W(70) = 49.
2. Классы {19, 91} и {56, 65} дают одно и то же значение: W(19) = W(91) = W(56) = W(65) = 91.

Других совпадений между разными классами нет.

**Доказательство.** Множество двузначных чисел конечно (90 элементов). Прямой перебор всех пар (A, B) и сравнение значений W(A) и W(B) показывает, что все совпадения исчерпываются перестановками цифр внутри одного класса и двумя указанными объединениями классов. Полная таблица значений W(A) для всех 90 чисел делает проверку конечной и воспроизводимой. ∎

**Замечание.** Всего существует 54 класса эквивалентности (числа с разными цифрами образуют пары, числа с одинаковыми цифрами и числа, оканчивающиеся на 0, — одиночные классы). После двух указанных слияний остаётся ровно 52 различных значения величины W.

## Решена ли задача Пруэ–Тарри–Эскотта?

В общем виде — **нет**. Это классическая открытая проблема диофантовой геометрии. Известны сильные частичные результаты:

- Идеальные решения (определение ниже) найдены для размеров n ≤ 10 и для n = 12.
- Для остальных размеров вопрос о существовании идеальных решений остаётся открытым.
- Совсем недавно, в 2023 году, было найдено первое идеальное решение для степени k = 9 (размер n = 10) с помощью компьютерного поиска.

То есть задача **частично решена**: известны отдельные идеальные решения и целые семейства, но общей теории, описывающей все решения или доказывающей их отсутствие для тех или иных параметров, нет.

## Что такое «идеальные решения PTE»?

Задача PTE спрашивает: существуют ли два непересекающихся мультимножества целых чисел A и B **одинакового размера** n, у которых совпадают суммы k-х степеней элементов для всех k от 1 до некоторого m:

    a₁ᵏ + … + aₙᵏ = b₁ᵏ + … + bₙᵏ   для k = 1, 2, …, m

Решение называется **идеальным**, если m = n − 1. Это **максимально возможная степень** при данном размере: доказано, что при m ≥ n равенство всех степеней вынуждает множества совпадать, поэтому m = n − 1 — это «предел». Идеальные решения — самые сильные и самые трудные; именно их поиск составляет основную часть проблемы PTE.

Помимо классических идеальных решений, в литературе рассматриваются **взвешенные идеальные решения** — когда равенства сумм степеней выполняются с некоторыми весами, а не только с единичными коэффициентами.
