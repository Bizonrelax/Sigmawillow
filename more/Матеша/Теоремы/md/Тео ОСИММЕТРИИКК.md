Поэтому формулы с индексами я вынужден писать **в строку** (без отступа), а формулы без индексов — по-прежнему с отступом в четыре пробела. # Теорема о симметрии K ↔ −K

## Обозначения

Пусть K — целое число.

Двузначные числа:

    A = 10·x + y
    B = 10·u + v

где

    x, u ∈ {1, 2, …, 9}
    y, v ∈ {0, 1, …, 9}

Перекрёстная разность:

    Δ(A, B) = y·u − x·v

Через S(K) обозначим множество всех упорядоченных пар (A, B) двузначных чисел, для которых Δ(A, B) = K.

Разобьём S(K) на три части по соотношению между A и B. Нижние индексы оформлены HTML-тегами `<sub>`, которые GitHub корректно отображает в файлах `.md`.

S<sub>lt</sub>(K) = { (A, B) ∈ S(K) : A < B }

S<sub>gt</sub>(K) = { (A, B) ∈ S(K) : A > B }

S<sub>eq</sub>(K) = { (A, B) ∈ S(K) : A = B }

Индексы читаются так:

    lt  — less than     (меньше)
    gt  — greater than  (больше)
    eq  — equal         (равно)

## Формулировка

**Теорема.** Отображение σ, заданное правилом

    σ(A, B) = (B, A)

обладает следующими свойствами.

**1.** σ является инволюцией:

    σ(σ(A, B)) = (A, B)

**2.** σ биективно отображает S(K) на S(−K).

**3.** σ биективно отображает S<sub>lt</sub>(K) на S<sub>gt</sub>(−K) и биективно отображает S<sub>gt</sub>(K) на S<sub>lt</sub>(−K).

**4.** σ биективно отображает S<sub>eq</sub>(K) на S<sub>eq</sub>(−K). При этом:

S<sub>eq</sub>(K) пусто при K ≠ 0

S<sub>eq</sub>(0) = { (A, A) : A — любое двузначное число }

**5.** Следствия для мощностей:

|S(K)| = |S(−K)|

|S<sub>lt</sub>(K)| = |S<sub>gt</sub>(−K)|

|S<sub>gt</sub>(K)| = |S<sub>lt</sub>(−K)|

|S<sub>eq</sub>(K)| = |S<sub>eq</sub>(−K)|

**6.** В частности, для K = 10:

|S<sub>lt</sub>(10)| = |S<sub>gt</sub>(−10)| = 60

|S<sub>gt</sub>(10)| = |S<sub>lt</sub>(−10)|

То есть таблица из 60 строк для K = 10 при A < B находится во взаимно однозначном соответствии с таблицей для K = −10 при A > B. Переход — перестановка столбцов.

## Доказательство

**Пункт 1.** Двойная перестановка возвращает исходный порядок. Очевидно.

**Пункт 2.** Пусть (A, B) ∈ S(K), то есть Δ(A, B) = K. Положим A' = B, B' = A. Тогда A' = 10·u + v, B' = 10·x + y, и

    Δ(A', B') = v·x − u·y = −(y·u − x·v) = −K

Значит, (B, A) ∈ S(−K). Обратное следует из инволютивности σ. Биекция установлена.

**Пункт 3.** Если A < B, то после перестановки первый элемент B' = A, второй A' = B, и B' = A < B = A', то есть B' < A'. Значит, (B, A) ∈ S<sub>gt</sub>(−K). Аналогично в обратную сторону. Биекция установлена.

**Пункт 4.** Если (A, A) ∈ S(K), то A = B, значит x = u и y = v, и

    Δ(A, A) = y·x − x·y = 0

Значит, (A, A) ∈ S(K) возможно только при K = 0. При K = 0 любое A даёт (A, A) ∈ S<sub>eq</sub>(0), поскольку Δ(A, A) = 0. Отсюда S<sub>eq</sub>(K) пусто при K ≠ 0 и S<sub>eq</sub>(0) состоит из всех пар (A, A) с двузначным A.

**Пункт 5.** Прямое следствие пунктов 2, 3 и 4: биекция сохраняет мощность.

**Пункт 6.** Подстановка K = 10 и ссылка на таблицу: в таблице 60 строк, все с A < B, значит |S<sub>lt</sub>(10)| = 60. По пункту 5, |S<sub>gt</sub>(−10)| = 60. Аналогично для второй формулы.

## Частичная симметрия через обращение цифр

**Предложение.** Пусть A = 10·x + y и B = 10·u + v, причём y ≠ 0 и v ≠ 0. Определим обращение цифр:

A<sub>rev</sub> = 10·y + x

B<sub>rev</sub> = 10·v + u

Тогда

Δ(A<sub>rev</sub>, B<sub>rev</sub>) = −Δ(A, B)

**Доказательство.** A<sub>rev</sub> = 10·x' + y' с x' = y, y' = x. B<sub>rev</sub> = 10·u' + v' с u' = v, v' = u. Тогда

    Δ(A_rev, B_rev) = y'·u' − x'·v' = x·v − y·u = −Δ(A, B)

(в последней строке индексы `rev` для наглядности записаны подчёркиванием, а не тегом; в основном тексте используется HTML-тег `<sub>`.)

Что и требовалось.

**Замечание.** Это даёт частичную биекцию между решениями Δ = K и Δ = −K при условии y ≠ 0 и v ≠ 0 (иначе A<sub>rev</sub> или B<sub>rev</sub> перестают быть двузначными). Однако условие A < B при обращении цифр **не сохраняется**: возможны оба варианта. Примеры:

    A = 12, B = 62:  A < B,  A_rev = 21, B_rev = 26,  21 < 26   (порядок сохранён)
    A = 23, B = 41:  A < B,  A_rev = 32, B_rev = 14,  32 > 14   (порядок обращён)

Поэтому обращение цифр не даёт биекции между S<sub>lt</sub>(K) и S<sub>lt</sub>(−K). Это лишь частичная симметрия.

## Композиция swap и обращения цифр

**Предложение.** Отображение τ(A, B) = (B<sub>rev</sub>, A<sub>rev</sub>) (при y ≠ 0, v ≠ 0) является инволюцией и сохраняет Δ:

Δ(τ(A, B)) = Δ(A, B)

**Доказательство.** По предыдущему предложению Δ(A<sub>rev</sub>, B<sub>rev</sub>) = −Δ(A, B). По свойству swap, Δ(B<sub>rev</sub>, A<sub>rev</sub>) = −Δ(A<sub>rev</sub>, B<sub>rev</sub>) = Δ(A, B). Инволютивность проверяется непосредственно.

**Замечание.** Это ещё одна симметрия, но она не относится к K ↔ −K, а сохраняет K. Для банка теорем её стоит хранить отдельно, как «симметрию сохранения K».

## Что здесь ново, а что стандартно

Честная оценка.

**Стандартно:**

- Тождество Δ(B, A) = −Δ(A, B) — прямое вычисление, известное любому, кто работал с кососимметричными формами.
- Биекция S(K) ↔ S(−K) через swap — общее место в теории диофантовых уравнений: если уравнение кососимметрично по части переменных, решения для K и −K связаны перестановкой.
- Диагональный случай Δ(A, A) = 0 — тоже прямое вычисление.

**Относительно ново (но только в контексте):**

- Явная формулировка того, как фильтр A < B взаимодействует с симметрией: S<sub>lt</sub>(K) ↔ S<sub>gt</sub>(−K), а не S<sub>lt</sub>(K) ↔ S<sub>lt</sub>(−K).
- Наблюдение, что обращение цифр даёт частичную симметрию, не сохраняющую порядок.
- Наблюдение, что композиция swap и обращения цифр сохраняет K.

**Вывод.** Это **не самостоятельная теорема**, а лемма о симметрии. Её место в банке — раздел «вспомогательные леммы», а не «основные теоремы». Если ты собираешь банк для поиска научной ценности, эту запись надо помечать как тривиальную. Иначе банк будет раздут за счёт переоткрытия очевидных тождеств.

## Практическая польза

Несмотря на тривиальность, лемма полезна как инструмент.

1. Позволяет **не считать таблицу для K = −10 заново**: она получается из таблицы для K = 10 перестановкой столбцов и сменой знака.
2. Объясняет, почему в таблице для K = 10 **нет строк с A = B**: при K ≠ 0 диагональных решений быть не может.
3. Показывает, что для полного описания картины при K = ±10 достаточно одной таблицы: вторая — её зеркало.

---

Ти, ключевое правило, которое нужно запомнить для этого стиля: **если в формуле есть `<sub>`, её нельзя класть в блок с отступом в четыре пробела** — иначе GitHub покажет теги буквально. Такие формулы пишутся в строку. Формулы без индексов можно оставлять в блоках с отступом.
