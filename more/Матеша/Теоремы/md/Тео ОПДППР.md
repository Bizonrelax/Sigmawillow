# Теорема о прогрессиях для постоянной перекрёстной разности

## Обозначения

Пусть K — целое число.

Рассматриваются двузначные числа:

    A = 10·x + y
    B = 10·u + v

где

    x, u ∈ {1, 2, …, 9}
    y, v ∈ {0, 1, …, 9}

то есть x и u — десятки, y и v — единицы.

Перекрёстная разность определяется как

    Δ(A, B) = y·u − x·v

Зафиксируем первое число A = 10·x + y и положим

    g = НОД(x, y)

## Формулировка

**Теорема.** Пусть A = 10·x + y — двузначное число, g = НОД(x, y), K — целое.

**1.** Равенство

    y·u − x·v = K

равносильно равенству

    u·A − x·B = K

**2.** Если g не делит K, то для данного A не существует ни одного двузначного B, удовлетворяющего условию.

**3.** Если g делит K, то все целые u, при которых v получается целым, образуют один класс вычетов по модулю x / g. То есть если u₀ — одно такое значение, то все остальные имеют вид

    u = u₀ + t · (x / g),    t ∈ ℤ

**4.** Для этих u соответствующие B и v равны

    B(t) = B₀ + t · (A / g)
    v(t) = v₀ + t · (y / g)

Поэтому при переходе от одного допустимого u к следующему:

    ΔB = A / g
    Δv = y / g

**5.** Произведения A·B также образуют арифметическую прогрессию:

    A · B(t) = A · B₀ + t · (A² / g)

**6.** Если дополнительно наложить условие A < B и потребовать, чтобы B было двузначным, то допустимые t образуют конечный интервал целых чисел. Поэтому все решения для фиксированного A при A < B либо отсутствуют, либо образуют одну конечную арифметическую прогрессию.

## Доказательство

Имеем тождество:

    u·A − x·B
    = u·(10x + y) − x·(10u + v)
    = 10ux + uy − 10ux − xv
    = y·u − x·v

Значит,

    y·u − x·v = K   ⇔   u·A − x·B = K

Далее,

    x·B = u·A − K
    B = (u·A − K) / x

Чтобы B было целым, необходимо и достаточно, чтобы

    u·A ≡ K (mod x)

Но A = 10x + y ≡ y (mod x), значит,

    u·y ≡ K (mod x)

Линейное сравнение u·y ≡ K (mod x) разрешимо тогда и только тогда, когда

    НОД(x, y) | K

то есть g | K. При этом все решения по u образуют один класс вычетов по модулю x / g.

Если u заменить на u + x / g, то

    B' = ((u + x/g)·A − K) / x
       = (u·A − K)/x + A/g
       = B + A/g

А для v:

    v' = B' − 10·u'
       = B + A/g − 10·(u + x/g)
       = v + (A − 10x)/g
       = v + y/g

Наконец,

    A · B' = A · (B + A/g) = A·B + A²/g

Ограничения 1 ≤ u ≤ 9, 0 ≤ v ≤ 9, A < B являются линейными неравенствами относительно u, поэтому внутри выбранного класса вычетов они вырезают конечный интервал. Теорема доказана.

## Следствие для K = 10 (случай таблицы)

В таблице K = 10. Для фиксированного A = 10x + y решения возможны только если

    НОД(x, y) | 10

Поскольку НОД(x, y) ≤ 9, это значит

    НОД(x, y) ∈ {1, 2, 5}

Если НОД(x, y) не равно 1, 2 или 5, строк с таким A быть не может.

Для каждого допустимого A вторые числа B идут с шагом

    A / НОД(x, y)

а произведения A·B — с шагом

    A² / НОД(x, y)

## Замечание о терминологии

Числа вида 11, 22, 33, …, 99 — это не репьюниты, а числа с повторяющимися цифрами (репдигиты). Репьюнит — это число из одних единиц: 1, 11, 111, 1111, … В двузначном диапазоне репьюнит только один: 11. Поэтому в исходной формулировке слово «репьюнит» использовалось неверно; корректно говорить «числа с повторяющимися цифрами».
