Ти, заменил «мёртвость» на «пустоту». Термины теперь нейтральные: **структурно пустой десяток** и **фактически пустой десяток**. Формат тот же — вариант D плюс `<sub>` там, где нужны индексы.

# Теорема о структурной и фактической пустоте десятка

## Обозначения

Пусть K — целое число.

Двузначные числа:

    A = 10·x + y
    B = 10·u + v

где

    x, u ∈ {1, 2, …, 9}
    y, v ∈ {0, 1, …, 9}

Перекрёстная разность:

    Δ(A, B) = y·u − x·v

Через S(K) обозначим множество всех упорядоченных пар (A, B) двузначных чисел, для которых Δ(A, B) = K.

Через S<sub>lt</sub>(K) обозначим подмножество пар с A < B:

S<sub>lt</sub>(K) = { (A, B) ∈ S(K) : A < B }

Через N(x, K) обозначим число пар (A, B) ∈ S<sub>lt</sub>(K), у которых десяток первого числа равен x:

N(x, K) = |{ (A, B) ∈ S<sub>lt</sub>(K) : A = 10·x + y, y ∈ {0, …, 9} }|

## Два определения пустоты

**Определение 1 (структурная пустота).** Десяток x называется структурно пустым для K, если для всех y ∈ {0, 1, …, 9} выполнено

НОД(x, y) ∤ K

то есть ни при каком y из диапазона единиц сравнение u·y ≡ K (mod x) не разрешимо.

**Определение 2 (фактическая пустота).** Десяток x называется фактически пустым для K, если

N(x, K) = 0

то есть в таблице для данного K нет ни одной строки с первым числом из интервала 10x ≤ A ≤ 10x + 9.

## Формулировка

**Теорема.** Пусть K — целое, x ∈ {1, 2, …, 9}.

**1.** Если x структурно пуст для K, то x фактически пуст для K:

структурная пустота ⇒ N(x, K) = 0

**2.** Обратное неверно: существуют K и x, для которых N(x, K) = 0, хотя x не является структурно пустым. То есть фактическая пустота может наступать без структурной.

**3.** Конкретный пример: K = 10, x = 9. Здесь

НОД(9, 1) = 1, и 1 | 10

то есть x = 9 не является структурно пустым для K = 10. Тем не менее

N(9, 10) = 0

**4.** При K = 10 десяток x = 9 является единственным фактически пустым десятком:

N(x, 10) > 0 для всех x ∈ {1, 2, …, 8}

**5.** Причина фактической пустоты x = 9 при K = 10: все кандидаты по u, дающие целое v ∈ {0, …, 9}, отсекаются условием A < B. То есть фильтр A < B, а не отсутствие решений сравнения, обнуляет N(9, 10).

## Доказательство

**Пункт 1.** Если x структурно пуст, то для любого y ∈ {0, …, 9} сравнение u·y ≡ K (mod x) неразрешимо. По горизонтальной теореме, для A = 10·x + y не существует целого v, при котором B = 10·u + v было бы двузначным и удовлетворяло Δ(A, B) = K. Значит, нет ни одной пары (A, B) ∈ S<sub>lt</sub>(K) с таким A. Суммируя по y, получаем N(x, K) = 0.

**Пункт 2.** Достаточно предъявить пример. Ниже — пункт 3.

**Пункт 3.** Проверим перебором все y ∈ {0, 1, …, 9} для x = 9, K = 10. Сравнение имеет вид

u·y ≡ 10 ≡ 1 (mod 9)

Разрешимость по u есть только при НОД(9, y) | 1, то есть при НОД(9, y) = 1. Это выполнено для y ∈ {1, 2, 4, 5, 7, 8}. Для каждого такого y найдём все u ∈ {1, …, 9}, дающие целое v = (u·y − 10) / 9, и проверим условия v ∈ {0, …, 9} и A < B.

**y = 1.** u ≡ 1 (mod 9), u ∈ {1}. v = (1 − 10)/9 = −1. Не годится (v < 0).

**y = 2.** 2u ≡ 1 (mod 9), u ≡ 5 (mod 9), u ∈ {5}. v = (10 − 10)/9 = 0. A = 92, B = 50. A < B не выполнено.

**y = 4.** 4u ≡ 1 (mod 9), u ≡ 7 (mod 9), u ∈ {7}. v = (28 − 10)/9 = 2. A = 94, B = 72. A < B не выполнено.

**y = 5.** 5u ≡ 1 (mod 9), u ≡ 2 (mod 9), u ∈ {2}. v = (10 − 10)/9 = 0. A = 95, B = 20. A < B не выполнено.

**y = 7.** 7u ≡ 1 (mod 9), u ≡ 4 (mod 9), u ∈ {4}. v = (28 − 10)/9 = 2. A = 97, B = 42. A < B не выполнено.

**y = 8.** 8u ≡ 1 (mod 9), u ≡ 8 (mod 9), u ∈ {8}. v = (64 − 10)/9 = 6. A = 98, B = 86. A < B не выполнено.

Для y ∈ {0, 3, 6, 9} имеем НОД(9, y) ∈ {9, 3, 3, 9}, и ни одно из этих чисел не делит 10, значит, сравнение неразрешимо. Итого N(9, 10) = 0. При этом x = 9 не является структурно пустым, поскольку y = 1 даёт НОД(9, 1) = 1 | 10.

**Пункт 4.** Для каждого x ∈ {1, …, 8} достаточно предъявить хотя бы одну пару (A, B) ∈ S<sub>lt</sub>(10) с десятком x. Примеры берутся из таблицы:

    x = 1:  A = 12,  B = 50
    x = 2:  A = 22,  B = 50
    x = 3:  A = 32,  B = 50
    x = 4:  A = 42,  B = 50
    x = 5:  A = 55,  B = 64
    x = 6:  A = 62,  B = 81
    x = 7:  A = 73,  B = 82
    x = 8:  A = 82,  B = 91

Во всех случаях Δ(A, B) = 10 и A < B, поэтому N(x, 10) ≥ 1. Вместе с пунктом 3 это даёт: множество фактически пустых десятков при K = 10 равно {9}.

**Пункт 5.** Из перебора в пункте 3 видно: для каждого y, при котором сравнение разрешимо, единственное (или все) u дают либо v < 0, либо B < A. То есть ограничение A < B отсекает все кандидаты. Если убрать фильтр A < B, для x = 9 появятся решения: например, (92, 50), (94, 72), (95, 20), (97, 42), (98, 86). Все они имеют A > B. Значит, именно фильтр A < B обнуляет N(9, 10).

## Следствие для K = 10

При K = 10:

1. Структурно пустых десятков нет. Действительно, y = 1 даёт НОД(x, 1) = 1, а 1 делит любое K. Значит, для любого x ∈ {1, …, 9} существует y, при котором сравнение разрешимо. Структурная пустота при K = 10 невозможна ни для какого x.

2. Фактически пустой десяток ровно один: x = 9.

3. Сумма N(x, 10) по x ∈ {1, …, 9} равна 60, что совпадает с числом строк таблицы.

## Обобщение на произвольное K

**Предложение.** Для любого целого K структурно пустых десятков не существует.

**Доказательство.** Для любого x ∈ {1, …, 9} возьмём y = 1. Тогда НОД(x, 1) = 1, а 1 делит любое целое K. Значит, условие структурной пустоты не выполняется ни для какого x. Что и требовалось.

**Следствие.** Пункт 1 теоремы для непустого множества K не даёт примеров: структурная пустота никогда не наступает. Вся фактическая пустота — следствие ограничений A < B и v ∈ {0, …, 9}, а не отсутствия решений сравнения.

## Что здесь ново, а что стандартно

**Стандартно:**

- Критерий разрешимости линейного сравнения через НОД — классика теории чисел.
- Пункт 1 теоремы — прямое следствие горизонтальной теоремы.

**Относительно ново (в контексте):**

- Явное разделение структурной и фактической пустоты.
- Доказательство того, что структурная пустота невозможна ни для какого K (из-за y = 1).
- Конкретный разбор x = 9 при K = 10 с полным перебором и указанием, что именно фильтр A < B обнуляет N.
- Наблюдение, что при K = 10 ровно один десяток фактически пуст.

**Вывод.** Это **не самостоятельная теорема** в строгом смысле: пункт 1 — следствие горизонтальной теоремы, пункты 3–4 — результат перебора, пункт 5 — объяснение перебора. Но разделение двух типов пустоты и доказательство невозможности структурной пустоты — это содержательное уточнение, которого в горизонтальной теореме не было. Для банка теорем её стоит хранить с пометкой «уточнение к горизонтальной теореме», а не как независимый результат.

## Практическая польза

1. Позволяет **не искать структурно пустые десятки**: их не существует ни при каком K.
2. Объясняет, почему в таблице для K = 10 нет строк с x = 9: не потому, что сравнение неразрешимо, а потому, что все решения имеют A > B.
3. Даёт шаблон для анализа других K: если для некоторого x все кандидаты отсекаются фильтром A < B, то x фактически пуст, хотя структурно жив.
