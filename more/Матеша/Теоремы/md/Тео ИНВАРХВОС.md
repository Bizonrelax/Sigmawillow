# 2. Теорема: хвост удовлетворяет 9·S<sub>T</sub> − Q<sub>T</sub> = 6q − 8

Смотрю на хвосты всех крупных A в данных и замечаю закономерность. Проверю её и докажу.

**Обозначения.** Пусть крупная пара имеет B = {7 × p, 6 × q}, где q = n − p. Пусть A = {9 × a} ∪ T, где T — хвост (цифры 1 … 8, ни одной девятки). Через S<sub>T</sub> и Q<sub>T</sub> обозначим сумму и сумму квадратов цифр хвоста.

**Проверка по данным.**

Все двенадцать совпадений. Это не совпадение, а тождество. Докажу.

**Теорема (инвариант хвоста).** В любой крупной паре A, B с B = {7 × p, 6 × q}, q = n − p, и A = {9 × a} ∪ T выполняется

    9·S_T − Q_T = 6q − 8

**Доказательство.** Из определений:

    S_A = 6n + p − 1 = 7n − q − 1

    Q_A = 48n + 15p − 1 = 63n − 15q − 1

С другой стороны, S_A = 9a + S<sub>T</sub>, Q_A = 81a + Q<sub>T</sub>. Тогда

    9·S_A − Q_A = 9·(9a + S_T) − (81a + Q_T) = 81a + 9·S_T − 81a − Q_T = 9·S_T − Q_T

С другой стороны, из формул через n и q:

    9·S_A − Q_A = 9·(7n − q − 1) − (63n − 15q − 1) = 63n − 9q − 9 − 63n + 15q + 1 = 6q − 8

Сравнивая обе формы, получаем 9·S<sub>T</sub> − Q<sub>T</sub> = 6q − 8. ∎

**Почему это важно.** Величина 9·S<sub>T</sub> − Q<sub>T</sub> зависит только от q, но не от n и не от хвоста. Значит, при данном q любой допустимый хвост обязан лежать на одной кривой. Хвосты — не свободные объекты, а решения одного уравнения.

# 3. Следствие: хвост должен попадать в правильный остаток по модулю 9

Из S<sub>A</sub> = 9a + S<sub>T</sub> следует, что S<sub>T</sub> ≡ S<sub>A</sub> (mod 9), то есть

    S_T ≡ 7n − q − 1 (mod 9)

Значит, для заданных q и n подходит только хвост с определённым остатком суммы по модулю 9. Поскольку 7·4 ≡ 1 (mod 9), это переписывается как

    n ≡ 4·(S_T + q + 1) (mod 9)

**Пример.** При q = 7 в данных встречаются хвосты:

- {7, 4}, S<sub>T</sub> = 11 ≡ 2 (mod 9), значит n ≡ 4·10 ≡ 4 (mod 9): работает при n = 40 (40 ≡ 4 mod 9). Не работает при n = 36 (36 ≡ 0).
- {8, 8, 3}, S<sub>T</sub> = 19 ≡ 1 (mod 9), n ≡ 4·9 ≡ 0 (mod 9): работает при n = 36.
- {8, 8, 6}, S<sub>T</sub> = 22 ≡ 4 (mod 9), n ≡ 4·12 ≡ 3 (mod 9): работает при n = 30 (30 ≡ 3 mod 9).
- {5, 2}, S<sub>T</sub> = 7 ≡ 7 (mod 9), n ≡ 4·15 ≡ 6 (mod 9): работает при n = 24 (24 ≡ 6 mod 9).

Все совпадает. Хвост выбирается по остатку n по модулю 9.

# 4. Что это объясняет в n = 32

n = 32 ≡ 5 (mod 9). Для каждого q нужен S<sub>T</sub> ≡ 7·5 − q − 1 = 34 − q ≡ 7 − q (mod 9):

- q = 4: S<sub>T</sub> ≡ 3 (mod 9).
- q = 5: S<sub>T</sub> ≡ 2 (mod 9).
- q = 6: S<sub>T</sub> ≡ 1 (mod 9).
- q = 7: S<sub>T</sub> ≡ 0 (mod 9).
- q = 9: S<sub>T</sub> ≡ 7 (mod 9).

Для q = 7 при S<sub>T</sub> ≡ 0 (mod 9) и 9·S<sub>T</sub> − Q<sub>T</sub> = 34 ближайший кандидат — S<sub>T</sub> = 9, Q<sub>T</sub> = 47. Но 47 не реализуется как сумма квадратов цифр 1 … 8 с суммой 9 (проверил: возможные варианты дают 27, 29, 31, 33, 35, 39, 41, 43, 45, 51 и т.д., но не 47). Аналогично для S<sub>T</sub> = 18, 27, … решения либо не существуют, либо дают не единственное A. Похоже, что при n ≡ 5 (mod 9) **ни один хвост не проходит**, поэтому крупных чистых II нет. Это гипотеза, требующая проверки при других n ≡ 5 (mod 9): n = 23, 41, 50.

# 6. Следующий шаг: полный список допустимых хвостов

Код ниже перебирает все хвосты для каждого q ∈ {4, 5, 6, 7, 9} и печатает, для каких остатков n по модулю 9 они работают. Это даст **полную карту** крупных чистых II: для каждого q — какие хвосты есть и при каких n они применимы.

Новая ячейка. Скопируй целиком, запусти. Работает независимо от предыдущих ячеек.

```python
def all_tails_with_sum_sq(s, q_sq, max_digit=8):
    """Все мультимножества цифр 1..8 с суммой s и суммой квадратов q_sq."""
    results = []
    def rec(remaining_sum, remaining_q, max_d, path):
        if remaining_sum == 0 and remaining_q == 0:
            results.append(tuple(path))
            return
        if remaining_sum == 0 or remaining_q == 0:
            return
        for d in range(min(max_d, remaining_sum), 0, -1):
            if d * d > remaining_q:
                continue
            path.append(d)
            rec(remaining_sum - d, remaining_q - d * d, d, path)
            path.pop()
    rec(s, q_sq, max_digit, [])
    return results


def enumerate_all_tails(q_values=(4, 5, 6, 7, 9), max_s=60):
    for q in q_values:
        target = 6*q - 8
        print(f"\n===== q = {q}, 9·S_T − Q_T = {target} =====")
        print(f"{'s':>3} | {'Q_T':>4} | n≡mod9 | примеры хвостов")
        print("-" * 80)
        total_tails = 0
        for s in range(1, max_s + 1):
            q_T = 9*s - target
            if q_T < s or q_T > 81*s:
                continue
            tails = all_tails_with_sum_sq(s, q_T)
            if not tails:
                continue
            n_mod = (4 * (s + q + 1)) % 9
            sample = tails[:3]
            total_tails += len(tails)
            print(f"{s:>3} | {q_T:>4} | {n_mod:>7} | {sample}{'...' if len(tails) > 3 else ''}")
        print(f"Всего хвостов для q={q}: {total_tails}")


enumerate_all_tails()
```

**Что смотреть.** Для каждого q получится таблица: при каких s существует хвост, какой у него остаток n mod 9, сколько всего хвостов. По этой карте можно предсказать, при каких n появятся крупные чистые II и с какими W. И станет видно, почему n ≡ 5 mod 9 (если гипотеза подтвердится) всегда даёт пусто — просто потому, что для нужных остатков S_T не находится реализуемого хвоста.
