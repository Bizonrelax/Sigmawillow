Ти, хороший вопрос. Сначала важное уточнение: **первая теорема уже была сформулирована для произвольного K**, а не только для K = 10. Таблица была для K = 10, но сама теорема — общая. Так что «расширять» её в этом смысле не нужно.

Но есть то, чего в первой теореме **не было** и что действительно расширяет картину: **для каких K вообще существуют решения**. Первая теорема говорит: «если решения есть, то они устроены так». Она молчит о том, **при каких K решения есть**. Вот это и можно добавить.

Ниже — новая теорема. Формат тот же: вариант D плюс `<sub>` там, где нужны индексы.

---

# Теорема о диапазоне допустимых K

## Обозначения

Двузначные числа:

    A = 10·x + y
    B = 10·u + v

где

    x, u ∈ {1, 2, …, 9}
    y, v ∈ {0, 1, …, 9}

Перекрёстная разность:

    Δ(A, B) = y·u − x·v

Через S(K) обозначим множество всех упорядоченных пар (A, B) двузначных чисел, для которых Δ(A, B) = K.

## Формулировка

**Теорема.** Множество всех целых K, для которых S(K) непусто, в точности равно отрезку

−81 ≤ K ≤ 81

То есть:

**1.** Если |K| > 81, то S(K) пусто.

**2.** Если |K| ≤ 81, то S(K) непусто.

**3.** Более того, для каждого K ∈ [0, 81] существует решение с x = 1 и u = 9, то есть с первым числом из интервала 10 ≤ A ≤ 19 и вторым числом из интервала 90 ≤ B ≤ 99.

**4.** Для каждого K ∈ [−81, 0) решение получается из решения для −K перестановкой пары:

если Δ(A, B) = −K, то Δ(B, A) = K

## Доказательство

**Пункт 1.** Оценим Δ(A, B) сверху и снизу. Максимум y·u достигается при y = 9, u = 9 и равен 81. Минимум x·v достигается при x = 1, v = 0 и равен 0. Поэтому

Δ(A, B) ≤ 81 − 0 = 81

Аналогично, минимум y·u равен 0 (при y = 0 или u = 0), максимум x·v равен 9·9 = 81 (при x = 9, v = 9). Поэтому

Δ(A, B) ≥ 0 − 81 = −81

Значит, при |K| > 81 решений нет.

**Пункт 2.** Достаточно построить решение для каждого K ∈ [0, 81]. Для K < 0 решение получается перестановкой.

Зафиксируем K ∈ [0, 81]. Положим

    y = ceil(K / 9)   при K > 0
    y = 1             при K = 0

где ceil — округление вверх до целого. Тогда

    1 ≤ y ≤ 9

поскольку K ≤ 81, и

    9·(y − 1) < K ≤ 9·y

Определим

    v = 9·y − K

Из неравенства 9·(y − 1) < K следует

    v = 9y − K < 9y − 9(y − 1) = 9

то есть v ≤ 8 при K > 0. При K = 0 имеем y = 1 и v = 9. В обоих случаях

    0 ≤ v ≤ 9

Теперь положим

    x = 1,   u = 9

Тогда

    A = 10·1 + y = 10 + y
    B = 10·9 + v = 90 + v

Оба числа двузначные, поскольку 1 ≤ y ≤ 9 и 0 ≤ v ≤ 9. Вычислим Δ:

    Δ(A, B) = y·u − x·v = y·9 − 1·v = 9y − v = 9y − (9y − K) = K

Значит, (A, B) ∈ S(K). Пункт 2 доказан.

**Пункт 3.** Построение в пункте 2 как раз даёт x = 1 и u = 9 для каждого K ∈ [0, 81].

**Пункт 4.** Если Δ(A, B) = −K, то по свойству кососимметричности

Δ(B, A) = −Δ(A, B) = K

Значит, (B, A) ∈ S(K). Это даёт решение для K < 0 из решения для −K > 0.

## Следствие для первой теоремы

Первая теорема (о горизонтальных прогрессиях) описывает **структуру** S(K) при условии, что S(K) непусто. Настоящая теорема добавляет **условие непустоты**: S(K) непусто тогда и только тогда, когда |K| ≤ 81.

Вместе две теоремы дают полное описание:

1. Для |K| > 81 решений нет.
2. Для |K| ≤ 81 решения есть, и для каждого фиксированного A = 10x + y они образуют арифметическую прогрессию с шагом A / НОД(x, y), если НОД(x, y) делит K; иначе для данного A решений нет.

## Примеры

**K = 0.** y = 1, v = 9, x = 1, u = 9. A = 11, B = 99. Проверка: Δ = 1·9 − 1·9 = 0.

**K = 1.** y = 1, v = 8, x = 1, u = 9. A = 11, B = 98. Проверка: Δ = 1·9 − 1·8 = 1.

**K = 9.** y = 1, v = 0, x = 1, u = 9. A = 11, B = 90. Проверка: Δ = 1·9 − 1·0 = 9.

**K = 10.** y = 2, v = 8, x = 1, u = 9. A = 12, B = 98. Проверка: Δ = 2·9 − 1·8 = 10. (В таблице для K = 10 эта пара тоже есть — строка 5.)

**K = 72.** y = 8, v = 0, x = 1, u = 9. A = 18, B = 90. Проверка: Δ = 8·9 − 1·0 = 72.

**K = 80.** y = 9, v = 1, x = 1, u = 9. A = 19, B = 91. Проверка: Δ = 9·9 − 1·1 = 80.

**K = 81.** y = 9, v = 0, x = 1, u = 9. A = 19, B = 90. Проверка: Δ = 9·9 − 1·0 = 81.

**K = −10.** По пункту 4 берём решение для K = 10: A = 12, B = 98. Переставляем: A' = 98, B' = 12. Проверка: Δ = 8·1 − 9·2 = 8 − 18 = −10. (Заметим, что A' > B', то есть это решение с A > B.)

## Что здесь ново, а что стандартно

**Стандартно:**

- Оценка |Δ| ≤ 81 — прямое следствие диапазонов цифр.
- Кососимметричность Δ(B, A) = −Δ(A, B) — уже использовалась в теореме о симметрии.

**Относительно ново (в контексте):**

- Явное доказательство того, что **все** целые K от −81 до 81 достижимы, а не только некоторые.
- Конструктивная формула y = ceil(K/9), v = 9y − K, x = 1, u = 9, дающая решение для любого K ≥ 0.
- Связка с первой теоремой: первая теорема описывает структуру, эта — условие непустоты. Вместе они дают полное описание S(K).

**Вывод.** Это **самостоятельная теорема**, а не следствие первой. Первая теорема не говорит, при каких K решения есть; эта говорит. Они дополняют друг друга. Для банка теорем её стоит хранить как «теорему о диапазоне», отдельно от горизонтальной.

## Практическая польза

1. Позволяет **сразу отбрасывать** K вне отрезка [−81, 81]: для них таблица пуста, считать нечего.
2. Даёт **эталонное решение** для каждого K: x = 1, u = 9, y = ceil(K/9), v = 9y − K. Это удобно для проверки программ, генерирующих таблицы.
3. Показывает, что «горизонтальная теорема» и «теорема о диапазоне» — два независимых ингредиента полного описания: структура плюс непустота.
