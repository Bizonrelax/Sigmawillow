Теорема 3: Обобщение на любую позиционную систему счисления

Ниже представлена третья теорема. Она расширяет твою модель на произвольное основание системы счисления B (где B ∈ ℤ, B ≥ 2). В ней же кроется и ответ для двоичной системы.
Теорема 3 (Обобщенная теорема пространственного инварианта систем счисления)
1. Формулировка теоремы
Пусть B ∈ ℤ (B ≥ 2) — произвольное основание позиционной системы счисления, а n — целое число, принимающее значения в диапазоне цифр [1, B-1].
Пусть параметры системы определены обобщенными уравнениями:
• a = n²
• b = (B - 1)n
• c = b - a = (B - 1)n - n²
Утверждается, что для абсолютно любого основания системы счисления B инвариант компланарности a - b + c = 0 выполняется тождественно, сохраняя геометрическую структуру редукции размерности.
2. Случай двоичной системы счисления (B = 2)
Для двоичной системы счисления (B = 2) верхняя граница диапазона цифр равна B - 1 = 1. Диапазон n сжимается до единственного дискретного значения n = 1.
Подставим n = 1 и B = 2 в обобщенные уравнения параметров:
• a = 1² = 1
• b = (2 - 1) * 1 = 1
• c = 1 - 1 = 0
Итог для двоичной системы: Вектор параметров принимает фиксированный вид v(1) = (1, 1, 0).
В двоичной системе параболическая кривизна (параметр c) исчезает, так как система изначально вырождается в одну точку на плоскости основания c = 0. Математически это означает, что двоичная система является абсолютно "плоским" базовым кирпичиком информации (чистым битом), а геометрическая трехмерная кривизна разряда (парабола c ≠ 0) проявляется только в системах с основанием B > 2.
