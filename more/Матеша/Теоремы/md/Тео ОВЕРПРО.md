# Теорема о вертикальных прогрессиях

## Обозначения

Пусть K — целое число.

Рассматриваются двузначные числа:

    A = 10·x + y
    B = 10·u + v

где

    x, u ∈ {1, 2, …, 9}
    y, v ∈ {0, 1, …, 9}

то есть x и u — десятки, y и v — единицы.

Перекрёстная разность определяется как

    Δ(A, B) = y·u − x·v

Зафиксируем второе число B = 10·u + v и положим

    g' = НОД(u, v)

## Формулировка

**Теорема.** Пусть B = 10·u + v — двузначное число, g' = НОД(u, v), K — целое.

**1.** Равенство

    y·u − x·v = K

равносильно равенству

    u·A − x·B = K

**2.** Если g' не делит K, то для данного B не существует ни одного двузначного A, удовлетворяющего условию.

**3.** Если g' делит K, то все целые x, при которых y получается целым, образуют один класс вычетов по модулю u / g'. То есть если x₀ — одно такое значение, то все остальные имеют вид

    x = x₀ + t · (u / g'),    t ∈ ℤ

**4.** Для этих x соответствующие A и y равны

    A(t) = A₀ + t · (B / g')
    y(t) = y₀ + t · (v / g')

Поэтому при переходе от одного допустимого x к следующему:

    ΔA = B / g'
    Δy = v / g'

**5.** Произведения A·B также образуют арифметическую прогрессию:

    A(t)·B = A₀·B + t · (B² / g')

**6.** Если дополнительно наложить условие A < B и потребовать, чтобы A было двузначным, то допустимые t образуют конечный интервал целых чисел. Поэтому все решения для фиксированного B при A < B либо отсутствуют, либо образуют одну конечную арифметическую прогрессию.

## Доказательство

Имеем тождество:

    y·u − x·v
    = u·(10x + y) − x·(10u + v)
    = 10ux + uy − 10ux − xv
    = y·u − x·v

Значит,

    y·u − x·v = K   ⇔   u·A − x·B = K

Далее,

    u·A = x·B + K
    A = (x·B + K) / u

Чтобы A было целым, необходимо и достаточно, чтобы

    x·B ≡ −K (mod u)

Но B = 10u + v ≡ v (mod u), значит,

    x·v ≡ −K (mod u)

Линейное сравнение x·v ≡ −K (mod u) разрешимо тогда и только тогда, когда

    НОД(u, v) | K

то есть g' | K. При этом все решения по x образуют один класс вычетов по модулю u / g'.

Если x заменить на x + u / g', то

    A' = ((x + u/g')·B + K) / u
       = (x·B + K)/u + B/g'
       = A + B/g'

А для y:

    y' = A' − 10·x'
       = A + B/g' − 10·(x + u/g')
       = y + (B − 10u)/g'
       = y + v/g'

Наконец,

    A'·B = (A + B/g')·B = A·B + B²/g'

Ограничения 1 ≤ x ≤ 9, 0 ≤ y ≤ 9, A < B являются линейными неравенствами относительно x, поэтому внутри выбранного класса вычетов они вырезают конечный интервал. Теорема доказана.

## Замечание о симметрии с горизонтальной теоремой

Теорема о вертикальных прогрессиях полностью симметрична теореме о горизонтальных прогрессиях при замене

    A ↔ B
    x ↔ u
    y ↔ v
    g ↔ g'

Поэтому отдельного независимого доказательства по существу не требуется: достаточно сослаться на симметрию тождества

    y·u − x·v = u·A − x·B

которое инвариантно относительно одновременной перестановки (A, x, y) ↔ (B, u, v).

## Следствие для K = 10 (случай таблицы)

В таблице K = 10. Для фиксированного B = 10u + v решения возможны только если

    НОД(u, v) | 10

Поскольку НОД(u, v) ≤ 9, это значит

    НОД(u, v) ∈ {1, 2, 5}

Для каждого допустимого B первые числа A идут с шагом

    B / НОД(u, v)

а произведения A·B — с шагом

    B² / НОД(u, v)

## Примеры из таблицы

**B = 50**, НОД(5, 0) = 5:

    A    = 12, 22, 32, 42              (шаг 10)
    A·B  = 600, 1100, 1600, 2100       (шаг 500)

**B = 55**, НОД(5, 5) = 5:

    A    = 13, 24, 35, 46              (шаг 11)
    A·B  = 715, 1320, 1925, 2530       (шаг 605)

**B = 42**, НОД(4, 2) = 2:

    A    = 13, 34                      (шаг 21)
    A·B  = 546, 1428                   (шаг 882)

**B = 64**, НОД(6, 4) = 2:

    A    = 23, 55                      (шаг 32)
    A·B  = 1472, 3520                  (шаг 2048)

**B = 73**, НОД(7, 3) = 1:

    A    = 64                          (один элемент, шаг 73)

## Что даёт эта теорема по сравнению с горизонтальной

1. Горизонтальная теорема отвечает на вопрос: «какие B подходят к данному A и с каким шагом».
2. Вертикальная теорема отвечает на вопрос: «какие A подходят к данному B и с каким шагом».
3. Вместе они описывают таблицу как **двумерную решётку**: по строкам (фиксированное A) и по столбцам (фиксированное B) идут арифметические прогрессии, причём шаг по строке равен A/НОД(x, y), а шаг по столбцу — B/НОД(u, v).
4. Обе теоремы — не независимые результаты, а два «вида» одного и того же тождества. Это важно для банка теорем: их не нужно считать двумя разными открытиями, это одна теорема в двух координатах.

## Статус уникальности

Среди доступных источников прямого совпадения не найдено. Однако надо честно зафиксировать: это **симметричное переписывание** уже сформулированной горизонтальной теоремы, а не независимо новое утверждение. Для банка теорем её лучше хранить как «следствие симметрии», а не как отдельную теорему. Иначе банк будет раздут дублями.
