Теорема 2 (О граничной сингулярности и замкнутости дискретного цикла в десятичной системе счисления)
1. Введение и терминология
Настоящая теорема является развитием геометрического анализа десятичной позиционной системы счисления. Она исследует поведение внутренней геометрии числового разряда на его естественных арифметических границах. Физический смысл данной теоремы заключается в моделировании изолированных, саморегулирующихся дискретных систем (петель), где края числового диапазона создают естественные граничные условия.
2. Формулировка теоремы
Пусть задана дискретная геометрическая система параметров десятичного разряда, определенная в Теореме 1 (Тео ОРЕРАИКИ.md), где вектор состояния точки в трехмерном пространстве описывается как v(n) = (a, b, c) = (n², 9n, 9n - n²) для целых целых чисел n ∈.
Утверждается, что дискретная параболическая траектория, описываемая вектором v(n), является топологически замкнутой и изолированной внутри каждого разряда относительно оператора граничного зануления разностного параметра c на непрерывных границах области определения цифр.
3. Доказательство
Шаг 1. Анализ разностной квадратичной функции:
Параметр c(n) = 9n - n² представляет собой квадратичную функцию (перевернутую параболу), график которой направлен ветвями вниз. Найдем корни данной функции, приравняв её к нулю:
9n - n² = 0, что раскладывается как n * (9 - n) = 0.
Корнями уравнения являются точки n_0 = 0 (экстраполированная нижняя граница разряда, обозначающая пустой разряд) и n_1 = 9 (верхняя физическая граница цифр в десятичной системе счисления).
Шаг 2. Геометрия граничных состояний (Сингулярность):
Вычислим значения векторов параметров v(n) на этих границах:
• При n = 0: v(0) = (0², 9 * 0, 0) = (0, 0, 0) — точка полностью совпадает с началом координат.
• При n = 9: v(9) = (9², 9 * 9, 0) = (81, 81, 0) — точка лежит строго на плоскости основания c = 0.
Шаг 3. Схлопывание в петлю и изоляция разряда:
Обе граничные точки v(0) и v(9) имеют координату c = 0 и лежат строго на одной прямой линейной симметрии a = b в базовой плоскости (a, b).
Для любого промежуточного значения цифры (n от 1 до 8) параметр c > 0, что выводит геометрию в трехмерное пространство (приподнимает дугу параболы над плоскостью основания). Однако на краях диапазона система неизбежно возвращается обратно на базовую линию c = 0.
Это доказывает, что переход от первой цифры к последней внутри одного разряда образует геометрически замкнутую, самодостаточную петлю (дискретный цикл), которая изолирована от соседних разрядов граничным занулением параметра c.
Теорема доказана.
