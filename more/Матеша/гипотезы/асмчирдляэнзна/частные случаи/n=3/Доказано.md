# Теорема об асимметрии числа решений для трёхзначных чисел

## Обозначения

Рассматриваются трёхзначные числа в десятичной записи:

A = 100·a<sub>2</sub> + 10·a<sub>1</sub> + a<sub>0</sub>

B = 100·b<sub>2</sub> + 10·b<sub>1</sub> + b<sub>0</sub>

где

    a<sub>0</sub>, a<sub>1</sub>, a<sub>2</sub>, b<sub>0</sub>, b<sub>1</sub>, b<sub>2</sub> ∈ {0, 1, …, 9}
    a<sub>2</sub>, b<sub>2</sub> ∈ {1, 2, …, 9}

Индекс 0 соответствует единицам, 1 — десяткам, 2 — сотням.

## Определение перекрёстной разности

Для трёхзначных чисел перекрёстная разность определяется как сумма по всем парам разрядов:

Δ<sub>3</sub>(A, B) = (a<sub>0</sub>·b<sub>1</sub> − a<sub>1</sub>·b<sub>0</sub>) + (a<sub>0</sub>·b<sub>2</sub> − a<sub>2</sub>·b<sub>0</sub>) + (a<sub>1</sub>·b<sub>2</sub> − a<sub>2</sub>·b<sub>1</sub>)

В развёрнутом виде:

    Δ<sub>3</sub>(A, B) = a<sub>0</sub>·b<sub>1</sub> − a<sub>1</sub>·b<sub>0</sub>
                       + a<sub>0</sub>·b<sub>2</sub> − a<sub>2</sub>·b<sub>0</sub>
                       + a<sub>1</sub>·b<sub>2</sub> − a<sub>2</sub>·b<sub>1</sub>

**Замечание о связи с двузначным случаем.** Для двузначных чисел A = 10·x + y, B = 10·u + v формула из первой теоремы имеет вид

Δ<sub>2</sub>(A, B) = y·u − x·v

и получается из Δ<sub>3</sub> отбрасыванием старшего разряда: при a<sub>2</sub> = b<sub>2</sub> = 0 три слагаемых Δ<sub>3</sub> сворачиваются в одно. Таким образом, Δ<sub>3</sub> является прямым обобщением Δ<sub>2</sub> на случай трёх разрядов, а не новой формулой.

## Определение T<sub>3</sub>(K)

Через S<sub>3</sub>(K) обозначается множество всех упорядоченных пар (A, B) трёхзначных чисел, для которых

Δ<sub>3</sub>(A, B) = K

Через S<sub>3,lt</sub>(K) обозначается подмножество пар с A < B:

S<sub>3,lt</sub>(K) = { (A, B) ∈ S<sub>3</sub>(K) : A < B }

Через T<sub>3</sub>(K) обозначается мощность:

T<sub>3</sub>(K) = |S<sub>3,lt</sub>(K)|

То есть T<sub>3</sub>(K) — число пар трёхзначных чисел с A < B и Δ<sub>3</sub>(A, B) = K.

## Формулировка

**Теорема.** Для любого целого K ≠ 0, для которого хотя бы одна из величин T<sub>3</sub>(K) или T<sub>3</sub>(−K) положительна, выполнено

T<sub>3</sub>(K) ≠ T<sub>3</sub>(−K)

Другими словами: внутри множества S<sub>3</sub>(K) при K ≠ 0 никогда не бывает точного баланса между парами с A < B и парами с A > B.

**Следствие 1 (закон сохранения).** Сумма T<sub>3</sub>(K) по всем целым K равна числу всех пар трёхзначных чисел с A < B:

сумма по K от T<sub>3</sub>(K) = 404 550 = 900 · 899 / 2

**Следствие 2 (диапазон).** T<sub>3</sub>(K) = 0 при K < −162 и при K > 234. Внутри отрезка [−162, 234] величина T<sub>3</sub>(K) положительна ровно для 373 значений K.

**Следствие 3 (асимметрия носителя).** Отрезок, на котором T<sub>3</sub>(K) положительна, не симметричен относительно нуля:

левая граница:  −162
правая граница: +234

Это ещё одно проявление асимметрии, независимое от основного утверждения: асимметрично не только распределение значений T<sub>3</sub>, но и сам носитель.

## Доказательство

Доказательство компьютерное, исчерпывающим перебором.

**Шаг 1.** Множество всех пар (A, B) трёхзначных чисел с A < B имеет мощность

900 · 899 / 2 = 404 550

Это конечное множество. Его можно явно перечислить.

**Шаг 2.** Для каждой пары (A, B) из этого множества вычисляется Δ<sub>3</sub>(A, B) по формуле из раздела «Определение перекрёстной разности». Значение Δ<sub>3</sub>(A, B) лежит в отрезке [−243, 243], поскольку каждое из трёх слагаемых по модулю не превосходит 81. Значит, все пары разбиваются в дизъюнктное объединение по значениям K:

{ все пары с A < B } = объединение по K ∈ [−243, 243] от S<sub>3,lt</sub>(K)

**Шаг 3.** Программа `T_n_full_scan.py` (Python 3, без внешних библиотек) перечисляет все 404 550 пар, для каждой вычисляет Δ<sub>3</sub> и увеличивает счётчик T<sub>3</sub>[Δ<sub>3</sub>] на 1. Для ускорения коэффициенты b<sub>0</sub>, b<sub>1</sub>, b<sub>2</sub> предвычисляются один раз на каждое B, после чего Δ<sub>3</sub> вычисляется как линейная комбинация цифр A:

    Δ<sub>3</sub>(A, B) = a<sub>0</sub>·c<sub>0</sub> + a<sub>1</sub>·c<sub>1</sub> + a<sub>2</sub>·c<sub>2</sub>

где

    c<sub>0</sub> = b<sub>1</sub> + b<sub>2</sub>
    c<sub>1</sub> = b<sub>2</sub> − b<sub>0</sub>
    c<sub>2</sub> = −(b<sub>0</sub> + b<sub>1</sub>)

Это тождественное преобразование формулы, не меняющее результат.

**Шаг 4.** По завершении перебора программа проверяет:

1. Число итераций равно 404 550.
2. Сумма T<sub>3</sub>(K) по всем K равна 404 550.
3. Для каждого K ≠ 0, где хотя бы одно из T<sub>3</sub>(K), T<sub>3</sub>(−K) положительно, выполнено T<sub>3</sub>(K) ≠ T<sub>3</sub>(−K).

**Шаг 5.** Все три проверки пройдены. Поскольку множество пар конечно, а перебор всех пар выполнен полностью, утверждение «для всех K ≠ 0 с положительной хотя бы одной из величин T<sub>3</sub>(K), T<sub>3</sub>(−K) выполнено T<sub>3</sub>(K) ≠ T<sub>3</sub>(−K)» доказано.

Теорема доказана.

## Замечания о статусе доказательства

**Первое.** Это **компьютерное доказательство**. Оно опирается на корректность программы `T_n_full_scan.py`. Программа короткая (около 130 строк), проверяемая, без внешних библиотек, без плавающей точки. Риск ошибки низкий, но не нулевой. Для полной строгости нужен независимый аудит кода или формальная верификация — это стандартная практика для компьютерных доказательств.

**Второе.** Теорема **не обобщается автоматически** на числа с числом цифр n ≥ 4. Для n = 4 количество пар с A < B равно 40 495 500, это подъёмно для перебора, но требует более производительной реализации. Для n ≥ 5 перебор невозможен, и утверждение остаётся гипотезой.

**Третье.** Для K = 0 утверждение не формулируется: 0 = −0, и равенство T<sub>3</sub>(0) = T<sub>3</sub>(−0) тривиально. Поэтому в формулировке стоит K ≠ 0.

**Четвёртое.** Условие «хотя бы одна из величин T<sub>3</sub>(K), T<sub>3</sub>(−K) положительна» отсекает случай, когда обе величины равны нулю. Для таких K равенство T<sub>3</sub>(K) = T<sub>3</sub>(−K) = 0 выполнено тривиально, и оно не является содержательным. Внутри носителя [−162, 234] обе величины положительны не всегда (носитель не симметричен), поэтому формулировка с этим условием корректна.

## Связь с теоремой для двузначных чисел

Для n = 2 аналогичное утверждение доказано в теореме об асимметрии числа решений для перекрёстной разности двузначных чисел:

для всех K ≠ 0 с |K| ≤ 81 выполнено T<sub>2</sub>(K) ≠ T<sub>2</sub>(−K)

Формулировки для n = 2 и n = 3 совпадают по структуре: «T<sub>n</sub>(K) ≠ T<sub>n</sub>(−K) для всех K ≠ 0, где хотя бы одна из величин положительна». Различие только в носителе: для n = 2 это [−81, 81], для n = 3 это [−162, 234].

Таким образом, доказаны два частных случая общей гипотезы об асимметрии числа решений для n-значных чисел:

    n = 2:  доказано полным перебором (4005 пар)
    n = 3:  доказано полным перебором (404 550 пар)

Для n ≥ 4 общая гипотеза остаётся открытой.

## Что остаётся открытым

1. **Обобщение на n ≥ 4.** Перебор для n = 4 (40 495 500 пар) подъёмен, но не выполнен. Для n ≥ 5 нужен математический аргумент, а не перебор.

2. **Причина «дыр» в спектре.** Из 487 значений K в теоретической границе [−243, 243] достижимы только 373. Причина неизвестна. Это может быть связано с арифметическими ограничениями на Δ<sub>3</sub> (например, с делимостью на некоторые числа), но проверка не проводилась.

3. **Замкнутая формула для T<sub>3</sub>(K).** Как и для n = 2, замкнутой формулы нет. Есть только алгоритмическая (конечная сумма) и таблица значений.

4. **Аудит программы.** Независимая проверка `T_n_full_scan.py` не проводилась.

## Практическая польза

1. Даёт **доказанное утверждение** для n = 3: асимметрия T<sub>3</sub>(K) ≠ T<sub>3</sub>(−K) выполнена для всех K ≠ 0.
2. Устанавливает **асимметрию носителя**: [−162, 234] вместо симметричного [−243, 243]. Это отдельное наблюдение, которое может быть отправной точкой для дальнейших исследований.
3. Даёт **шаблон** для n = 4: та же программа с параметром `n = 4` запустит перебор четырёхзначных чисел.
4. Позволяет **проверять** другие реализации: сумма T<sub>3</sub>(K) должна равняться 404 550, а T<sub>3</sub>(24) должно быть 5438.
