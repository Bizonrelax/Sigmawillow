# Примитивные коллизии типа II: ядро и задача о стабилизации

Величина W определена в файле [Величина W.md](https://github.com/Bizonrelax/Sigmawillow/blob/bbf9f477768bdc2344d3f8697cd45186d758cbcb/more/%D0%9C%D0%B0%D1%82%D0%B5%D1%88%D0%B0/%D0%BE%D0%BF%D1%80%D0%B5%D0%B4%D0%B5%D0%BB%D0%B5%D0%BD%D0%B8%D1%8F/%D0%92%D0%B5%D0%BB%D0%B8%D1%87%D0%B8%D0%BD%D0%B0%20W.md) как W = (S² + Q) / 2, где S — сумма цифр, Q — сумма квадратов цифр.

Здесь уточняется понятие **примитивной коллизии типа II** и приводится частичный список таких коллизий. Полный список по данным перебора до n = 16 не восстановлен; его составление — первая часть задачи 1 из файла «Эмпирические закономерности величины W для n = 3 … 16».

## Определения

Пусть A — мультимножество цифр, то есть набор цифр 0 … 9, в котором порядок не важен, а повторения разрешены. Через |A| обозначим число цифр в наборе (размер набора).

Для набора A определим:

    S(A) = сумма всех цифр набора A

    Q(A) = сумма квадратов всех цифр набора A

    W(A) = (S(A)² + Q(A)) / 2

**Коллизия типа II** — это пара наборов A и B, для которых одновременно выполнены три условия:

1. W(A) = W(B);
2. S(A) ≠ S(B);
3. A не получается из B перестановкой цифр.

Условие 3 при разных S выполняется автоматически, поскольку перестановка не меняет S. Поэтому его можно не проверять отдельно.

**Примитивная коллизия типа II** — это коллизия типа II, в которой ни один из наборов A и B не содержит цифру 0.

## Почему нули не меняют коллизию

Добавление нуля к набору не меняет ни S, ни Q, а значит, не меняет и W. Поэтому если в коллизии типа II один из наборов содержит ноль, этот ноль можно удалить, и коллизия сохранится: равенство W останется, различие S останется, условие 3 останется. Следовательно, любая коллизия типа II с нулями получается из некоторой беcнулевой коллизии добавлением нулей к одному или обоим наборам.

Отсюда простое наблюдение: **примитивные коллизии типа II — это в точности беcнулевые коллизии типа II**. Они образуют «ядро», из которого добавлением нулей получаются все остальные коллизии типа II при любых n.

## Частичный список известных примитивных пар

В таблице собраны пять пар, которые встречаются в данных для n = 6 … 16. Для каждой пары указаны W, наборы, их суммы цифр и размеры.

| W  | Набор A | Набор B | S(A) | S(B) | \|A\| | \|B\| |
|---:|:--------|:--------|-----:|-----:|------:|------:|
| 16 | {4}     | {1,1,1,2} | 4  | 5    | 1     | 4     |
| 25 | {5}     | {1,2,3}   | 5  | 6    | 1     | 3     |
| 36 | {6}     | {1,1,1,1,1,1,1,1} | 6 | 8 | 1 | 8 |
| 49 | {7}     | {3,5}     | 7  | 8    | 1     | 2     |
| 81 | {9}     | {3,4,4}   | 9  | 11   | 1     | 3     |

**Проверка для W = 16.** Для набора {4}: S = 4, Q = 16, W = (16 + 16) / 2 = 16. Для набора {1,1,1,2}: S = 5, Q = 1 + 1 + 1 + 4 = 7, W = (25 + 7) / 2 = 16. Суммы различны (4 и 5), наборы не являются перестановками друг друга. Коллизия типа II, примитивная.

**Проверка для W = 25.** Для {5}: S = 5, Q = 25, W = (25 + 25) / 2 = 25. Для {1,2,3}: S = 6, Q = 1 + 4 + 9 = 14, W = (36 + 14) / 2 = 25. Суммы 5 и 6 различны. Примитивная.

**Проверка для W = 36.** Для {6}: S = 6, Q = 36, W = (36 + 36) / 2 = 36. Для восьми единиц: S = 8, Q = 8, W = (64 + 8) / 2 = 36. Суммы 6 и 8 различны. Примитивная.

**Проверка для W = 49.** Для {7}: S = 7, Q = 49, W = (49 + 49) / 2 = 49. Для {3,5}: S = 8, Q = 9 + 25 = 34, W = (64 + 34) / 2 = 49. Суммы 7 и 8 различны. Примитивная.

**Проверка для W = 81.** Для {9}: S = 9, Q = 81, W = (81 + 81) / 2 = 81. Для {3,4,4}: S = 11, Q = 9 + 16 + 16 = 41, W = (121 + 41) / 2 = 81. Суммы 9 и 11 различны. Примитивная.

## Как из примитивной пары получаются коллизии при больших n

Пусть A и B — примитивная пара, и пусть m = max(|A|, |B|). Для любого n ≥ m добавим к A ровно n − |A| нулей, а к B ровно n − |B| нулей. Получатся наборы A′ и B′ одинакового размера n. При этом S(A′) = S(A), Q(A′) = Q(A), значит W(A′) = W(A). Аналогично для B′. Следовательно, W(A′) = W(B′), S(A′) ≠ S(B′), и A′ не является перестановкой B′. Это коллизия типа II размера n.

**Пример.** Возьмём примитивную пару W = 16: A = {4}, B = {1,1,1,2}. Здесь m = 4. При n = 6 добавим к A пять нулей, к B два нуля:

    A′ = {0,0,0,0,0,4}

    B′ = {0,0,1,1,1,2}

Размеры обоих наборов равны 6. Суммы: S(A′) = 4, S(B′) = 5. Значения W: W(A′) = 16, W(B′) = 16. Это коллизия типа II при n = 6.

## Гипотеза о конечности ядра

**Гипотеза.** Существует конечное множество примитивных коллизий типа II, такое что любая коллизия типа II при любом n получается из одной из них добавлением нулей к одному или обоим наборам.

**Следствие.** Число значений W, у которых все сталкивающиеся наборы имеют попарно разные S (чистый тип II), ограничено сверху константой, не зависящей от n.

По данным перебора для n = 6 … 16 это число колеблется в коридоре 13 … 18, что согласуется с гипотезой. Однако полный список примитивных пар по этим данным не восстановлен: в таблице выше приведены только пять пар, а число значений W с чистым типом II при n = 16 равно 15. Значит, вероятно, существуют ещё примитивные пары, не попавшие в таблицу.

## Задача 1. Полный список примитивных пар

**Что нужно сделать.** (а) По данным перебора для n = 6 … 16 выписать все беcнулевые пары A, B с W(A) = W(B) и S(A) ≠ S(B), которые дают коллизии типа II при некотором n. (б) Убедиться, что этот список конечен и не зависит от n. (в) Доказать, что добавление нулей — единственный способ поднять примитивную пару на бо́льшую размерность.

**Почему это разрешимо.** Условие типа II — одно уравнение S(A)² + Q(A) = S(B)² + Q(B) на две пары величин. При фиксированных S(A) и S(B) оно квадратично по цифрам. Оценка числа решений в цифровом прямоугольнике — стандартная техника. Главная трудность — аккуратно показать, что «случайных» беcнулевых решений при больших n не появляется.
