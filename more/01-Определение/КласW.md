# 1. Почему отчёт неверный

Твой прогон дал `чистый I = 0` при всех n. Это невозможно: в сводной таблице для n = 16 стоит 3602. Значит, код считает не то, что нужно.

**В чём ошибка.** Код собирал список пар (S, Q) для каждого W и проверял, сколько там разных S. Но коллизия типа I — это когда **два разных мультимножества** имеют одинаковые (S, Q). А код считал каждую пару (S, Q) один раз, независимо от того, сколько мультимножеств её реализуют. Поэтому тип I не обнаруживался вообще, а «чистый II» раздувался: туда попадали все W, у которых хотя бы две разные пары (S, Q), даже если внутри какой-то пары сидело несколько мультимножеств.

**Что нужно считать.** Для каждой пары (S, Q) — число мультимножеств, которые её дают. Тогда:

- если у W ровно одна пара (S, Q) и она даёт ≥ 2 мультимножества — чистый I;
- если у W ≥ 2 пары (S, Q), все S различны и каждая пара даёт ровно одно мультимножество — чистый II;
- если у W ≥ 2 пары (S, Q) и хотя бы одна даёт ≥ 2 мультимножества — смешанный.

# 2. Исправленный код

Создай в Colab новую ячейку через «+код» и вставь целиком. Запуск — Shift+Enter или кнопка воспроизведения слева от ячейки.

```python
from collections import defaultdict

def classify_collisions(max_n, max_digit=9):
    """
    Для каждого n от 3 до max_n считает число W с чистым типом I,
    чистым типом II и смешанным.
    """
    # dp[k][(S,Q)] = min(2, число мультимножеств размера k)
    dp = [defaultdict(int) for _ in range(max_n + 1)]
    dp[0][(0, 0)] = 1
    for d in range(1, max_digit + 1):
        for k in range(max_n):
            for (S, Q), c in list(dp[k].items()):
                key = (S + d, Q + d * d)
                new_c = dp[k + 1].get(key, 0) + c
                dp[k + 1][key] = 2 if new_c >= 2 else new_c

    # total[n][(S,Q)] = min(2, sum_{k=0}^{n} dp[k][(S,Q)])
    total = [defaultdict(int) for _ in range(max_n + 1)]
    running = defaultdict(int)
    for n in range(max_n + 1):
        for key, c in dp[n].items():
            new_c = running.get(key, 0) + c
            running[key] = 2 if new_c >= 2 else new_c
        total[n] = dict(running)

    print(f"{'n':>3} | {'чистый I':>9} | {'чистый II':>10} | {'смешанный':>10} | {'W с коллизией':>14}")
    print("-" * 60)
    for n in range(3, max_n + 1):
        W_to_S = defaultdict(dict)
        for (S, Q), c in total[n].items():
            W = (S * S + Q) // 2
            prev = W_to_S[W].get(S, 0)
            new_c = prev + c
            W_to_S[W][S] = 2 if new_c >= 2 else new_c
        pure_I = pure_II = mixed = 0
        for W, S_counts in W_to_S.items():
            M = sum(S_counts.values())
            if M < 2:
                continue
            if len(S_counts) == 1:
                pure_I += 1
            elif all(c == 1 for c in S_counts.values()):
                pure_II += 1
            else:
                mixed += 1
        total_coll = pure_I + pure_II + mixed
        print(f"{n:>3} | {pure_I:>9} | {pure_II:>10} | {mixed:>10} | {total_coll:>14}")


classify_collisions(20)
```

**Что должно получиться.** Для n = 3: 14, 17, 2. Для n = 16: 3602, 15, 4225. Если совпало — код верный. После этого можно поставить `classify_collisions(30)` и посмотреть, растёт ли «чистый II» дальше. По твоему первому прогону (где считались пары, а не W) видно, что пары растут как S². Но чистые II — это другая величина, она может вести себя иначе.

# 3. Главное действие: подтверждение

Ты не ошибаешься. Величина

    W(A) = Σ dᵢ·dⱼ  по всем 1 ≤ i ≤ j ≤ n

— это в точности сумма всех произведений пар цифр с повторениями, включая квадраты. В терминах симметрических многочленов это **полный однородный симметрический многочлен степени 2**, обозначается h₂. Он выражается через суммы степеней:

    h₂ = (p₁² + p₂) / 2

где p₁ = S — сумма цифр, p₂ = Q — сумма квадратов. Тождество W = (S² + Q) / 2 — это частный случай.

**Почему это важно.** Коллизия W(A) = W(B) означает равенство p₁² + p₂ у двух наборов. Тип I — это когда p₁ и p₂ совпадают по отдельности (задача Пруэ–Тарри–Эскотта степени 2). Тип II — когда p₁ различаются, но комбинация p₁² + p₂ совпадает. Так что «главное странное действие» имеет точное имя: h₂. Это не самодельная конструкция, а стандартный объект.

# 4. Классификация проблем

## 4.1. Объекты и отношения

**Объекты.**

- **Мультимножество** — неупорядоченный набор цифр 0 … 9 с повторениями.
- **Размер** n — число цифр в наборе.
- **S(A)** — сумма цифр.
- **Q(A)** — сумма квадратов цифр.
- **W(A)** — (S² + Q) / 2.
- **Пара (S, Q)** — класс эквивалентности мультимножеств с одинаковыми S и Q.
- **Значение W** — число, в которое отображается набор.

**Отношения.**

- **Коллизия** — W(A) = W(B) для разных мультимножеств A, B.
- **Тип I** — S(A) = S(B) и Q(A) = Q(B).
- **Тип II** — S(A) ≠ S(B).
- **Примитивная** — ни A, ни B не содержат 0.
- **Непримитивная** — хотя бы один содержит 0; получается из примитивной добавлением нулей.
- **Чистый I** — все коллизии для данного W имеют тип I.
- **Чистый II** — все коллизии для данного W имеют тип II.
- **Смешанный** — есть оба типа.

## 4.3. Статусы

Кроме трёх, которые ты назвал, есть ещё. Полный список:

1. **Определение** — соглашение о термине, не утверждение.
2. **Обозначение** — соглашение о символе.
3. **Обнаружено** — замечено в данных, но ещё не сформулировано точно.
4. **Сформулировано** — точное утверждение записано, но не проверено и не доказано.
5. **Эмпирически подтверждено** — проверено полным перебором до некоторой границы n ≤ N.
6. **Гипотеза** — сформулировано, считается верным, доказательства нет.
7. **Частично доказано** — доказано для части случаев (например, для чётных n или для малых n).
8. **Доказано** — есть полное математическое доказательство.
9. **Опровергнуто** — найден контрпример.
10. **Открыто** — сформулировано, ни доказано, ни опровергнуто.
11. **Контрпример** — конкретный случай, опровергающий утверждение.
12. **Теорема** — доказанное утверждение, главное в разделе.
13. **Лемма** — вспомогательное доказанное утверждение.
14. **Следствие** — вывод из теоремы.

Для твоей работы полезно различать 5 и 6: «эмпирически подтверждено» — это факт о конечных данных, «гипотеза» — универсальное утверждение. Смешивать нельзя.

# 5. Напоминание про теги и отступы

Коротко, чтобы держать в голове при каждой формуле.

1. **Без индексов** — блок с отступом 4 пробела.
2. **С индексами** — только в строку, не в блок.
3. **Цифры-индексы** — Unicode: ₁ ₂ ₃ ₄ ₅ ₆ ₇ ₈ ₉ ₀. Без тегов.
4. **Буквенные индексы** — Unicode, если есть: ₐ ₑ ᵢ ⱼ ₖ ₗ ₘ ₙ ₒ ₚ ᵣ ₛ ₜ ᵤ ᵥ ₓ. Иначе `<sub>` / `<sup>`.
5. **Внутри `<sub>` и `<sup>`** символы `<` и `>` писать как `&lt;` и `&gt;`.
6. **Главная ошибка** — `<sub>` или `<sup>` внутри блока с отступом 4 пробела. GitHub покажет теги буквально. Так нельзя.
7. **Перед отправкой** — пробежать глазами: нет ли тегов внутри отступов.
