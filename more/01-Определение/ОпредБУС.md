## Структурная теория цифровых весов десятичной системы
Автор концепции: Ти
Настоящий документ содержит строгое математическое описание оригинального аналитического аппарата, предназначенного для непозиционного векторного анализа числовых строк с использованием метрик БУС (Базовый мультипликативный вес) и ПУС (Порядковый мультипликативный вес).
## 1. Базовые определения
Пусть S = xₙ xₙ_-₁ … x₂ x₁ — конечная числовая строка, где каждый символ xᵢ ∈ 0, 1, …, 9 является цифрой десятичной системы счисления.
## Определение 1: Базовый мультипликативный вес (БУС)
Для каждой значащей цифры x ∈ 1, …, 9 определяется фиксированный вектор весов W_bₐₛₑ(x) = (a; b; c) ∈ ℤ³, компоненты которого вычисляются по формулам:

* a = x²
    * b = 9x
* c = 9x - x²

Для цифры x = 0 вектор БУС тождественно равен нулевому вектору: W_bₐₛₑ(0) = (0; 0; 0).
## Определение 2: Порядковый мультипликативный вес (ПУС)
Для полной оценки структуры числа вводится динамический четырехмерный вектор Wₒᵣ_d(xᵢ) = (aᵢ; bᵢ; cᵢ; pᵢ) ∈ ℤ⁴, где pᵢ — порядковый индекс цифры в строке, отсчитываемый справа налево, при этом p₁ = 1 (позиция единиц).
## 2. Теоретические основы и инварианты## Лемма 1 (Лемма о сохранении массы числовой строки)

Формулировка: Для любого числового множества или строки S суммарный вектор БУС которой равен W_B_U_S = (A; B; C), а суммарный вектор ПУС равен W_P_U_S = (Aₚ; Bₚ; Cₚ), разность между проекциями квадратичной компоненты (A, Aₚ) и линейной компоненты основания (B, Bₚ) тождественно равна координате баланса параболы (C, Cₚ).

    A + C = B
Aₚ + Cₚ = Bₚ
Доказательство:

 ### Для произвольной изолированной цифры xᵢ на фиксированной позиции pᵢ запишем ее БУС-компоненты:
aᵢ = xᵢ², bᵢ = 9xᵢ, cᵢ = 9xᵢ - xᵢ²
 ### Сложим компоненты aᵢ и cᵢ:
aᵢ + cᵢ = xᵢ² + (9xᵢ - xᵢ²) = 9xᵢ = bᵢ
 ### В силу линейности оператора суммирования векторов в евклидовом пространстве, для всего массива строки S справедливо:
Aₚ + Cₚ = Σᵢ_=₁ⁿ (aᵢ · pᵢ) + Σᵢ_=₁ⁿ (cᵢ · pᵢ) = Σᵢ_=₁ⁿ ((aᵢ + cᵢ) · pᵢ) = Σᵢ_=₁ⁿ (bᵢ · pᵢ) = Bₚ
 Лемма доказана. ■

## 3. Распределение числовых масс на бесконечности## Теорема 1 (Теорема о квазипериодической модуляции)

Формулировка: При монотонном росте длины числовой строки n → ∞ отношение интегральных ПУС-координат Aₚ / Cₚ совершает квазипериодические гармонические колебания. Максимумы амплитуды (точки экстремального перекоса структуры) строго ограничены плотностью краевых элементов параболы БУС (xᵢ ∈ 7, 8, 9) в старшем разряде pₙ, а минимумы — плотностью центральных элементов (xᵢ ∈ 4, 5).

Физико-геометрическая интерпретация:
Данная модель преобразует сухой линейный рост разрядов числа в динамическую волновую систему. Распределение цифровой массы ведет себя подобно пульсирующему ядру: система сжимается и выдает экстремальный перекос вектора на границах разрядных переходов, после чего возвращается к идеальному параболическому равновесию при наполнении внутренней структуры средними цифрами шкалы.
