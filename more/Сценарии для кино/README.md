# Сценарии для кино

Папка содержит сценарии и концепты для фильмов и анимации.

## Проекты

### Half-Life: Episode Three (фанатский сценарий)
- Путь: `half-life game/`
- Жанр: научная фантастика, триллер
- Основа: фанатское продолжение Half-Life 2
- **Важно**: персонажи и мир принадлежат Valve, это fan fiction

### Хасиб и Царица Змей (оригинальный сценарий)
- Путь: `Хасиб и Царица Змей/`
- Жанр: сказка, драма, приключения
- Основа: мотивы "Тысячи и одной ночи"
- Особенность: визуализация эмоций через "Индикатор Чувств" (Сигил)
