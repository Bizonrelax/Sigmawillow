# Существенные коллизии величины W для n = 3 … 10

Величина W определена в файле [Величина W.md](https://github.com/Bizonrelax/Sigmawillow/blob/bbf9f477768bdc2344d3f8697cd45186d758cbcb/more/%D0%9C%D0%B0%D1%82%D0%B5%D1%88%D0%B0/%D0%BE%D0%BF%D1%80%D0%B5%D0%B4%D0%B5%D0%BB%D0%B5%D0%BD%D0%B8%D1%8F/%D0%92%D0%B5%D0%BB%D0%B8%D1%87%D0%B8%D0%BD%D0%B0%20W.md) как W = (S² + Q) / 2.

**Существенная коллизия** — пара n-значных чисел A ≠ B, не получающихся друг из друга перестановкой цифр, с W(A) = W(B). Эквивалентно: два разных мультимножества цифр (размера n, не все нули) с одинаковым W.

- **Тип I**: все классы коллизии имеют одинаковую S (это PTE-решения степени 2).
- **Тип II**: все классы имеют попарно разные S.
- **Смешанный**: часть классов совпадает по S, часть — нет.
