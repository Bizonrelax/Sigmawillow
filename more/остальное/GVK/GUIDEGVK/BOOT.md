### BOOT.md — БУТСТРАП ОКРУЖЕНИЯ (C3)

Грузится только ролями, которым нужен инструмент сборки или git-запись: DEV, CLEANER, FIRST, CLOSER, FIREFIGHTER, TESTER, COMPLIANCE, TERMINATOR. Роли без инструмента (REVIEWER, OBSERVER, PLANNER_TEST, TZFIX, WISH, TERMINATOR2) этот модуль не грузят: выжимка C3 в ядре им достаточна.


Стек берётся из `GVK/PEP.json` → `stack`. Роли без инструмента сборки (REVIEWER, OBSERVER, PLANNER_TEST, TERMINATOR2) пункт пропускают. Остальные выполняют общую часть и **только блок своего стека**, один вызов. Платные инструменты не покупать и не требовать от владельца (ST1).

C3.0. Общая часть, любой стек:

```bash
cat > /opt/env.sh <<'EOF'
[ -f /opt/.t ] && T=$(cat /opt/.t)
AUTH="Authorization: Basic $(printf 'x-access-token:%s' "$T" | base64 -w0)"
EOF
git config --global user.name Bizonrelax
git config --global user.email bizonrelax79426315@gmail.com
git config --global --add safe.directory '*'
```

C3.1. Блок своего стека. Команды установки и проверки инструмента лежат в файле каркаса своего стека: java — `SKEL_JAVA.md` K2.0, python — `SKEL_PY.md` K6.0, прочие — `SKEL_OTHER.md` K8.0. Загрузи только свой файл и выполни его блок бутстрапа: это факт работы, а не чтение «на всякий случай». Вывод обязан показать версию инструмента (java 21 и Maven; Python 3.11+ и pip). Не показал — отчёт о причине, код не писать. Платные инструменты не покупать (ST1), Anaconda `defaults` не использовать (ST4). Windows-поставку локально не собирать: её собирает CI (W9).

C3.2. Каждая последующая команда начинается с `. /opt/env.sh`: оболочка между вызовами может быть новой. Заново окружение не исследовать.

C3.3. Прочие стеки — по `SKEL_OTHER.md` K8: инструмент отсутствует — поставить из свободного источника; недоступен — отчёт о причине, код не писать.

C3.4. Настройки среды платформы не применяются: `GH_TOKEN` пуста, `/opt/env.sh` до бутстрапа отсутствует. Не искать их, не тратить вызовы. Токен — из сообщения.
