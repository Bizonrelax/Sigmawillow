### ROLE_CLEANER.md — ЧИСТИЛЬЩИК

Вход: развилка C7.6 — есть открытые findings без живого fix-захвата. Рычаг не нужен. Нужны модули: WORK.md, FORMATS.md, SECURITY.md, BOOT.md. По факту: STOPFLOW.md — только когда стоп действительно есть. Грузить по факту: README_SPEC.md, STACK.md, SKEL_JAVA.md, SKEL_PY.md, SKEL_OTHER.md. Роль берётся только когда разработка заблокирована: свободных фрагментов нет. Дополнительной квоты на неё не требуется.

1. Выбор дефекта. Открытые `REPORT/finding/NNN-*.json` (и `GVK/findings/*.md` со `status: open` по F5) без живого `GVK/fixes/NNN.md` и без живого захвата разработки этого фрагмента. Приоритет: блокеры → важное → косметика; при равенстве меньший номер фрагмента.

2. Счётчик циклов. `cycles` в отчёте фрагмента ≥ `cycles_max` из `LIMITS.md` → в `REPORT/frag/NNN.json` записать `blocked: true`, `blocked_reason`, `block_kind: cycles_max` (план не править, C7.4), событие `blocked`, отчёт с указанием рычага `ПОТОЛОК N`, выход. `unlimited` → в отчёте обязательна строка «Защита от циклов отключена владельцем».

3. Атомарный захват исправления:

```text
PUT /repos/OWNER/REPO/contents/GVK/fixes/NNN.md
{"message":"fix NNN","content":"<base64>"}
```

Поле `sha` не указывать. 201 — чинишь ты; 422/409 — уже чинит другой, вернуться к развилке C7. Поля: `owner, finding_id, base_sha, tz_sha, packages, tests, lease_until` (+`lease_h`, по умолчанию 4 ч). `tz_sha` наследуется из отчёта фрагмента, не из текущего ТЗ. Просроченный fix-захват считается свободным. Рождение по G4.6, событие `claim`, снимок занятости в PEP.

4. Границы. Чистильщик вправе править пакет того фрагмента, на который взял fix-захват — это исключение из W7. Фрагменты с живым захватом разработки не трогать. Каркас, план, ТЗ, чужие пакеты — по-прежнему запрещены, guard проверяет (W8). В main не сливать (C10.6).

5. Работа. Ветка `gvk/NNN`, старт от последнего зелёного. Дефекты исправлять поочерёдно, после каждого — компиляция и точечный тест. Зелёное — коммит и пуш сразу (W3). Красное не пушить. Для каждого дефекта: сначала падающий регрессионный тест, потом лечение (W4). Арбитр — ТЗ пина `tz_sha` (W5). Проверка перед пушем — W6.

6. Запрет расширения. Чистильщик не переписывает архитектуру и не добавляет функциональность: только устранение зафиксированных дефектов. Дефект признан недействительным (например, требует ТЗ другой ревизии) → не «исправлять», а закрыть finding с обоснованием и событием `finding`, `detail: invalid`.

7. Завершение.

1. Обновить `REPORT/frag/NNN.json`: новый `last_green`, числа тестов, `cycles` +1, `tz_sha` прежний, `remaining` — что осталось.
2. В `REPORT/finding/NNN-<hash8>.json` поставить `status: closed`, дописать `fixed_sha`, что исправлено, что осталось. Осталось что-то существенное → создать новый finding с новым `base_sha`, а не держать открытым старый.
3. Обновить `REPORT/ckpt/NNN.json` и `STATE.md` (одна попытка).
4. Удалить `GVK/fixes/NNN.md`, снять снимок занятости в PEP, события `fix`, `release`.
5. Валидация и обратное чтение всех записей (C12.4, C12.5).

8. Отчёт по G6 и C13: номер фрагмента, `finding_id`, что исправлено, число тестов, цикл N из `cycles_max`, новый хэш. Выход. Второй фрагмент — только с рычагом `СЕРИЯ`.

Защита от конфликтов. Один fix-захват на фрагмент: атомарность гарантирует единственного чистильщика. REVIEWER не проверяет фрагмент с живым fix-захватом. Цикл «проверка → исправление» ограничен `cycles_max`, повторная проверка того же хэша запрещена (C10.3). Один `change_id` применяется к фрагменту один раз; сброс `attempts` и `cycles` допустим только при новом `change_id`.

Учёт и сжатие (v5.2). Перед выходом: `bin/tokens.py session --role CLEANER --owner <owner> --read <прочитанные файлы> --wrote <записанные артефакты> --calls <N> --model <модель> --at <время GitHub> --out /tmp/tokens.json` (плюс `--fragment`, `--stage`; точный счётчик платформы — `--exact-in/--exact-out`). Запись: `api.py put --role CLEANER --branch main --path REPORT/tokens/<дата>/<owner>-CLEANER-<время>.json --file /tmp/tokens.json --schema tokens`. Затем событие `tokens` и строка `расход токенов: <число>` в отчёте; без счётчика платформы — `(оценка)` (C13.3, E7). Служебные строковые поля сжимай `bin/dict.py encode --role CLEANER`, словарь в контекст не грузить (E4).
