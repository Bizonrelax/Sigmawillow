15. INTAKE — ИМПОРТ ФАЙЛА РЕПОЗИТОРИЯ В КАРТОЧКИ
15.1 Команда intake --source <path> [--repo OWNER/REPO] [--section N] [--lines a-b]: читает
 источник, режет на кандидаты, пишет черновик fixrealm/data/INTAKE-<n>.tsv с колонками
 source_repo, source_path, source_sha, lines, anchor, kind, raw, title, param, etalon,
 test_cost, floor, prize, dup_of, propose_truth, propose_novelty.
15.2 kind: def, lemma, formula, claim, counterexample, open, table, code, link, limitation.
 Для каждого kind обязательный маршрут и предельный статус при импорте.
15.3 Статусы источника НЕ наследуются. Определение -> def. Лемма с доказательством источника ->
 emp плюс пометка ожидает CHK плюс задача CHK; prf при импорте запрещён. Заявленная эмпирика
 без своего прогона -> hyp или opn плюс задача воспроизведения. Открытый вопрос -> opn.
 Контрпример -> ref только после своей проверки; составной контрпример декомпозировать
 на дешёвую арифметику и вычислительную часть.
15.4 Провенанс обязателен в каждой карточке: источник repo/path@sha, строки, заголовок, дата,
 вид автора (черновик агента, статья, книга). Нет провенанса — lint отказывает.
15.5 Источник только чтение:deny на путь источника для всех ролей; intake не правит и не удаляет
 файл владельца. Повторный импорт того же sha идемпотентен.
15.6 Дедуп: каждая строка черновика прогоняется prior; совпадение -> dup_of, карточка не создаётся,
 вместо неё задача-аннотация на связь.
15.7 Таблицы источника становятся эталонным TSV в data и служат эталоном для precheck. Код
 источника сохраняется как артефакт с пометкой исполнялся или нет; первый этап обязан
 воспроизвести таблицу и зафиксировать расхождения.
15.8 Формулы нормализовать под правила заказчика: без LaTeX, без индексов блоком четыре пробела,
 с индексами строкой Unicode. Неоднозначность -> blk, сырое в data, не выдумывать.
15.9 Новизна сразу: каждая импортированная карточка получает долг LIT. Ссылки источника —
 кандидаты, не основания: LIT обязан открыть и датировать, иначе unc.
15.10 Декомпозиция: большой файл режется по разделам, один раздел один этап под потолком,
 черновик сохраняется между этапами. Новую роль не вводить: PLN планирует, WRK исполняет,
 CHK и LIT гасят долги. Модуль mod/intake.txt — lazy. Срез показывает число строк черновика.
15.11 Запуск владельцем одной строкой: Импортируй <path> в карточки. Selftest: золотой случай
 на нейтральном фикстурном файле, включая отказ наследовать prf и идемпотентность.
