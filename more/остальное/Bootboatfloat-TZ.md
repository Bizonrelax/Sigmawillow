# ТЗ: Bootboatfloat — Minecraft-сервер клубного доступа

Имя проходит критерии (13 символов, латиница, одно слово, точных совпадений в поиске нет). Фиксация после ручной проверки: домен .ru/.com, GitHub exact, товарный знак ФИПС/Роспатент.

## 0. Принципы и принятые риски

- Владелец — самозанятый (НПД), физлицо. Переходы ИП/ООО не реализуются, только счётчик дохода.
- Предоплата за доступ, не донат. ЗП владельца 5000 ₽/мес публична.
- Потолка взносов нет. Репутационный риск принят.
- EULA Mojang игнорируется, `online-mode=false`. Владелец уведомлён: нарушение ГК РФ ч. IV, риск принят. Код не «исправляет» это.
- Сбор бессрочный, без дедлайна.
- Данные — файлы, без БД, перенос копированием папки. Публичные страницы — статичная генерация из JSON.
- Стек: Java 21, Spring Boot (сайт/сервис), Paper (плагины). Исполнение — вручную владельцем/разработчиком, автономный кодер не используется.

## 1. Scope (границы работы)

**In scope (обязательно):**
1. Минимальный игровой сервер (Paper + AuthMe + приват + случайный спавн).
2. Финансовая автоматизация: сайт-касса, реестр, движок долей, 2 агрегатора, авто чеки, whitelist по оплате, планировщик, публичная прозрачность. **Не опция — обязательная часть проекта.**
3. Vault и восстановление доступа.
4. Оферта и юридический контур.

**Out of scope (отложено):** Diablo 2 / Zy-El; косметические префиксы; клиентский мод (отдельное ТЗ, бесплатный, свой код); SMS-шлюз; третий агрегатор; ИП/ООО-переходы.

## 2. Минимальный сервер и трафик

- VPS РФ: 4 ГБ RAM, 2–4 vCPU, NVMe, **тариф с безлимитным трафиком**, канал 100 Mbps.
- Java 21, Paper (стабильная, напр. 1.21.x).
- `server.properties`: `online-mode=false`, `white-list=true`, `spawn-protection=0`, `view-distance=8`.
- Плагины: AuthMeReloaded, GriefPrevention (приват), RandomSpawn/BetterRTP или свой (спавн), EssentialsX и SkinsRestorer — опционально.
- Клиенты ванильные, той же версии; ничего не скачивают. Приват — серверный плагин.
- На этапе 1 whitelist вручную (`/whitelist add`), учёт взносов в файле. **Этап 2 (финансы) обязателен и заменяет ручной учёт автоматикой.**

**Трафик:** у большинства РФ VPS безлимитный, включён в аренду; отдельной строки в кассе нет. Расход ~20–100 КБ/с на игрока (пики до 200 КБ/с при прогрузке чанков): 10 активных ≈ 100–400 ГБ/мес, 20 ≈ 200–800 ГБ/мес. 100 Mbps хватает на ~30 игроков. Избегать тарифов с пакетом ГБ и платным перерасходом. DDoS: игровые серверы атакуют часто, базовая защита провайдера или отдельная — иметь в виду.

## 5. Финансовая модель

### 5.1 Формулы
```
M_t = ceil5( (H_t + S + Прочее_t) / (1 − fee − tax_rate) )
доля_i(t) = Σ_{m=join_i..t} (M_m / N_m)     # исторические M,N из snapshots
баланс_i  = max(0, внесено_i − доля_i)
долг_i    = max(0, доля_i − внесено_i)
```

### 5.2 Счёт месяца (с 7-го; новичкам — с месяца вступления, если позже)
```
если Σдолг ≥ M_t:  счёт_i = M_t × долг_i / Σдолг
иначе:             счёт_i = M_t / N
к_оплате_i = max(0, счёт_i − баланс_i)
списание_с_баланса = min(баланс_i, счёт_i)
```
Округление до ₽, сумма подгоняется под M_t корректировкой наибольшего счёта. Доля начисляется за все месяцы с вступления (включая prepaid 1–6), счета — только с 7-го.

### 5.3 Касса
```
касса_t = касса_{t−1} + Receipts_t×(1−fee) − НПД(Receipts_{t−1}) − Расходы_t
```
НПД кассовый: налог со сборов М0 платится в М1. ЗП ежемесячно, не авансом.

### 5.4 Правила
- **Запуск:** Σgross ≥ G → М0: предоплата хостинга 6×H, домен, резерв налога. Превышение G остаётся в кассе. Сбор бессрочный, ждут сколько угодно.
- **Возврат до запуска:** по ст. 32 ЗоЗПП, расходы ещё не понесены → возврат почти полный (минус комиссия агрегатора как фактический расход). Без дедлайна это право постоянно до открытия.
- **Возврат после запуска:** ст. 32 минус фактические расходы (хостинг предоплачен → ≈0). Игроку — вся gross; налог себе — аннулирование чека «возврат прихода», переплата ЕНС; невозвращённая комиссия — из резерва.
- **Новичок в 1–6 мес:** взнос = минимальный среди основателей; доля с месяца вступления.
- **Апгрейд из-за новичков:** разовый целевой сбор с них; общий апгрейд → рост M.
- **Неплательщик:** напоминание → grace_days → suspend, мир/инвентарь целы, начисления идут → оплатил → unsuspend.
- **Ушедший:** баланс не возвращается, остаётся в кассе; долг прощается через forgive_months, в N не counted.
- **Дефицит:** касса < Расходы_{t+1} → экстренное распределение по 5.2 среди активных либо пауза (решение владельца).

## 7. Сайт и API

Авторизация своя (ник+пароль), 406-ФЗ; email — контакт, любой ящик.

```
POST /register /login /logout
POST /recovery/totp /recovery/backup /recovery/email /recovery/ticket
GET  /pay/options            # 2 агрегатора, СБП приоритетом
POST /pay/create {agg}
POST /webhook/{agg}          # подпись, идемпотентность по order_id
GET  /api/whitelist          # bearer-token, для плагина
GET  /api/player/{nick}
GET  /public/progress /public/ledger /public/expenses
Admin: GET /admin/tickets, POST /admin/recovery/{id}/decide,
       POST /admin/expenses, POST /admin/config
```

Регистрация: ник, пароль, email обязательно; TOTP рекомендуется (QR + 10 резервных кодов, один показ); reserve_email/phone/кодовое слово опционально. Паспорт/ФИО/адрес/ДР не собирать.

Поле prose (опционально, 0–40 000): метка «Сочините прозаический текст и запомните его смысл»; можно вымысел; шифруется, открывается только при восстановлении; не писать пароли/карты/паспорт. В профиле не показывать; перечитать после повторной аутентификации; редактировать пока залогинен.

## 8. Платежи

- Два агрегатора: Prodamus + Робокасса (самозанятый, авто чеки «Мой налог»). СБП приоритетом.
- order_id="{agg}:{uuid}", webhook с подписью, идемпотентная запись.
- Чек формирует агрегатор. Возврат через агрегатор оплаты.
- Блокировка одного → второй работает.

## 9. Плагины Paper и спавн

- `online-mode=false`, AuthMeReloaded обязателен, SkinsRestorer опционально.
- **Случайный спавн:** на `PlayerJoinEvent`, если `hasPlayedBefore()==false` → x,z ∈ [−1000,+1000], безопасная высота; повторные входы — спавн/кровать. Плагин RandomSpawn/BetterRTP или свой (~30 строк). Зона 2000 м проходима за ~5–6 мин — для реальной защиты новичков опционально PvP-грейс или зона больше.
- GriefPrevention: клейм-блоки новичкам.
- Poll `/api/whitelist` каждые 5 мин; на AuthMe login — проверка, kick если не в списке.
- Команды: `/balance` (баланс, счёт, история), `/kassa` (публичная касса, расходы, ЗП).
- Никаких pay-to-win. Префиксы — out of scope.

## 10. Vault и восстановление

- AES-GCM, мастер-ключ вне /data. Decrypt только при активном recovery-ticket, каждое открытие → audit.jsonl.
- Каналы: (1) TOTP мгновенно; (2) резервный код + регенерация; (3) magic-link 15 мин; (4) ручной: пересказ prose + второй фактор (registered contact ИЛИ детали последнего платежа из ledger).
- Hero (баланс ≥ 3×M): второй фактор обязателен.
- Решение логируется (approve/deny + reason). Лимит 3 заявки/мес.
- Prose не хешировать (сверка смысловая) — хранить шифрованным.

## 11. Планировщик

- Ежемесячно (1-е): доли/счета, публикация, напоминания.
- Ежедневно: grace-expiry → suspend; оплата → unsuspend; регенерация статики.
- Ежегодно: счётчик НПД с 1 января, warn при npd_warn, факт при npd_cap (без автопереходов).
- Календарь налогов: уведомление владельцу к 12-му и 28-му.

## 12. Юридический контур

Клаузулы оферты: предоплата за доступ; цель G, сбор бессрочный; возврат до запуска по ст. 32 (расходы не понесены); взнос = право играть пока сервер работает, первые 6 мес prepaid; невозвратность после запуска через фактические расходы, не через запрет (ст. 16 ничтожен); с 7 мес персональный счёт по равной доле, баланс переносится; ЗП и расходы публичны; неоплата → приостановка, мир сохраняется; сервер может закрыться при недоборе, остатки не возвращаются; апгрейды → рост счёта; новички с месяца вступления; ПДн по политике; не аффилирован с Mojang/Microsoft.

Действия владельца вручную: домен .ru; VPS РФ + предоплата хостинга 6 мес; договоры с агрегаторами; уведомление РКН до обработки ПДн; публикация политики + оферты; привязка «Мой налог». 152-ФЗ: минимизация, локализация РФ, согласие. С 2025 утечка ПДн — многомиллионные штрафы, ст. 272.1 УК; vault — главная цель защиты.

## 14. Этапы (вручную, без автономного кодера)

1. **Минимальный сервер:** VPS, Paper, AuthMe, GriefPrevention, спавн, ручной whitelist. Критерий: игроки заходят, приват и спавн работают.
2. **Ledger-движок** (чистая Java): сущности, формулы, алгоритм 5.2, тесты 1–8, 15, 17. Критерий: числовые тесты зелёные.
3. **Сайт + регистрация + vault + восстановление:** тесты 12–13, BCrypt/AES-GCM, аудит.
4. **Платежи:** 2 агрегатора, webhook, идемпотентность, чеки; тесты 9–10.
5. **Плагин-финансы + whitelist-автозамена:** команды, AuthMe-интеграция, тест 11; ручной whitelist заменяется.
6. **Планировщик + статика + админка:** тесты 14, 16; календарь налогов.
7. **Оферта + ручные действия владельца:** публикация, РКН, домен, VPS, агрегаторы.
