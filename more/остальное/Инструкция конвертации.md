## Шаг 2. Python

Если скрипт у тебя уже запускался — Python есть, переходи к шагу 3.

### 2.1. Проверка

1. `Win + X` → **Терминал** или **Windows PowerShell**
2. Введи:

```powershell
python --version
```

| Что видишь | Что делать |
|---|---|
| Python 3.10–3.13 | всё есть, шаг 3 |
| Открылся Microsoft Store | Python не установлен |
| «не является командой» | Python не установлен или не в PATH |

### 2.2. Где скачать

Основная ссылка:

```text
https://www.python.org/downloads/
```

Нажми большую кнопку **Download Python 3.x.x**. Лучше 3.12 или 3.13, 64-bit.

Страница всех версий для Windows:

```text
https://www.python.org/downloads/windows/
```

Выбирай **Windows installer (64-bit)**.

Не бери: ARM64, embeddable package, web installer.

### 2.3. Как установить

1. Запусти скачанный `.exe`
2. В первом окне обязательно поставь галочку:

```text
Add python.exe to PATH
```

3. Нажми **Install Now**
4. Дождись конца → **Close**

### 2.4. Проверка после установки

Закрой PowerShell, открой заново и введи:

```powershell
python --version
python -m pip --version
```

Обе команды должны показать версии.

### 2.5. Если Python всё равно открывает Store

1. **Параметры** → **Приложения**
2. **Дополнительные параметры приложений**
3. **Псевдонимы выполнения приложений**
4. Выключи `python.exe` и `python3.exe` («Установщик приложения»)
5. Закрой и открой PowerShell

Запасной вариант — команда `py`:

```powershell
py --version
py -m pip --version
```

Если `py` работает, везде дальше вместо `python` пиши `py`.

## Шаг 5. FFmpeg (только если нужен MP3)

Если `winget` качается бесконечно — нажми `Ctrl + C` и ставь вручную по ссылке.

### 5.1. Где скачать

Основная прямая ссылка:

```text
https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip
```

Если не открылась — страница builds:

```text
https://www.gyan.dev/ffmpeg/builds/
```

Раздел **release builds** → файл `ffmpeg-release-essentials.zip`.

Запасной вариант (GitHub):

```text
https://github.com/BtbN/FFmpeg-Builds/releases/latest
```

Там нужен файл вида `ffmpeg-master-latest-win64-gpl.zip`.

Главное: Windows, 64-bit, ZIP.

### 5.2. Куда распаковать

1. Создай папку `C:\ffmpeg`
2. Открой скачанный ZIP
3. Внутри папка вида `ffmpeg-7.x.x-essentials_build`
4. Внутри неё папка `bin`
5. Скопируй `bin` в `C:\ffmpeg`

Должно получиться:

```text
C:\
└── ffmpeg\
    └── bin\
        ├── ffmpeg.exe     ← этот файл главный
        ├── ffplay.exe
        └── ffprobe.exe
```

Проверь глазами, что файл лежит именно тут:

```text
C:\ffmpeg\bin\ffmpeg.exe
```

### 5.3. Добавь папку в PATH

Способ А — через окна Windows:

1. `Win + R` → введи `sysdm.cpl` → Enter
2. Вкладка **Дополнительно**
3. Кнопка **Переменные среды...**
4. Верхний блок «Переменные среды пользователя» → выдели `Path`
5. **Изменить...** → **Создать**
6. Впиши:

```text
C:\ffmpeg\bin
```

7. **ОК** во всех окнах

Способ Б — одной командой в PowerShell:

```powershell
[Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","User") + ";C:\ffmpeg\bin", "User")
```

После любого способа обязательно:

1. Закрой PowerShell
2. Открой заново
3. Проверь:

```powershell
ffmpeg -version
```

Показал версию — готово.

## Шаг 6. Получить MP3

### Вариант А — WAV уже есть (быстро, рекомендуется)

```powershell
cd C:\OpenAirDisco
ffmpeg -y -i OpenAirDisco_3m36s.wav -b:a 192k OpenAirDisco_3m36s.mp3
```

Если команда `ffmpeg` не распознаётся — полный путь:

```powershell
cd C:\OpenAirDisco
C:\ffmpeg\bin\ffmpeg.exe -y -i OpenAirDisco_3m36s.wav -b:a 192k OpenAirDisco_3m36s.mp3
```

Результат: `OpenAirDisco_3m36s.mp3`, ~5 МБ, звучит почти так же.

### Вариант Б — заново прогнать скрипт

Если FFmpeg уже в PATH:

```powershell
cd C:\OpenAirDisco
python track.py
```

Скрипт создаст сразу и WAV, и MP3.
Если MP3 не появился — значит FFmpeg не найден, используй вариант А.

### Если хочешь качество выше

Битрейт 320k вместо 192k:

```powershell
ffmpeg -y -i OpenAirDisco_3m36s.wav -b:a 320k OpenAirDisco_320k.mp3
```

## Шаг 9. Ошибки и что делать

| Проблема | Причина | Решение |
|---|---|---|
| python не является командой | нет Python или нет в PATH | переустанови с галочкой Add python.exe to PATH |
| python открывает Store | псевдонимы Windows | отключи псевдонимы или используй py |
| pip не является командой | pip не в PATH | пиши python -m pip |
| No module named numpy | библиотека не встала | python -m pip install numpy scipy |
| No module named scipy | библиотека не встала | python -m pip install numpy scipy |
| ffmpeg не является командой | нет PATH или не перезапущен терминал | перезапусти PowerShell или дай полный путь |
| Сделался только WAV | скрипт не нашёл FFmpeg | конвертируй вручную, шаг 6 вариант А |
| Файл track.py.txt | скрытые расширения | включи расширения, переименуй |
| PowerShell в System32 | не та папка | cd C:\OpenAirDisco |
| FFmpeg качается вечность | большой ZIP, медленный сервер | забей, WAV уже работает; или запасная ссылка |
| Окно мигнуло и закрылось | запуск двойным кликом | запускай из PowerShell, чтобы видеть текст ошибки |
| Звук тихий или хрипит | громкость плеера / клиппинг | убавь громкость в Winamp до 70–80% |

## Приложение. Если pip не качает, а браузер качает

Запасной путь, обычно не нужен.

### 1. Узнай метку своей версии Python

```powershell
python --version
```

| Python | Метка |
|---|---|
| 3.11 | cp311 |
| 3.12 | cp312 |
| 3.13 | cp313 |

### 2. Скачай два файла через Chrome

```text
https://pypi.org/project/numpy/#files
https://pypi.org/project/scipy/#files
```

Ищи файлы вида:

```text
numpy-...-cp312-cp312-win_amd64.whl
scipy-...-cp312-cp312-win_amd64.whl
```

Для 3.13 — cp313, для 3.11 — cp311.
Бери именно win_amd64: не linux, не macosx, не arm.

### 3. Положи оба файла в папку

```text
C:\OpenAirDisco\wheels
```

### 4. Установи из локальных файлов, без интернета

```powershell
python -m pip install --no-index --find-links C:\OpenAirDisco\wheels numpy scipy
```
