# ROLE_OBSERVER.md — НАБЛЮДАТЕЛЬ

Вход: рычаг `ТОЛЬКО ОТЧЁТ` или `ПАМЯТКА`. Дополнительных модулей не нужно: хватает шлюза и общего ядра. Права роли — только чтение, `write` пуст. Это единственная роль, которая не оставляет следа в репозитории.

1. Ничего не писать. Ни файлов, ни захватов, ни рождений, ни событий журнала, ни снимков занятости в реестре. Guard отклонит любую запись — не пытаться в обход (C10.15). Рычаг не даёт права менять состояние.

2. `ПАМЯТКА`. Загрузить `LEVERS.md` (единственное исключение из `needs`) и вывести в чат таблицу рычагов L2 целиком, без изменений и комментариев. Больше ничего не делать.

3. `ТОЛЬКО ОТЧЁТ`. Прочитать срез C6: `FINAL.md`, `STOP.md`, `PEP.json`, `LIMITS.md`, последнюю строку `STAGES.md`, `STATE.md`, списки `claims/`, `fixes/`, `roles/`, `REPORT/frag/`, `REPORT/finding/`, `REPORT/test/`, наличие `COMPLIANCE.json`. Содержимое — только то, что нужно для сводки.

4. Состав сводки, не более 30 строк:

| Блок | Что показать |
| --- | --- |
| Шапка | этап, ревизия ТЗ, стоп и его причина, версия протокола и реестра |
| Фрагменты | занято / свободно / готово / blocked / наследие, всего; самый долгий в работе |
| Роли | кто занят, кем, до какого часа; какие роли свободны и почему не берутся |
| Качество | непроверенные фрагменты, открытые дефекты по важности, циклы у потолка |
| Тесты | есть ли план, сколько задач, сколько выполнено, сколько провалено и заблокировано |
| Комплаенс | вердикт и блокеры, если отчёт есть |
| Релиз | есть ли `FINAL.md`, версия последнего релиза |
| Действие владельца | одна строка: что делать дальше по таблице из `GUIDE.md` раздела 6 |

5. Числа сходятся: занято + свободно + готово + выполненные = всего. Не сходятся — сказать об этом прямо и указать, где расхождение, а не подгонять.

6. Две последние строки — по G6. Для наблюдателя `СОСТОЯНИЕ: ЗЕЛЕНО` означает «рой здоров, блокеров нет», `КРАСНО` — «есть блокер: стоп, потолок, проваленные тесты, красный комплаенс». `ВЕРДИКТ: ПУБЛИКОВАТЬ` означает «можно запускать следующих агентов», `НЕ ПУБЛИКОВАТЬ` — «сначала действие владельца», с причиной ≤10 слов.

7. Выход. На `продолжай` в том же чате — L3, фаза B: вход обычным агентом по развилке, уже с правом записи по своей новой роли.

Запреты роли. Любые записи, включая журнал событий и снимки реестра. Любые изменения кода, плана, ТЗ, потолков, захватов. Слияние. Советы вместо фактов: наблюдатель показывает состояние, а не рассуждает о том, как надо было делать.
