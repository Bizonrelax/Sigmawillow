# Гипотеза об асимметрии числа решений для n-значных чисел

## Обозначения

Пусть n ≥ 2 — целое. Рассматриваются n-значные числа в десятичной записи:

A = сумма по i от 0 до n−1 от aᵢ · 10ⁱ

B = сумма по i от 0 до n−1 от bᵢ · 10ⁱ

где

aᵢ, bᵢ ∈ {0, 1, …, 9}

и старшие цифры не равны нулю:

a<sub>n−1</sub>, b<sub>n−1</sub> ∈ {1, 2, …, 9}

Индекс i = 0 соответствует единицам, i = n−1 — старшему разряду.

## Определение перекрёстной разности

Для n-значных чисел перекрёстная разность определяется как сумма по всем парам разрядов:

Δₙ(A, B) = сумма по 0 ≤ i < j ≤ n−1 от (aᵢ · bⱼ − aⱼ · bᵢ)

**Проверка для n = 2.** При n = 2 есть только одна пара разрядов: (0, 1). Тогда

Δ₂(A, B) = a₀ · b₁ − a₁ · b₀ = y · u − x · v

что совпадает с определением из теоремы о полном числе решений T(K).

**Замечание о другом возможном обобщении.** Существует более простая версия, использующая только крайние разряды:

Δₙᵒᵘᵗ(A, B) = a₀ · b<sub>n−1</sub> − a<sub>n−1</sub> · b₀

При n = 2 она совпадает с Δ₂. При n ≥ 3 она игнорирует промежуточные цифры. Гипотеза ниже сформулирована для полной версии Δₙ; версия Δₙᵒᵘᵗ — отдельная задача.

## Определение Tₙ(K)

Через Sₙ(K) обозначается множество всех упорядоченных пар (A, B) n-значных чисел, для которых

Δₙ(A, B) = K

Через S<sub>n,lt</sub>(K) обозначается подмножество пар с A < B:

S<sub>n,lt</sub>(K) = { (A, B) ∈ Sₙ(K) : A < B }

Через Tₙ(K) обозначается мощность:

Tₙ(K) = |S<sub>n,lt</sub>(K)|

То есть Tₙ(K) — число пар n-значных чисел с A < B и Δₙ(A, B) = K.

## Формулировка гипотезы

**Гипотеза.** Для любого целого n ≥ 2 и любого целого K ≠ 0, для которого хотя бы одна из величин Tₙ(K) или Tₙ(−K) положительна, выполнено

Tₙ(K) ≠ Tₙ(−K)

Другими словами: внутри множества Sₙ(K) при K ≠ 0 никогда не бывает точного баланса между парами с A < B и парами с A > B.

## Известные данные

**n = 2.** Гипотеза доказана полным перебором всех 4005 пар. Таблица в файле `full_table.md`: для всех K от 1 до 81 выполнено T(K) ≠ T(−K).

**n = 3.** Не проверялась. Объём перебора — 404 550 пар, это выполнимо в Colab за секунды.

**n = 4.** Не проверялась. Объём перебора — 40 495 500 пар, это минуты в чистом Python и секунды с оптимизацией.

**n ≥ 5.** Перебор невозможен. Нужен математический аргумент.

## Что известно точно (для любого n)

**Предложение 1 (кососимметричность).** Для любых n-значных A, B:

Δₙ(B, A) = −Δₙ(A, B)

**Доказательство.** Каждое слагаемое aᵢ bⱼ − aⱼ bᵢ при перестановке A и B меняет знак: bᵢ aⱼ − bⱼ aᵢ = −(aᵢ bⱼ − aⱼ bᵢ). Сумма меняет знак. Что и требовалось.

**Предложение 2 (swap-симметрия).** Отображение (A, B) → (B, A) биективно переводит S<sub>n,lt</sub>(K) в S<sub>n,gt</sub>(−K). Следовательно,

Tₙ(K) + Tₙ(−K) = |Sₙ(K)| − Dₙ(K)

где Dₙ(K) — число пар с A = B и Δₙ(A, B) = K. При K ≠ 0 имеем Dₙ(K) = 0, поэтому

Tₙ(K) + Tₙ(−K) = |Sₙ(K)|

**Доказательство.** Прямое следствие предложения 1 и разбиения Sₙ(K) на S<sub>n,lt</sub>, S<sub>n,gt</sub>, S<sub>n,eq</sub>. При K ≠ 0 диагональных пар нет, поскольку Δₙ(A, A) = 0.

**Предложение 3 (закон сохранения).** Сумма Tₙ(K) по всем целым K равна числу всех пар n-значных чисел с A < B:

сумма по K от Tₙ(K) = Nₙ · (Nₙ − 1) / 2

где Nₙ = 9 · 10<sup>n−1</sup> — количество n-значных чисел.

**Доказательство.** Каждая пара (A, B) с A < B имеет ровно одно значение Δₙ(A, B). Множество всех таких пар разбивается в дизъюнктное объединение по K. Суммируя мощности, получаем утверждение.

**Предложение 4 (носитель).** |Δₙ(A, B)| ≤ 81 · n(n−1)/2. Следовательно, Tₙ(K) = 0 при |K| > 81 · n(n−1)/2.

**Доказательство.** Каждое слагаемое aᵢ bⱼ − aⱼ bᵢ по модулю не превосходит 81. Число слагаемых равно n(n−1)/2. Оценка следует из неравенства треугольника.

## Статус

Гипотеза. Для n = 2 доказана полным перебором. Для n ≥ 3 не доказана и не опровергнута.

## Почему это правдоподобно

Для n = 2 асимметрия установлена перебором, и структурная причина видна: отображение swap переводит S(K) в S(−K), но внутри S(K) нет естественной инволюции, сохраняющей Δ и одновременно меняющей местами A < B и A > B. Единственная симметрия, сохраняющая Δ, — композиция swap и обращения цифр, но она определена не всегда и не сохраняет неравенство A < B.

Для n ≥ 3 эта структурная причина сохраняется: swap по-прежнему переводит Sₙ(K) в Sₙ(−K), а внутри Sₙ(K) нет очевидной симметрии, которая давала бы баланс. Однако для n ≥ 3 появляются новые симметрии: перестановки разрядов. При перестановке цифр внутри числа Δₙ меняется, но множество Sₙ(K) может приобрести дополнительную структуру. Именно поэтому гипотеза для n ≥ 3 не тривиальна: дополнительные симметрии могут создать случайные совпадения Tₙ(K) = Tₙ(−K).

## Как проверить

**n = 3.** Написать программу, аналогичную `T_full_scan.py`, но с перебором трёхзначных чисел: `for a in range(100, 1000)` и `for b in range(100, 1000)`. Число пар с A < B — 404 550. В Colab это займёт секунды. Если контрпримеров нет — гипотеза подтверждена для n = 3 (и становится теоремой для n = 2, 3).

**n = 4.** То же, но 40 495 500 пар. В чистом Python — минуты. С предвычислением цифр в массивы — быстрее. Если Colab справится — гипотеза подтверждена для n = 4.

**n ≥ 5.** Перебор невозможен. Нужен математический аргумент: либо доказательство асимметрии для всех n, либо контрпример для некоторого n.

## Что это даёт

Если гипотеза верна для всех n, она описывает общее свойство десятичной записи: перекрёстная разность «чувствует» порядок чисел и никогда не даёт точного баланса между A < B и A > B. Это свойство можно сформулировать как «асимметрия перекрёстной разности относительно обращения знака».

Если гипотеза неверна для некоторого n, это тоже ценно: контрпример покажет, при каком n и при каком K наступает баланс, и это может указать на скрытую структуру (например, на связь с перестановками разрядов).

## Этическая пометка

Гипотеза названа по содержанию, а не по имени автора. Имя автора нигде не указано. Использованные понятия (кососимметричная форма, сумма по парам разрядов) стандартны. Гипотеза не является переоткрытием известного результата в той формулировке, которая здесь приведена; в литературе по цифровым инвариантам и по подсчёту целых точек аналогичная постановка для n-значных чисел не встречалась в доступных источниках, но полный обзор не проводился. Если гипотеза окажется известной, это надо зафиксировать и снять статус «гипотеза».

# 3. Зачем всё это нужно

Ти, честный ответ. Прямой практической пользы — почти никакой. Ни в инженерии, ни в физике, ни в промышленности эти теоремы не применяются. Если кто-то скажет тебе обратное — не верь.

Но есть несколько слоёв ценности, и они реальны.

## Математическая ценность

**Первое.** Теорема об асимметрии — это чистое, неочевидное утверждение о десятичной записи. Такие утверждения иногда попадают в задачники (например, в American Mathematical Monthly, раздел Problems) или в статьи о комбинаторике цифр. Это не прорыв, но это законный математический факт.

**Второе.** Функция T(K) и её свойства (conservation law, симметрия, асимметрия) — это задача о подсчёте целых точек на гиперплоскости внутри многогранника. Такие задачи изучаются в теории Эрхарта и в арифметической геометрии. Твоя задача — маленький, но конкретный пример этой общей теории. Она может служить тестовым примером для общих теорем.

**Третье.** Обобщение на n-значные числа связывает задачу с внешней алгеброй (сумма по парам разрядов — это коэффициент клина) и с координатами Плюккера. Это уже более серьёзная математика. Если гипотеза для n ≥ 3 окажется верной или неверной, это может дать содержательный пример в этой области.

## Методологическая ценность

**Первое.** Ты прошёл полный цикл: наблюдение → гипотеза → компьютерная проверка → доказательство (для n = 2) → обобщение (для n ≥ 3). Это ровно то, как работает математика. Многие школьные и студенческие проекты останавливаются на «я заметил закономерность». Ты дошёл до «я доказал перебором и сформулировал обобщение».

**Второе.** Ты увидел разницу между **доказательством перебором** (конечное множество, полная проверка — это доказательство) и **гипотезой** (бесконечное или слишком большое множество — перебор невозможен). Это важное различие, которое многие путают.

**Третье.** Ты потренировался в аккуратности: conservation law, проверка симметрии, независимая реализация, сверка двух таблиц. Это навык, который переносится на любую исследовательскую работу.

## Потенциальные глубокие связи (спекулятивно)

**Первое.** Сумма по парам разрядов — это коэффициент клина двух векторов цифр. Внешняя алгебра — рабочая область. Гипотеза об асимметрии может иметь интерпретацию в терминах координат Плюккера и соотношений между ними. Это спекуляция, но не безумная.

**Второе.** Функция T(K) — это счётная функция для многогранника. По теореме Эрхарта, такие функции часто являются квазиполиномами. Если T(K) окажется квазиполиномом (или суммой квазиполиномов), это даст замкнутую формулу. Пока этого не видно: значения прыгают. Но для n ≥ 3 картина может быть регулярнее.

**Третье.** Перекрёстная разность — это что-то вроде «синдрома» в теории кодирования. Если рассматривать цифры как символы алфавита, Δ — это билинейная форма, которая обнуляется на некоторых конфигурациях. Это может быть связано с кодами, обнаруживающими ошибки. Но это очень далёкая аналогия, и я не знаю ни одной работы, где она реализована.
