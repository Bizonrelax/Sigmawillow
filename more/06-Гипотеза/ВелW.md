Короткое описание: Определение W = (S² + Q)/2 и гипотезы о её свойствах как отображения мультимножеств цифр в целые числа.

# Величина W: определение через сумму и сумму квадратов цифр

## Обозначения

Пусть A — n-значное число в десятичной записи:

    A = d₁·10ⁿ⁻¹ + d₂·10ⁿ⁻² + … + dₙ

где d₁ ∈ {1, …, 9}, d₂, …, dₙ ∈ {0, …, 9}. Числа d₁, …, dₙ называются цифрами числа A.

Определим две вспомогательные величины:

    S(A) = d₁ + d₂ + … + dₙ        (сумма цифр)

    Q(A) = d₁² + d₂² + … + dₙ²     (сумма квадратов цифр)

## Определение величины W

**Определение.** Величиной W числа A называется

    W(A) = (S(A)² + Q(A)) / 2

Это определение принимается как основное для всех n ≥ 1.

## Корректность определения

**Утверждение 1 (целочисленность).** Для любого A значение W(A) — целое число.

*Доказательство.* Достаточно показать, что S² + Q чётно. Для каждой цифры d выполняется d² ≡ d (mod 2). Суммируя по всем цифрам, получаем Q ≡ S (mod 2). Кроме того, S² ≡ S (mod 2). Следовательно,

    S² + Q ≡ S + S = 2S ≡ 0 (mod 2)

Значит, числитель чётный, и W(A) — целое. ∎

## Согласованность с исходным определением для двузначных чисел

**Утверждение 2.** Если A = 10·x + y — двузначное число (x ∈ {1, …, 9}, y ∈ {0, …, 9}), то

    W(A) = x² + x·y + y²

*Доказательство.* Имеем S = x + y и Q = x² + y². Тогда

    (S² + Q) / 2 = ((x + y)² + x² + y²) / 2
                 = (x² + 2xy + y² + x² + y²) / 2
                 = (2x² + 2xy + 2y²) / 2
                 = x² + xy + y²

Что и требовалось. ∎

## Эквивалентная комбинаторная интерпретация

**Утверждение 3 (сумма попарных произведений).** Для любого A выполняется

W(A) = Σ dᵢ·dⱼ, где сумма берётся по всем парам 1 ≤ i ≤ j ≤ n.

Иными словами, W(A) есть сумма всех произведений пар цифр с повторениями, где порядок не важен.

*Доказательство.* Раскроем квадрат суммы. Имеем S² = Q + 2·T, где T = Σ dᵢ·dⱼ по всем i < j. Отсюда

    (S² + Q) / 2 = Q + T

Но Q + T есть в точности сумма по всем парам i ≤ j: слагаемые с i = j дают Q, слагаемые с i < j дают T. Значит, (S² + Q) / 2 = Σ dᵢ·dⱼ по i ≤ j. ∎

Это оправдывает название величины: W — сумма всех произведений пар цифр с повторениями.

## Простейшие свойства

**Свойство 1 (инвариантность относительно перестановки цифр).** Если B получается из A перестановкой цифр, то W(B) = W(A). Это следует из симметричности выражений для S и Q относительно перестановки цифр.

**Свойство 2 (зависимость только от S и Q).** Значение W(A) полностью определяется парой (S(A), Q(A)). В частности, если S(A) = S(B) и Q(A) = Q(B), то W(A) = W(B).

**Свойство 3 (минимальное значение).** W(A) = 1 тогда и только тогда, когда A = 10ⁿ⁻¹, то есть A есть степень десяти.

*Доказательство.* W(A) = 1 означает S² + Q = 2. Так как d₁ ≥ 1, имеем S ≥ 1 и Q ≥ 1. Если S ≥ 2, то S² ≥ 4 > 2, противоречие. Значит, S = 1, откуда Q = 1. Сумма цифр равна 1 при Q = 1 только тогда, когда одна цифра равна 1, а остальные 0. Поскольку d₁ ≥ 1, это ровно число 10ⁿ⁻¹. Обратно, для 10ⁿ⁻¹ имеем S = 1, Q = 1, W = 1. ∎

**Свойство 4 (связь с задачей Пруэ–Тарри–Эскотта).** Равенства S(A) = S(B) и Q(A) = Q(B) означают, что наборы цифр чисел A и B имеют равные суммы первых и вторых степеней. Это в точности условие задачи Пруэ–Тарри–Эскотта степени 2.

## Сводка

| Величина | Определение | Смысл |
|:---------|:------------|:------|
| S(A)     | d₁ + … + dₙ | сумма цифр |
| Q(A)     | d₁² + … + dₙ² | сумма квадратов цифр |
| W(A)     | (S² + Q) / 2 | сумма попарных произведений цифр с повторениями |

Определение W(A) = (S² + Q) / 2 принимается как основное. Для двузначных чисел оно совпадает с прежним определением x² + xy + y², что доказано в утверждении 2.

## Открытый вопрос для n = 3, 4, …

**Открытый вопрос (о существенных коллизиях величины W).** Пусть n ≥ 3. Назовём пару n-значных чисел A ≠ B **существенной коллизией**, если W(A) = W(B) и A не получается из B перестановкой цифр. Существенные коллизии делятся на два типа:

- **Тип I:** S(A) = S(B) и Q(A) = Q(B).
- **Тип II:** S(A) ≠ S(B), но S(A)² + Q(A) = S(B)² + Q(B).

Требуется:

1. Для n = 3, 4, 5 найти все существенные коллизии (полный перебор; при n = 3 это конечная проверка 900 чисел).
2. Описать, как число существенных коллизий растёт с n: полиномиально, экспоненциально или иначе.
3. Установить, верно ли, что все существенные коллизии при n ≥ 3 порождаются конечным набором «образующих» коллизий и операцией добавления одинаковых цифр к обоим числам (то есть сводятся к коллизиям меньшей размерности).

**Известный пример для n = 3.** Наборы цифр {0, 3, 3} и {1, 1, 4} дают существенную коллизию типа I: S = 6, Q = 18 в обоих случаях, W = 27. Соответствующие числа — 330, 303 (с ведущей 3) и 114, 141, 411. Это одновременно классическое минимальное решение задачи Пруэ–Тарри–Эскотта степени 2 (см. п. 4).

## Проверка: связь коллизий с решениями PTE

Напомню условие PTE: два набора из n целых чисел имеют равные суммы k-х степеней для всех k = 1, …, m. Решение идеально, если m = n − 1 (максимально возможная степень при данном размере).

**Коллизии типа I.** Условие S(A) = S(B) и Q(A) = Q(B) означает равенство сумм первых и вторых степеней цифр. Это в точности PTE-решение размера n со степенью m = 2.

- Для n = 3 имеем m = 2 = n − 1, то есть коллизии типа I — это **ровно идеальные PTE-решения размера 3**. Пример {0, 3, 3} против {1, 1, 4}: суммы 6 = 6, суммы квадратов 18 = 18. Это и есть классическое минимальное идеальное PTE-решение размера 3. Проверка сходится.
- Для n > 3 имеем m = 2 < n − 1, поэтому коллизии типа I — это PTE-решения степени 2, но **не идеальные**. Идеальные решения потребовали бы равенства сумм степеней вплоть до n − 1, что для наших цифровых наборов является более сильным и, вообще говоря, не выполненным условием.

**Коллизии типа II.** Условие S(A) ≠ S(B) означает, что суммы первых степеней цифр различны. Следовательно, коллизии типа II **не являются PTE-решениями** ни при каком m ≥ 1. Они лежат вне задачи PTE: это решения одного составного уравнения S₁² + Q₁ = S₂² + Q₂, а не системы равенств сумм степеней.

**Двузначные исключения из теоремы.** Оба исключения относятся к типу II:

| Коллизия | S | Q | S² + Q |
|:---------|--:|--:|-------:|
| 35, 53   | 8 | 34 | 98 |
| 70       | 7 | 49 | 98 |
| 19, 91   | 10 | 82 | 182 |
| 56, 65   | 11 | 61 | 182 |

В каждой строке S различны, поэтому это не PTE. Проверка подтверждает: двузначные исключения — чисто типа II.

**Итог проверки.** Коллизии типа I — это в точности PTE-решения степени 2; при n = 3 они идеальны и совпадают с классическими минимальными решениями. Коллизии типа II — не PTE, это отдельное явление. Таким образом, часть нашей теории (тип I) напрямую встраивается в известную задачу PTE, а часть (тип II) остаётся независимой. Именно тип I даёт «законную» связь с живой математикой, а тип II — собственную комбинаторную задачу.
