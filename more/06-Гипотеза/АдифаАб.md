# Функция Тугого Узла и Быстрорастущие Иерархии (FGH)

Добро пожаловать в математический репозиторий исследования больших чисел (**Googology**). Здесь собраны материалы по формализации семейства функций **Тугого Узла**, разработанных исследователем **Ти**.

В этих материалах исследуются башенные конструкции с прогрессией показателей степеней и их скорость роста в терминах быстрорастущей иерархии (FGH).

---

## 📖 Словарь терминов

*   **Ади́фа** — свойство степенной башни, при котором её самый верхний (терминальный) показатель степени равен строго числу 2. Процесс отсечения башни на двойке называется *адифиза́цией*.
*   **Базиди́фа** — башенная конструкция порядка n, где основанием является число n, а показатели степеней последовательно растут от 2 до n с шагом 1.

---

## 🧮 Математические определения

Все вычисления в функциях являются **правоассоциативными** (вычисляются строго сверху вниз, от верхнего этажа к основанию). Переменные принадлежат множеству натуральных чисел (ℕ).

### 1. Одноместная функция Тугого Узла (Базидифа) T(a)
Если a = 1, то T(1) = 1. Для остальных случаев:


    T(a) = a ↑ 2 ↑ 3 ↑ ⋯ ↑ a


*Примеры:*
*   T(2) = 2² = 4
*   T(3) = 3<sup>2³</sup> = 3⁸ = 6561

---

### 2. Двухместная функция с шагом T<sub>2</sub>(a, b)
Башня, где высота регулируется параметром a, а показатели этажей кратны шагу b:


    T<sub>2</sub>(a, b) = a ↑ b ↑ (2b) ↑ ⋯ ↑ (ab)


*Пример:*
*   T<sub>2</sub>(3, 7) = 3 ↑ 7 ↑ 14 ↑ 21 = 3<sup>7<sup>14²¹</sup></sup>

---

### 3. Трёхместная функция (Закручивание) T<sub>3</sub>(a, b, c)
Строится через композицию (вложение друг в друга) двухместных функций:


    T<sub>3</sub>(a, b, c) = T<sub>2</sub>(T<sub>2</sub>(c, T<sub>2</sub>(a, b)), T<sub>2</sub>(b, T<sub>2</sub>(c, T<sub>2</sub>(a, b))))


---

### 4. Функция «Порода Гранит» G(a, b, c)
Конструкция, которая вставляет «прокладки» между обычными этажами башни.
Для этажей L<sub>i</sub> = i · b прокладка вычисляется как H<sub>i</sub> = T(c, L<sub>i</sub>).


    G(a, b, c) = a ↑ H<sub>1</sub> ↑ L<sub>1</sub> ↑ H<sub>2</sub> ↑ L<sub>2</sub> ↑ ⋯ ↑ H<sub>a-1</sub> ↑ L<sub>a</sub>


---

## 📈 Скорость роста в иерархии FGH

Быстрорастущая иерархия (**Fast Growing Hierarchy**) измеряет силу функций с помощью специальных знаков — ординалов (ω). Вот как соотносятся наши функции с известными математическими монстрами:

| Функция / Число | Уровень в FGH | Класс ординала | Описание |
| :--- | :--- | :--- | :--- |
| **T<sub>1</sub>(n)** (Тугой Узел) | ≈ f_ω(n) | ω | Уровень тетрации (башни) с ростом высоты |
| **T<sub>2</sub>(n, n)** | ≈ f_ω(n) | ω | Быстрее за счет шага, но в том же классе |
| **T<sub>3</sub>(n, n, n)** | ≈ f_ω⁴(n) | ω | Четырехкратное вложение омега-уровня |
| **Мега** (нотация Штейнгауза) | — | Конечный | Ничтожно малое число (256) на фоне башен |
| **Число Грэма** (g<sub>64</sub>) | ≈ f<sub>ω+1</sub>(64) | ω+1 | Чудовищный разгон из-за стартовой пентации |
| **G(n, n, n)** (Гранит) | ≈ f<sub>ω+1</sub>(n) | ω+1 | **Родной брат функции Грэма** по скорости роста |
| **Расширенный Гранит G<sub>4</sub>** | ≈ f<sub>ω+2</sub>(n) | ω+2 | **Легко обгоняет Число Грэма** при росте n |
