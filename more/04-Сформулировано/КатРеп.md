## 🛠️ Утилиты и Приложения (Software & Tools)

### 1. [SaberW-2](https://github.com/Bizonrelax/SaberW-2)
* **Назначение:** Продвинутый компрессор текста для отправки огромных сообщений (и исходного кода) в чат-боты и нейросети. Позволяет обходить лимиты на количество символов и экономить токены контекстного окна.
* **Технологии:** Java, Maven, GitHub Actions (CI/CD).
* **Статус:** Активная разработка, есть готовые релизы.

### 2. [Velocipenna](https://github.com/Bizonrelax/Velocipenna)
* **Назначение:** Мощный локальный анализатор текстов. Ищет кириллические символы, выявляет стеганографию на основе омоглифов (латиница/кириллица), маскировку текста и смешение раскладок.
* **Технологии:** Java (Swing), Maven. Поддерживает экспорт отчётов в 8 форматов (включая PDF и DOCX) и 5 языков интерфейса.
* **Статус:** Полноценный релиз v1.0, работает 100% офлайн.

### 3. [MathTrainer2](https://github.com/Bizonrelax/MathTrainer2)
* **Назначение:** Десктопный тренажёр для устного счёта (умножение). Генерирует примеры, проверяет ответы в реальном времени, имеет секундомер, подсказки и настраиваемые диапазоны.
* **Технологии:** Чистая Java (Swing).
* **Статус:** Стабильная версия, ведётся статистика сессий.

### 4. [MeDocPiece](https://github.com/Bizonrelax/MeDocPiece)
* **Назначение:** Утилита для пакетной вставки (и удаления) диалоговых окон `JOptionPane` в методы `.java` файлов. Упрощает отладку и логирование без ручного редактирования кода.
* **Технологии:** Java (Swing), JavaParser.
* **Статус:** Рабочий инструмент v1.0.

### 5. [SaberW](https://github.com/Bizonrelax/SaberW)
* **Назначение:** Первая версия компрессора текста. Сжимает данные с использованием словаря, который нейросеть затем может расшифровать.
* **Технологии:** Java, Launch4j (обёртка в `.exe` для Windows).
* **Статус:** Стабильная версия v1.1.

## 🧠 Математика, Теория и Заметки

### 6. [Sigmawillow](https://github.com/Bizonrelax/Sigmawillow) (Этот репозиторий)
* **Назначение:** Личный цифровой блокнот. Главный хаб для сбора математических концепций, теоретических набросков, формул и независимых исследований. Сочетает структуру (Sigma) и гибкость мышления (Willow).
* **Технологии:** HTML, Markdown.
* **Статус:** Основной каталог идей.

### 7. [Caudox](https://github.com/Bizonrelax/Caudox)
* **Назначение:** Экспериментальный фреймворк и репозиторий исследований геометрического представления позиционных систем счисления. Основан на концепции Ковиртуальных Пространств (Covirtual Spaces) и инвариантов цифр.
* **Технологии:** Java, Математическое моделирование.
* **Статус:** Теоретическая база и документация.

### 8. [Runtolap](https://github.com/Bizonrelax/Runtolap)
* **Назначение:** Математический препринт, предлагающий независимое доказательство Гипотезы об одиноком бегуне (Lonely Runner Conjecture) через индукцию по рациональному рангу (обходя классические барьеры).
* **Технологии:** Алгебраическая геометрия чисел, Теорема Кронекера.
* **Статус:** Независимое исследование (Preprint).

### 9. [july-rain](https://github.com/Bizonrelax/july-rain)
* **Назначение:** Дискретный геометрический подход к арифметическим прогрессиям (7n). Исследует матричные проекции, «Пароходную плоскость» и «Цилиндр Ти» для оптимизации вычислений (O(1)) на аппаратном уровне.
* **Технологии:** Комбинаторика, Топология.
* **Статус:** Исследовательский архив.

### 10. [gold-ounce](https://github.com/Bizonrelax/gold-ounce)
* **Назначение:** Коллекция концептуальных инсайтов и качественных комментариев к Великой теореме Ферма. Документация личных размышлений и теоретических изысканий.
* **Технологии:** Заметки, Markdown.
* **Статус:** Теоретические размышления.

### 11. [s2-network](https://github.com/Bizonrelax/s2-network)
* **Назначение:** Рабочие заметки по проблеме 3x+1 (гипотеза Коллатца). Исследует границы S2-сети, накопление избытка и содержит черновики лемм.
* **Технологии:** Java (код для верификации), Математика.
* **Статус:** Рабочие заметки и верификация.

## 🎮 Алгоритмы, Визуализация и Эксперименты

### 12. [Wawestone](https://github.com/Bizonrelax/Wawestone)
* **Назначение:** Экспериментальный шахматный движок, который отказывается от перебора дерева ходов и статического веса фигур. Использует многоуровневую модель пространств и метрику CSS (Сила Клеточного Спектра) для статической оценки позиции.
* **Технологии:** Java, Битовые маски.
* **Статус:** PoC (Proof of Concept), эндшпиль.

### 13. [PrimeWalker](https://github.com/Bizonrelax/PrimeWalker)
* **Назначение:** Геометрический визуализатор простых чисел.
* **Технологии:** Java.
* **Статус:** Визуализация, примеры.

### 14. [PatternMiner-PoC](https://github.com/Bizonrelax/PatternMiner-PoC)
* **Назначение:** Концепт «Цифровой геологии». Система для поиска паттернов в данных, улучшения сжатия и вознаграждения майнеров крипто-токенами (PatternCoin).
* **Технологии:** Java, Блокчейн (демо), GUI.
* **Статус:** Рабочий прототип (PoC).

## 🌱 Молодые проекты (ранняя стадия)

### 16. Alterno
* **Назначение:** Визуальное сравнение документов методом мигающего компаратора (техника астрономов, открывших Плутон): документы быстро чередуются в одной позиции экрана, и любое различие видно глазом мгновенно. Режим Press экспортирует сравнение в видеофайл для плавного просмотра без лагов.
* **Технологии:** Java 21+, Maven, Swing/JavaFX (выбор открыт), FFmpeg (экспорт видео).
* **Статус:** Ранняя стадия: ТЗ, README и лицензия готовы, код не начат.
