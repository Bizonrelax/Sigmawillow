# Lowbml (Yellow Brick Melon) — стандарт локального взаимодействия программ
Версия черновика: 0.1. Статус: проект. Лицензия: The Unlicense.

## 1. Назначение
Стандарт позволяет установленным на одном компьютере программам обнаруживать друг друга,
запускать друг друга в тихом режиме и пользоваться функционалом друг друга через единый протокол.

## 2. Термины
- Участник — программа, реализующая стандарт.
- Манифест — файл lowbml.json с описанием участника.
- Реестр — общий список участников на машине.
- Capability — именованная функция участника, доступная другим (глагол_существительное: compress_text, extract_archive).
- Тихий запуск — запуск без пользовательского интерфейса по стандартному флагу.
- Сессия — пара запрос-ответ между участниками с общим токеном.

## 3. Манифест участника (lowbml.json в папке установки)
Поля: name, version, apiVersion (major.minor), executable, silentArgs, capabilities[]
(имя, входная JSON-схема, выходная JSON-схема, таймаут секунд), vendor, license.

## 4. Реестр
Путь: Windows %APPDATA%/lowbml/registry.json; Linux и macOS ~/.lowbml/registry.json.
Запись реестра = манифест плюс registeredAt и lastSeen.
Участник при первом запуске добавляет себя в реестр; при каждом запуске обновляет lastSeen.
Чтение реестра — единственный способ обнаружения в MVP.

## 5. Тихий запуск
Флаг: --lowbml-silent. Без окон, без трея, без вопросов.
Программа в тихом режиме живёт только как IPC-сервер и завершается по команде shutdown или по таймауту бездействия (по умолчанию 300 секунд).

## 6. IPC
Транспорт: HTTP JSON, только 127.0.0.1.
Порт эфемерный; участник пишет его в %APPDATA%/lowbml/<name>.port, токен сессии — в <name>.token.
Запросы: GET /capabilities; POST /invoke {capability, params}; POST /shutdown.
Таймаут вызова по умолчанию 60 секунд, переопределяется манифестом.

## 7. Безопасность
Только localhost. Токен обязателен для каждого вызова.
Запрещено: запускать другого участника с интерфейсом; эскалировать права; ходить в сеть от имени стандарта.
Глубина цепочки запусков не более 8 (защита от циклов); при превышении — ошибка LOOP.

## 8. Версии и ошибки
Несовпадение major apiVersion вызывающего и вызываемого — отказ VERSION_MISMATCH.
Коды ошибок: CAP_NOT_FOUND, TIMEOUT, LOOP, VERSION_MISMATCH, INTERNAL.
Формат ошибки: {error: {code, message}}.

## 9. MVP стандарта
Два участника: SaberW 2 (compress_text, decompress_text) и Извлекатель архивов (extract_archive).
Реестр, тихий запуск, invoke с таймаутом, обработка четырёх кодов ошибок.
Вне MVP: сетевой транспорт, асинхронные подписки, витрина участников, шифрование канала (localhost не требует).
