# Trirunner — треугольный язык одинокого бегуна, черновик 0.1

Дата: 28 ноября 2026. Статус: рабочий черновик, не публикация.
Имяworking «Trirunner» не прогнано по твоим критериям публичных имён — считать временным.

Чего текст **не** утверждает: доказательства гипотезы, доказанной новизны, преимущества перед существующими подходами. Текст даёт язык, четыре леммы с доказательствами, точный алгоритм и тест пригодности.

## 0. Обозначения

‖x‖ — расстояние от x до ближайшего целого.

V = {v₁ < v₂ < … < v_k} — различные положительные целые, k = n − 1, где n — полное число бегунов.

f_V(t) = minᵢ ‖vᵢ t‖,  κ(V) = maxₜ f_V(t).

Гипотеза одинокого бегуна: κ(V) ≥ 1/(k + 1).

Стандартная редукция (используется молча): вычитаем скорость выделенного бегуна; заменяем vᵢ на |vᵢ|, так как ‖−x‖ = ‖x‖; совпавшие скорости склеиваем —constraints становится меньше, а требуемая граница 1/(k′+1) только слабее; делим на НОД — κ не меняется.

Позиции: xᵢ(t) = vᵢ t mod 1 ∈ [0, 1). Выделенный бегун стоит в 0.

## 1. Словарь

| Термин языка | Определение | Стандартный смысл |
|---|---|---|
| Зазоры g₁, gₙ | g₁ = minᵢ xᵢ, gₙ = minᵢ (1 − xᵢ) mod 1 | дуги до ближайших соседей выделенного бегуна |
| Тень | точка (g₁, gₙ, 1 − g₁ − gₙ) | проекция состояния на 2 координаты |
| Треугольник Δ | {g₁, gₙ, остаток ≥ 0, сумма = 1} | пространство зазоров |
| Старт S | вершина (0, 0, 1) | все бегуны в одной точке, t = 0 |
| Мишень T(δ) | {g₁ ≥ δ, gₙ ≥ δ} | условие одиночества уровня δ |
| Вершина мишени A(δ) | (δ, δ, 1 − 2δ) | равноудалённость от обоих соседей |
| Пучок | семейство T(δ), 0 ≤ δ ≤ 1/2 | шкала уровней одиночества |
| Медиана | луч g₁ = gₙ из S | симметрия соседей относительно 0 |
| Глубина касания | max{δ : тень ∩ T(δ) ≠ ∅} | κ(V) |
| Плотный набор | касание ровно в A(1/n) | κ(V) = 1/n, равенство в гипотезе |

Обратный перевод: любое утверждение про тень переводится в ‖vᵢ t‖ подстановкой g₁ = minᵢ xᵢ, gₙ = minᵢ (1 − xᵢ). Потерь нет, кроме одной, названной в разделе 5.

## 2. Четыре леммы

### Лемма 1 (Тень)

Для всех t выполнено g₁ + gₙ ≤ 1 и

min(g₁(t), gₙ(t)) = f_V(t).

Доказательство. min(g₁, gₙ) = minᵢ min(xᵢ, 1 − xᵢ) = minᵢ ‖vᵢ t‖, так как минимум минимумов перестановочен. Неотрицательность третьей координаты: если все xᵢ > 0, то g₁ = min xᵢ, gₙ = 1 − max xᵢ, сумма = 1 − (max xᵢ − min xᵢ) ≤ 1; если хоть один xᵢ = 0, то g₁ = gₙ = 0. ∎

Следствие: гипотеза равносильна тому, что тень попадает в T(1/n).

### Лемма 2 (Пучок)

T(δ) = (δ, δ, 0) + (1 − 2δ)·Δ — гомотетия Δ с коэффициентом 1 − 2δ. Доля площади:

    (1 − 2δ)²

Вершина A(δ) лежит на медиане; T(0) = Δ; T(1/2) = середина стороны, противоположной S. Вложенность: δ′ > δ ⟹ T(δ′) ⊂ T(δ).

Доказательство. Замена g₁′ = g₁ − δ, gₙ′ = gₙ − δ даёт неотрицательные координаты с суммой 1 − 2δ. Остальное — подстановка. ∎

При δ = 1/n доля площади равна ((n − 2)/n)²; для трёх бегунов — 1/9.

### Лемма 3 (Медиана)

Максимум f_V достигается в момент t, где g₁ = gₙ, и всякий такой момент с f_V > 0 имеет вид t = m/(vᵢ + vⱼ), i ≤ j, m ∈ ℤ.

Доказательство. Пусть t* — точка максимума, δ* = f_V(t*) > 0. Активным назовём индекс i с ‖vᵢ t*‖ = δ*. Функция t ↦ ‖vᵢ t‖ кусочно-линейна с наклонами ±vᵢ и изломами при vᵢ t ∈ ½ℤ.

Если все активные ветви имеют одинаковый знак наклона и ни у одной нет излома, то f_V строго монотонна вблизи t* — противоречие. Излом-минимум даёт δ* = 0, исключено. Остаются два случая.

Случай A: две активные ветви с противоположными наклонами. Возрастающая ветвь означает xᵢ ∈ (0, ½), убывающая — xⱼ ∈ (½, 1). В точке пересечения xᵢ = δ*, xⱼ = 1 − δ*, а все прочие бегуны удалены не меньше чем на δ*, значит это и есть оба соседа: g₁ = gₙ = δ*.

Случай B: одна активная ветвь в изломе-максимуме, то есть xᵢ = ½. Этот бегун является обоими соседями сразу: g₁ = gₙ = ½.

В обоих случаях (vᵢ + vⱼ)t* ∈ ℤ, причём случай B — это i = j. ∎

### Следствие (точная формула)

κ(V) = max{ D(q, V) / q : q = vᵢ + vⱼ, i ≤ j }, где D(q, V) = maxₘ minₗ dist(q, vₗ m), а dist(q, a) = min(a mod q, q − (a mod q)) — целое.

Доказательство. По лемме 3 максимум ищется среди t = m/q, q из множества сумм; f_V(m/q) = (1/q)·minₗ dist(q, vₗ m). Период 1 позволяет взять 1 ≤ m < q. ∎

Это уже не картинка: язык даёт точный целочисленный алгоритм вместо сканирования по t. Сложность O(k · Σq), памяти O(k).

### Лемма 4 (Плотность = касание вершины)

V плотный ⟺ тень встречается с T(1/n) ровно в вершине A(1/n).

Доказательство. Самое глубокое касание происходит на медиане (лемма 3), а медиана ∩ T(δ) = {A(δ)}. Значит κ(V) = 1/n равносильно тому, что максимум глубины равен 1/n, то есть касание в A(1/n) и ни одной внутренней точки. ∎

## 3. Тест пригодности: три бегуна за пять строк

Пусть k = 2, V = {a, b}, gcd(a, b) = 1, q = a + b.

1. На медиане оба бегуна симметричны: при t = j/q имеем bt ≡ −at, значит f_V(j/q) = ‖a j/q‖ = dist(q, a j)/q.
2. gcd(a, q) = gcd(a, b) = 1, поэтому a j mod q пробегает все ненулевые вычеты при j = 1 … q − 1.
3. Значит κ(V) ≥ ⌊q/2⌋/q.
4. При q ≥ 4 это ≥ 1/2 > 1/3; при q = 3 получаем ровно 1/3.
5. Отсюда κ ≥ 1/3 всегда, и равенство forces q = 3, то есть V = {1, 2} с точностью до растяжения. ∎

Тест пройден: язык даёт короткое доказательство известного случая и классификацию плотных наборов при k = 2. Это минимальная планка, ниже которой язык надо выбрасывать.

## 4. Проверенное и опровергнутое

Численно проверено в прототипе (точная арифметика по формуле-следствию, сверка с сеткой по t):

| V | κ | плотный | медиана в оптимуме |
|---|---|---|---|
| 1,2 | 1/3 | да | да |
| 1,2,3 | 1/4 | да | да |
| 1,3,4,7 | 1/5 | да | да |
| 1,3,4,5,9 | 1/6 | да | да |
| 1,2,3,4,5,7,12 | 1/8 | да | да |
| 1,4,5,6,7,11,13 | 1/8 | да | да |
| 1…29,31,90 (n=32) | 1/32 | да | да |
| 1…209,211,1050 (n=212) | 1/212 | да | да |
| 1,3,4 | 2/7 | нет | да |
| 2,5,9 | 3/7 | нет | да |
| 3,5,11,17 | 1/2 | нет | да |

**Опровергнуто.** Гипотеза «всякий плотный набор порождён суммами» (каждый элемент с третьего — сумма двух предыдущих). Держится на всех классических примерах, но ломается на семействе Годдина–Вона: набор {1, …, 29, 31, 90} плотный, κ = 1/32, а 90 > 31 + 29. Правильная формулировка-кандидат: порождение суммами **плюс ускорения** r → m·r.

**Открыто, проверяется скриптом.** Для k = 2 и gcd(a, b) = 1 верно ли κ({a, b}) = ⌊(a + b)/2⌋ / (a + b) точно? Нижняя оценка доказана в разделе 3, верхняя — нет; на выборке {1,2}, {1,3}, {2,3}, {1,4}, {2,5}, {3,5} совпадает.

## 5. Чего язык не даёт (честные ограничения)

Тень не автономна. Для V = {1, 3, 7} в момент t = 1/6 бегуны 1 и 7 сталкиваются в точке 1/6, и ближний сосед меняется **внутри** треугольника, а не на стене. Направление тени берётся из конечного набора (vᵢ, −vⱼ), но переключения задаёт спрятанное состояние. Вся трудность задачи сидит ровно в этой потерянной информации — двумерность картинки бесплатной не бывает.

Это не биллиард. На стенах, где сосед меняется через выделенного бегуна, работает циклический перенос координат, а не отражение. Формулировку «биллиард в равностороннем треугольнике» без оговорки использовать нельзя.

Язык не сокращает перебор. Там, где сейчас работают конечные проверки, он не даёт выигрыша.

## 6. Скрипт проверки (Java 21, один файл)

Запуск: `java TriLonely.java` или `java TriLonely.java data/trl-check.tsv`. Зависимостей нет, БД нет, выход — обычный TSV.

```java
import java.util.*;
import java.nio.file.*;

public class TriLonely {

    static long gcd(long a, long b) { while (b != 0) { long t = a % b; a = b; b = t; } return a; }

    /** kappa(V) = max D(q)/q по q = v_i + v_j. Возврат: {числитель, знаменатель, m, q}. */
    static long[] kappa(int[] v) {
        TreeSet<Integer> sums = new TreeSet<>();
        for (int i = 0; i < v.length; i++)
            for (int j = i; j < v.length; j++) sums.add(v[i] + v[j]);
        long bp = 0, bq = 1, bm = 0, bqr = 1;
        for (int q : sums) {
            if ((long) (q / 2) * bq <= bp * q) continue;   // D(q) <= floor(q/2)
            for (int m = 1; m < q; m++) {
                long d = Long.MAX_VALUE;
                for (int x : v) {
                    long r = ((long) x * m) % q;
                    d = Math.min(d, Math.min(r, q - r));
                    if (d == 0) break;
                }
                if (d * bq > bp * q) { bp = d; bq = q; bm = m; bqr = q; }
            }
        }
        long g = gcd(bp, bq);
        return new long[]{bp / g, bq / g, bm, bqr};
    }

    /** Лемма 3 в целых числах: g1 == gn в оптимуме. */
    static boolean medianOk(int[] v, long m, long q) {
        long lo = q, hi = -1;
        for (int x : v) { long r = ((long) x * m) % q; lo = Math.min(lo, r); hi = Math.max(hi, r); }
        return lo == q - hi;
    }

    static boolean tight(int[] v, long[] k) { return k[0] * (v.length + 1) == k[1]; }

    static boolean sumGenerated(int[] v) {
        int[] s = v.clone(); Arrays.sort(s);
        for (int i = 2; i < s.length; i++) {
            boolean ok = false;
            for (int a = 0; a < i && !ok; a++)
                for (int b = a + 1; b < i; b++)
                    if (s[a] + s[b] == s[i]) { ok = true; break; }
            if (!ok) return false;
        }
        return true;
    }

    static double grid(int[] v, int n) {
        double best = 0;
        for (int i = 1; i < n; i++) {
            double t = (double) i / n, mn = 1;
            for (int x : v) { double y = x * t; mn = Math.min(mn, Math.abs(y - Math.rint(y))); }
            best = Math.max(best, mn);
        }
        return best;
    }

    static int[] range(int lo, int hi, int skip, int extra) {
        int[] a = new int[hi - lo + 1 - (skip >= lo && skip <= hi ? 1 : 0) + (extra > 0 ? 1 : 0)];
        int p = 0;
        for (int i = lo; i <= hi; i++) if (i != skip) a[p++] = i;
        if (extra > 0) a[p] = extra;
        return a;
    }

    public static void main(String[] args) throws Exception {
        int[][] tests = {
            {1,2}, {1,2,3}, {1,3,4,7}, {1,3,4,5,9}, {1,2,3,4,5,7,12}, {1,4,5,6,7,11,13},
            range(1,31,30,90), range(1,211,210,1050), {1,3,4}, {2,5,9}, {3,5,11,17}
        };
        String[] expect = {"1/3","1/4","1/5","1/6","1/8","1/8","1/32","1/212","2/7","3/7","1/2"};
        StringBuilder out = new StringBuilder("id\tk\tkappa\texpected\ttight\tmedian\tsumgen\tt_star\n");
        boolean green = true;
        for (int i = 0; i < tests.length; i++) {
            int[] v = tests[i];
            long[] r = kappa(v);
            String val = r[0] + "/" + r[1];
            boolean med = medianOk(v, r[2], r[3]);
            boolean ok = val.equals(expect[i]) && med;
            if (v.length <= 8) ok &= Math.abs((double) r[0] / r[1] - grid(v, 200001)) < 1e-3;
            green &= ok;
            out.append(String.format("A%04d\t%d\t%s\t%s\t%s\t%s\t%s\t%d/%d%n",
                i + 1, v.length, val, expect[i], tight(v, r), med, sumGenerated(v), r[2], r[3]));
        }
        int bad = 0;
        for (int a = 1; a <= 40; a++)
            for (int b = a + 1; b <= 40; b++) {
                if (gcd(a, b) != 1) continue;
                long[] r = kappa(new int[]{a, b});
                int q = a + b;
                if (r[0] * q != (q / 2) * r[1]) bad++;
            }
        out.append("k2_formula_mismatches\t").append(bad).append('\n');
        out.append(green ? "GREEN\n" : "RED\n");
        System.out.print(out);
        if (args.length > 0) Files.writeString(Path.of(args[0]), out.toString());
    }
}
```

Критерий зелёного цикла: все строки kappa совпадают с expected, median = true везде, сеточная сверка в пределах 1e-3, итог GREEN. Строка `k2_formula_mismatches` — не критерий, а сбор данных по открытому вопросу.

## 7. Позиционирование

Занято до нас: кубы view-obstruction и биллиардная формулировка, зонотопы и политопы, нигде-не-нулевые потоки, круговое хроматическое число distance-графов, множества Бора. Обзор Perarnau–Serra: https://arxiv.org/abs/2409.20160 . Политопы: https://arxiv.org/abs/1606.01783 .

Фронт основного случая — конечные проверки: 8 бегунов https://arxiv.org/abs/2509.14111 , 9 и 10 https://arxiv.org/abs/2511.22427 , анонсы 11–15. Сюда язык не целится.

Куда целится язык: характеризация плотных наборов (открытая Problem 1 обзора) и спектр одиночества. Плотность — это касание, то есть геометрическое условие, и лемма 4 переводит его в язык мишеней. Свежее по плотным наборам: https://arxiv.org/abs/2608.13599 . По спектру: https://www.combinatorics.org/ojs/index.php/eljc/article/view/v33i1p38 .

Новизна на сегодня: упаковка_known_ фактов в новую геометрию плюс точный алгоритм. Теоремы, которой нет у других, пока нет.
