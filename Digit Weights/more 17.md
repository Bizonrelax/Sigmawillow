Для расчёта и построения двухмерного порядочного графика возьмём год рождения отца царя [Петра Первого](https://www.google.com/search?q=%D0%BF%D0%B5%D1%82%D1%80%D0%B0+%D0%BF%D0%B5%D1%80%D0%B2%D0%BE%D0%B3%D0%BE&kgmid=/m/0c2sf) — царя Алексея Михайловича Романова. Он родился 1629 года. [1] 
Прогоним числовую строку 1629 через метод ортогонального проецирования и двухмерного сворачивания ПУС-структур, который мы разработали. Вычисления проводятся для 10-ричной системы счисления с основанием N равным 10. Квадратный корень из 6 принят равным 2.45, а квадратный корень из 2 равен 1.41.
Числовая строка имеет 4 разряда. Позиции p отсчитываются справа налево: на позиции p=1 находится цифра 9, на p=2 цифра 2, на p=3 цифра 6, на p=4 цифра 1. Верхняя граница числового поля N-1 равна 9.
## 1. Математический поразрядный расчёт двухмерных координат ПУС (U; V)
Напоминаю формулы перехода в плоские координаты без потери информации:
Координата X равна (3 * x * x) / 2.45
Координата Y равна (18 * x - x * x) / 1.41
Координата U (проекция БУС) равна p * X
Координата V (интеграция позиции) равна p * Y + p
Для разряда единиц (p = 1, x = 9):
Базовое X равно (3 * 81) / 2.45 = 243 / 2.45 = 99.18
Базовое Y равно (18 * 9 - 81) / 1.41 = (162 - 81) / 1.41 = 81 / 1.41 = 57.45
Порядковое U_1 равно 1 * 99.18 = 99.18
Порядковое V_1 равно 1 * 57.45 + 1 = 58.45
Координатная точка первого разряда: (99.18; 58.45)
Для разряда десятков (p = 2, x = 2):
Базовое X равно (3 * 4) / 2.45 = 12 / 2.45 = 4.90
Базовое Y равно (18 * 2 - 4) / 1.41 = (36 - 4) / 1.41 = 32 / 1.41 = 22.70
Порядковое U_2 равно 2 * 4.90 = 9.80
Порядковое V_2 равно 2 * 22.70 + 2 = 47.40
Координатная точка второго разряда: (9.80; 47.40)
Для разряда сотен (p = 3, x = 6):
Базовое X равно (3 * 36) / 2.45 = 108 / 2.45 = 44.08
Базовое Y равно (18 * 6 - 36) / 1.41 = (108 - 36) / 1.41 = 72 / 1.41 = 51.06
Порядковое U_3 равно 3 * 44.08 = 132.24
Порядковое V_3 равно 3 * 51.06 + 3 = 156.18
Координатная точка третьего разряда: (132.24; 156.18)
Для разряда тысяч (p = 4, x = 1):
Базовое X равно (3 * 1) / 2.45 = 3 / 2.45 = 1.22
Базовое Y равно (18 * 1 - 1) / 1.41 = 17 / 1.41 = 12.06
Порядковое U_4 равно 4 * 1.22 = 4.88
Порядковое V_4 равно 4 * 12.06 + 4 = 52.24
Координатная точка четвертого разряда: (4.88; 52.24)
## 2. Агрегированный вектор состояния года 1629
Суммируем плоские координаты всех разрядов, чтобы получить единый плоский паспорт года рождения:
Итоговое U_total равно 99.18 + 9.80 + 132.24 + 4.88 = 246.10
Итоговое V_total равно 58.45 + 47.40 + 156.18 + 52.24 = 314.27
Двухмерный векторный паспорт исторического года 1629 зафиксирован в точке с координатами (246.10; 314.27).
## 3. Описание геометрии плоского ПУС-графика для числа 1629
На полярной или декартовой плоскости ПУС-портрет года 1629 разворачивается в виде четырехвершинной динамической структуры. Каждая точка представляет собой законченный лепесток цифровой массы:

* 
* Девятка на первой позиции создает сильный горизонтальный базовый импульс, вытягивая нижнее правое крыло графика в точку (99.18; 58.45).
* Двойка на второй позиции сжимается близко к вертикальной оси из-за малой квадратичной массы, фиксируя плотный узел у основания трека в точке (9.80; 47.40).
* Шестерка на третьей позиции, за счет мощного позиционного рычага p=3, совершает колоссальный пространственный выброс вверх и вправо, формируя доминирующую верхнюю корону всей геометрической фигуры в точке (132.24; 156.18).
* Единица на четвертой позиции, несмотря на максимальный множитель p=4, остается миниатюрным замыкающим штрихом на левой границе из-за минимального собственного веса, уходя в точку (4.88; 52.24).
