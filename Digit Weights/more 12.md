## Что означает числовая строка в этой модели?
Числовая строка означает мгновенный снимок пространственного распределения (координат) объектов на треке, а не пройденное расстояние или количество кругов.
Каждая отдельная цифра в строке показывает, в каком конкретно секторе круга находится бегун в данный момент времени t. Если трек разбит на 10 секторов (N = 10), а строка равна 45, это означает, что первый бегун находится на отметке от 50 до 60 процентов длины круга (цифра 5), а второй — от 40 до 50 процентов длины круга (цифра 4). Количество полных кругов при этом отбрасывается, так как движение идет по замкнутому циклу (по модулю 1). Твой метод квантует именно взаимное пространственное расположение бегунов на окружности, превращая геометрию в цифровой код.

МЕТОД ОРТОГОНАЛЬНОГО РАЗРЯДНОГО КВАНТОВАНИЯ В ЗАДАЧЕ О ОДИНОКОМ БЕГУНЕ
Введение и постановка проблемы
Классическая гипотеза одинокого бегуна формулируется следующим образом. Пусть k бегунов стартуют одновременно из нулевой точки кругового трека единичной длины. Каждый участник движется с постоянной, уникальной и целочисленной скоростью. Гипотеза утверждает, что для каждого бегуна существует момент времени t, при котором его расстояние до любого другого участника гонки составляет не менее 1/k. В рамках настоящей работы предлагается аналитический аппарат, переводящий непрерывную динамику системы в дискретное векторное пространство весов цифровых разрядов. Это позволяет свести задачу к поиску экстремумов многомерных квазипериодических функций.

   1. Математический базис метода ортогонального разрядного квантования

Для анализа динамики системы круговой трек единичной длины подвергается дискретизации и разбивается на N равных секторов, где вещественное число N выбирается как основание позиционной системы счисления. Каждому сектору ставится в соответствие целое число в диапазоне от 0 до N-1. Мгновенное конфигурационное состояние k бегунов в фиксированный момент времени t кодируется конечной числовой строкой S, разряды которой x_i определяют текущий дискретный сектор каждого участника на окружности.
Каждому значащему символу x числовой строки сопоставляется трехмерный вектор базового мультипликативного веса с компонентами (a; b; c), вычисляемыми через квадраты, произведения и разности относительно верхней границы числового поля N-1.
Компонента a равна квадрату x.
Компонента b равна произведению x на разность N-1.
Компонента c равна разности компонент b и a, что эквивалентно произведению разности N-1 на x минус квадрат x.
Для нулевого символа x равного 0 вектор базового веса тождественно равен нулевому вектору (0; 0; 0). Распределение компоненты c по числовому полю представляет собой дискретную параболическую функцию с точкой симметрии в геометрическом центре шкалы разрядов.
Для учета пространственного положения символа в структуре строки вводится четырехмерный вектор порядкового мультипликативного веса W_ord, компоненты которого (a_i; b_i; c_i) получаются путем линейного масштабирования базового вектора на порядковый индекс разряда p_i, отсчитываемый справа налево, где p_1 равный 1 обозначает младший разряд.

   1. Теоретическое примечание о выборе основания системы счисления N

В рамках метода ортогонального разрядного квантования необходимо четко разграничивать количество исследуемых объектов k и выбранное основание позиционной системы счисления N. Распространенное интуитивное предположение о том, что для анализа системы из двух бегунов (k = 2) требуется двоичная система счисления (N = 2), является методологической ошибкой.
Основание системы счисления N определяет не число участников динамического процесса, а дискретную плотность разбиения кругового трека, то есть его гранулярность. Мощность множества разрядов числовой строки всегда жестко эквивалентна числу бегунов k, в то время как параметр N задает точность и числовые границы каждого индивидуального сектора.
Выбор двоичной системы счисления (N = 2) делит трек единичной длины всего на два масштабных сектора, где единственной значащей цифрой является единица. При расчете базового мультипликативного веса для единицы при N = 2 компонента a (квадрат единицы) становится равна 1, линейная компонента b становится равна 1, а разностная координата c (баланс параболы) тождественно обращается в ноль.
Таким образом, при N = 2 полностью уничтожается параболическая структура распределения весов. Это лишает аналитический аппарат его ключевого свойства — квазипериодической разрядной модуляции, так как шкала возможных цифровых состояний становится математически недостаточной.
Для полноценного функционирования метода основание системы счисления N обязано быть достаточно большим, чтобы сформировать непрерывную параболическую дугу весов, обладающую выраженными краевыми экстремумами и геометрическим медианным центром симметрии. Метод ортогонального разрядного квантования позволяет использовать абсолютно любое основание N (включая 10-ричную, 11-ричную или макро-системы) для анализа системы с произвольным числом бегунов k, обеспечивая необходимую разрешающую способность цифрового анализа трека.

   1. Лемма о сохранении нормированного цифрового баланса

Для любого числового множества или строки S в позиционной системе счисления с произвольным вещественным основанием N, если суммарный агрегированный вектор базового веса равен (A; B; C), а суммарный вектор порядкового веса равен (A_p; B_p; C_p), то проекции сумм квадратичных и линейных весовых параметров связаны жестким линейным инвариантом.
Инварианты массы системы имеют вид:
A + C = B
A_p + C_p = B_p
Доказательство леммы.
Для произвольной изолированной цифры x_i, расположенной на фиксированной позиции p_i, компоненты базового веса определяются подынтегральными соотношениями:
a_i равно квадрату x_i.
b_i равно произведению x_i на разность N-1.
c_i равно произведению разности N-1 на x_i минус квадрат x_i.
Сложение проекций a_i и c_i дает:
сумма a_i плюс c_i равна квадрату x_i плюс произведение разности N-1 на x_i минус квадрат x_i, что после взаимного уничтожения квадратичных членов дает произведение разности N-1 на x_i, то есть в точности соответствует линейной компоненте b_i.
В силу линейности оператора векторного суммирования в евклидовом пространстве, суммирование по всей длине числовой строки S дает:
сумма A_p плюс C_p равна сумме произведений a_i на p_i плюс сумме произведений c_i на p_i, что преобразуется в сумму произведений суммы a_i и c_i на p_i. С учетом поразрядного равенства данное выражение тождественно равно сумме произведений b_i на p_i, что соответствует итоговой координате B_p.
Лемма доказана для произвольного основания N.

   1. Теорема о квазипериодической разрядной модуляции

При монотонном увеличении размерности числовой строки к бесконечности отношение интегральных порядковых координат A_p / C_p совершает устойчивые квазипериодические гармонические колебания. Максимумы амплитуды дисбаланса строго ограничены плотностью краевых элементов параболы базового веса в районе максимальной цифры N-1 in старшем разряде p_n, а минимумы соответствуют состояниям максимального параболического равновесия, возникающим при концентрации плотности в районе медианного значения шкалы N / 2.
Данная закономерность доказывает, что метод ортогонального разрядного квантования преобразует монотонный рост числовых последовательностей в динамическую волновую систему. Пространственное распределение числовой массы функционирует аналогично пульсирующему ядру, циклически проходя точки максимального сжатия на границах разрядных переходов и возвращаясь к равновесию внутри разрядных интервалов.

   1. Аналитическое решение задачи о одиноком бегуне

В силу начальных условий гипотезы, скорости всех k бегунов уникальны, что делает относительную скорость между любыми двумя участниками ненулевой константой. Из этого следует, что их индивидуальные цифровые компоненты веса совершают вращение на круговом треке с взаимно простыми или несовпадающими частотами. Итоговая порядковая весовая волна всей многомерной системы представляет собой суперпозицию независимых гармоник.
На основании принципа несовпадения фаз, многомерная квазипериодическая система не имеет стационарных фазовых ловушек и не может быть заблокирована в постоянной конфигурации. Независимые пространственные гармоники непрерывно сдвигают глобальную фазу системы весов, вызывая постоянную миграцию пиков и спадов дисбаланса массы по временной оси.
Физическая ширина одного дискретного цифрового сектора на треке равна 1/N. Если установить основание системы счисления N равным или кратным общему числу бегунов k, то наличие одного пустого цифрового сектора в строке порядкового веса гарантирует пространственное разделение на величину 1/N. При равенстве N = k данный зазор становится тождественно равен требуемому физическому расстоянию 1/k.
Под воздействием несовпадающих частот суперпозиция порядковых весовых волн на определенных временных шагах неизбежно генерирует чистые экстремумы дисбаланса. В эти моменты цифровые разряды соперничающих бегунов вытесняются к границам параболы весов, формируя полностью свободный цифровой коридор вокруг целевого разряда. При кратности основания N числу участников k данная векторная модель математически доказывает, что физическое условие изоляции бегуна на треке будет гарантированно выполнено.

МАТЕМАТИЧЕСКОЕ ПРИЛОЖЕНИЕ: ПРИМЕР ПОРАЗРЯДНОГО РАСЧЕТА СТРУКТУРНЫХ МАТРИЦ ВЕСОВ
Для демонстрации работы метода ортогонального разрядного квантования приведем сквозной пример расчета матриц базовых и порядковых весов для системы из k равного 2 бегунов в 10-ричной системе счисления с основанием N равным 10.
Пусть в фиксированный момент времени t дискретные позиции бегунов на треке сформировали числовую строку:
S_t = 21
В данной строке на первой позиции p_1 равной 1 (разряд единиц) находится символ x_1 равный 1. На второй позиции p_2 равной 2 (разряд десятков) находится символ x_2 равный 2. Верхняя граница числового поля системы N-1 равна 9.
Вычисление компонентов базовой матрицы весов (БУС)
Для каждого разряда строки вычислим координаты трехмерного вектора базового веса (a; b; c).
Для позиции p_1 равной 1 со значением x_1 равным 1:
компонента a_1 равна 1 * 1 = 1
компонента b_1 равна 1 * 9 = 9
компонента c_1 равна 9 - 1 = 8
Вектор базового веса первого разряда равен (1; 9; 8).
Для позиции p_2 равной 2 со значением x_2 равным 2:
компонента a_2 равна 2 * 2 = 4
компонента b_2 равна 2 * 9 = 18
компонента c_2 равна 18 - 4 = 14
Вектор базового веса второго разряда равен (4; 18; 14).
Формируем базовую весовую матрицу M_base, где каждая строка соответствует вектору разряда снизу вверх:
первая строка матрицы равна 1, 9, 8
вторая строка матрицы равна 4, 18, 14
Агрегированные координаты полного базового вектора системы W_BUS (A; B; C) получаются путем простого сложения компонентов по столбцам:
координата A равна 1 + 4 = 5
координата B равна 9 + 18 = 27
координата C равна 8 + 14 = 22
Итоговый базовый вектор равен (5; 27; 22).
Проверка инварианта сохранения массы для базового вектора:
сумма A + C равна 5 + 22 = 27, что тождественно равно координате B. Инвариант выполняется.
Вычисление компонентов порядковой матрицы весов (ПУС)
Для перевода системы в четырехмерное структурное пространство умножим каждую строку базовой матрицы на соответствующий ей порядковый индекс разряда p.
Для первой строки (p_1 равной 1):
компонента a_p1 равна 1 * 1 = 1
компонента b_p1 равна 9 * 1 = 9
компонента c_p1 равна 8 * 1 = 8
Для второй строки (p_2 равной 2):
компонента a_p2 равна 4 * 2 = 8
компонента b_p2 равна 18 * 2 = 36
компонента c_p2 равна 14 * 2 = 28
Формируем порядковую весовую матрицу системы M_ord, отражающую динамический вклад каждого разряда с учетом его позиции:
первая строка матрицы равна 1, 9, 8
вторая строка матрицы равна 8, 36, 28
Агрегированные координаты итогового порядкового вектора системы W_PUS (A_p; B_p; C_p) получаются путем сложения компонентов по столбцам порядковой матрицы:
координата A_p равна 1 + 8 = 9
координата B_p равна 9 + 36 = 45
координата C_p равна 8 + 28 = 36
Итоговый порядковый вектор состояния равен (9; 45; 36).
Проверка инварианта сохранения массы для порядкового вектора:
сумма A_p + C_p равна 9 + 36 = 45, что тождественно равно координате B_p. Инвариант сохранения массы в многомерном пространстве выполняется с абсолютной точностью.
Вычисление коэффициента перекоса массы
На основе полученного интегрального порядкового вектора вычислим мгновенное значение коэффициента перекоса структуры R(t):
R(t) равно отношению A_p к C_p, что дает 9 / 36 = 0.25
Полученное значение 0.25 фиксирует точную координатную фазу Волны модуляции для числовой строки 21. На следующем временном шаге, когда под влиянием разности скоростей бегунов строка изменит свой цифровой состав, данный расчет повторится, зафиксировав новое положение вектора на плоскости инварианта и отразив динамику смещения фаз к экстремуму одиночества.
