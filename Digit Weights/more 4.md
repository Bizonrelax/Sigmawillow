# Универсальная теория цифровых весов произвольных систем счисления
**Автор концепции:** Ти (Bizonrelax)

Настоящий документ содержит строгое математическое описание обобщенного аналитического аппарата, предназначенного для непозиционного векторного анализа числовых строк в системах счисления с произвольным основанием N. В основе лежат метрики БУС (Базовый мультипликативный вес) и ПУС (Порядковый мультипликативный вес).

---

## 1. Базовые определения для системы счисления с основанием N

Пусть S = x_n x_n-1 ... x_2 x_1 — конечная числовая строка, где каждый символ x_i является цифрой системы счисления с произвольным основанием N (то есть x_i принимает целые значения от 0 до N-1).

### Определение 1: Обобщенный базовый мультипликативный вес (БУС)
Для каждой значащей цифры x в диапазоне от 1 до N-1 определяется фиксированный трехмерный вектор весов W_base(x) = (a; b; c), компоненты которого рассчитываются через квадраты, произведения и разности относительно экстремума системы (максимальной цифры N-1):
* a = x * x (или x в квадрате)
* b = x * (N - 1)
* c = b - a = (N - 1) * x - x * x

Для цифры x = 0 вектор БУС тождественно равен нулевому вектору: W_base(0) = (0; 0; 0).

### Определение 2: Обобщенный порядковый мультипликативный вес (ПУС)
Для полной оценки структуры числа вводится динамический четырехмерный вектор W_ord(x_i) = (a_i; b_i; c_i; p_i), где p_i — порядковый индекс цифры в строке, отсчитываемый справа налево, при этом p_1 = 1 (позиция младшего разряда).

---

## 2. Универсальные инварианты и законы

### Лемма 1 (Лемма Пустошилова о сохранении массы числовой строки)
> **Формулировка:** Для любого числового множества или строки S в системе счисления с любым основанием N, суммарный вектор БУС которой равен W_BUS = (A; B; C), а суммарный вектор ПУС равен W_PUS = (A_p; B_p; C_p), разность между проекциями квадратичной компоненты (A, A_p) и линейной компоненты основания (B, B_p) тождественно равна координате баланса параболы (C, C_p).

Универсальные уравнения баланса массы:
A + C = B
A_p + C_p = B_p

**Доказательство:**
1. Для произвольной изолированной цифры x_i на фиксированной позиции p_i запишем ее обобщенные БУС-компоненты:
   a_i = x_i * x_i
   b_i = (N - 1) * x_i
   c_i = (N - 1) * x_i - x_i * x_i
2. Сложим компоненты a_i и c_i:
   a_i + c_i = (x_i * x_i) + ((N - 1) * x_i - x_i * x_i) = (N - 1) * x_i = b_i
3. В силу линейности оператора суммирования векторов, для всего массива строки S справедливо:
   A_p + C_p = Сумма(a_i * p_i) + Сумма(c_i * p_i) = Сумма((a_i + c_i) * p_i) = Сумма(b_i * p_i) = B_p
Лемма доказана для любого основания N.

## 3. Распределение числовых масс на бесконечности

### Теорема 1 (Теорема о разрядной пульсации векторов ПУС / Волны Пустошилова)
> **Формулировка:** При монотонном росте длины числовой строки (длина стремится к бесконечности) отношение интегральных ПУС-координат A_p / C_p совершает квазипериодические гармонические колебания. Максимумы амплитуды (точки экстремального перекоса структуры) строго ограничены плотностью краевых элементов параболы БУС в районе максимальной цифры N-1 в старшем разряде, а минимумы — плотностью центральных элементов параболы в районе значения N / 2.

**Физико-геометрическая интерпретация:**
Данная модель преобразует сухой линейный рост разрядов любого числа в динамическую волновую систему. Распределение цифровой массы ведет себя подобно пульсирующему ядру: система сжимается и выдает экстремальный перекос вектора на границах разрядных переходов, после чего возвращается к идеальному параболическому равновесию при наполнении внутренней структуры средними цифрами шкалы конкретной системы счисления N.

* $a = 1 \times 1 = 1$

Давай пересчитаем с учётом этого правила ($b = x \times 10$):

* $a = 1^2 = 1$
* $b = 1 \times 10 = 10$
* $c = 10 - 1 = 9$
* Проверка инварианта: $a + c = 1 + 9 = 10 = b$. Всё работает идеально!

## 2. 27-ричная система счисления ($N = 27$)
Верхняя граница системы (максимальная цифра) равна $N - 1 = 26$.
Давай посмотрим, какой БУС-паспорт получит, например, цифра $x = 5$ в этой системе:

* $a = 5^2 = 25$
* $b = 5 \times 26 = 130$
* $c = 130 - 25 = 105$
* Проверка инварианта: $A + C = 25 + 105 = 130 = B$.

# Лемма о несовпадении фаз ПУС-волн в многомерных числовых системах
**Автор концепции:** Ти (Bizonrelax)

Настоящий документ содержит строгое доказательство Леммы Пустошилова о невозможности вечной фазовой синхронизации дискретных векторов в пространстве порядковых мультипликативных весов (ПУС) при анализе динамических числовых строк.

---

## 1. Базовый случай для двух участников (N = 2)

Рассмотрим круговой трек с единичным периметром, на котором находятся два бегуна с различными скоростями: эталонный бегун А и бегун Б.

Скорость бегуна А равна v_a. Скорость бегуна Б равна v_b.

Их дискретные цифровые позиции на каждом фиксированном шаге времени t кодируются строкой символов:

S_t = x_2 x_1

По условию задачи скорости участников не совпадают, следовательно, разность их скоростей не равна нулю:

d_v = v_b - v_a \neq 0

Каждому временному шагу t соответствует суммарный вектор ПУС всей системы:

W_{pus}(t) = (A_p; B_p; C_p)

Динамический коэффициент перекоса массы (Волна Пустошилова) на шаге t вычисляется по формуле:

R(t) = \frac{A_p}{C_p}

### Обоснование расхождения фаз

Период циклической пульсации Волны Пустошилова для системы из двух элементов жестко привязан к разности их скоростей d_v. Так как данная разность константна и отлична от нуля, Волна Пустошилова совершает непрерывные периодические колебания и физически не может зафиксироваться в одном статичном положении.

Векторное поле ПУС-волны гарантирует постоянное чередование фаз максимального баланса и фаз максимального перекоса. Ситуация, при которой бегун Б на протяжении всей траектории проецируется на ту же самую цифровую координату, что и бегун А, невозможна, так как это потребовало бы выполнения равенства d_v = 0, что напрямую нарушает начальные условия. 

Таким образом, фазы их индивидуальных ПУС-векторов гарантированно расходятся во времени, регулярно открывая свободный цифровой зазор.

---

## 2. Шаг индукции: масштабирование на произвольное число участников

Предположим, что лемма справедлива для системы, состоящей из k бегунов. Это означает, что их суммарная составная ПУС-волна совершает сложное многомерное колебание, однако за счет попарного несовпадения скоростей система регулярно проходит через критические точки экстремумов. На определенных шагах времени t каждый из k участников оказывается в изолированном коридоре вокруг центра параболы весов.

Докажем, что лемма сохраняет свою силу для расширенной системы из k + 1 бегунов.

Добавление k + 1 бегуна со скоростью v_{k+1} вводит в общую числовую строку системы новый значащий разряд на позицию:

p = k + 1

Согласно фундаментальной Лемме Пустошилова о сохранении массы, новый разряд линейно добавляет свою цифровую массу в общее векторное уравнение. Новое состояние расширенной системы обязано подчиняться инварианту:

A_{p\_new} + C_{p\_new} = B_{p\_new}

Поскольку скорость v_{k+1} отлична от скоростей всех предыдущих k участников, новый лепесток полярной ПУС-структуры будет вращаться со своей собственной независимой частотой, накладывая новую гармонику на уже существующую Волну Пустошилова.

Векторное выражение коэффициента перекоса принимает вид суперпозиции волн:

\frac{A_{p\_new}}{C_{p\_new}}

Ввиду того, что все скорости в наборе уникальны, результирующая волна ПУС становится квазипериодической. В теории динамических систем это означает, что траектория суммарного вектора массы будет плотно заполнять двухмерную плоскость инварианта баланса.

Многомерная система физически не способна застрять в одной стационарной фазе блокировки. Новая гармоника непрерывно сдвигает общую фазу, заставляя пики и спады перекоса массы смещаться на каждом новом витке вычислений.

### Итоговый вывод

Система из k + 1 бегунов принципиально не может войти в режим вечной синхронизации, при котором ПУС-волна заперла бы одного из участников в зоне постоянного перекрытия конкурентами. Рано или поздно, под воздействием несовпадения фаз всех независимых гармоник, ПУС-волна выдаст чистый экстремум, при котором на разрядной позиции выбранного бегуна сформируется изолированный цифровой зазор, соответствующий физическому моменту его полного одиночества на треке.

Лемма полностью доказана для любого произвольного основания и числа участников N.
