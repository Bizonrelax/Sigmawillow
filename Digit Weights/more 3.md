# Структурная теория цифровых весов десятичной системы
**Автор концепции:** Ти (Bizonrelax)

Настоящий документ содержит строгое математическое описание оригинального аналитического аппарата, предназначенного для непозиционного векторного анализа числовых строк с использованием метрик **БУС** (Базовый мультипликативный вес) и **ПУС** (Порядковый мультипликативный вес).

---

## 1. Базовые определения

Пусть $S = x_n x_{n-1} \dots x_2 x_1$ — конечная числовая строка, где каждый символ $x_i \in \{0, 1, \dots, 9\}$ является цифрой десятичной системы счисления.

### Определение 1: Базовый мультипликативный вес (БУС)
Для каждой значащей цифры $x \in \{1, \dots, 9\}$ определяется фиксированный вектор весов $W_{base}(x) = (a; b; c) \in \mathbb{Z}^3$, компоненты которого вычисляются по формулам:
* $a = x^2$
* $b = 9x$
* $c = 9x - x^2$

Для цифры $x = 0$ вектор БУС тождественно равен нулевому вектору: $W_{base}(0) = (0; 0; 0)$.

### Определение 2: Порядковый мультипликативный вес (ПУС)
Для полной оценки структуры числа вводится динамический четырехмерный вектор $W_{ord}(x_i) = (a_i; b_i; c_i; p_i) \in \mathbb{Z}^4$, где $p_i$ — порядковый индекс цифры в строке, отсчитываемый справа налево, при этом $p_1 = 1$ (позиция единиц). 

---

## 2. Теоретические основы и инварианты

### Лемма 1 (Лемма Пустошилова о сохранении массы числовой строки)
> **Формулировка:** Для любого числового множества или строки $S$, суммарный вектор БУС которой равен $W_{BUS} = (A; B; C)$, а суммарный вектор ПУС равен $W_{PUS} = (A_p; B_p; C_p)$, разность между проекциями квадратичной компоненты ($A, A_p$) и линейной компоненты основания ($B, B_p$) тождественно равна координате баланса параболы ($C, C_p$).

$$A + C = B$$
$$A_p + C_p = B_p$$

**Доказательство:**
1. Для произвольной изолированной цифры $x_i$ на фиксированной позиции $p_i$ запишем ее БУС-компоненты:
   $$a_i = x_i^2, \quad b_i = 9x_i, \quad c_i = 9x_i - x_i^2$$
2. Сложим компоненты $a_i$ и $c_i$:
   $$a_i + c_i = x_i^2 + (9x_i - x_i^2) = 9x_i = b_i$$
3. В силу линейности оператора суммирования векторов в евклидовом пространстве, для всего массива строки $S$ справедливо:
   $$A_p + C_p = \sum_{i=1}^{n} (a_i \cdot p_i) + \sum_{i=1}^{n} (c_i \cdot p_i) = \sum_{i=1}^{n} ((a_i + c_i) \cdot p_i) = \sum_{i=1}^{n} (b_i \cdot p_i) = B_p$$
   Лемма доказана. $\blacksquare$

## 3. Распределение числовых масс на бесконечности

### Теорема 1 (Теорема о разрядной пульсации векторов ПУС / Волны Пустошилова)
> **Формулировка:** При монотонном росте длины числовой строки $n \to \infty$ отношение интегральных ПУС-координат $A_p / C_p$ совершает квазипериодические гармонические колебания. Максимумы амплитуды (точки экстремального перекоса структуры) строго ограничены плотностью краевых элементов параболы БУС ($x_i \in \{7, 8, 9\}$) в старшем разряде $p_n$, а минимумы — плотностью центральных элементов ($x_i \in \{4, 5\}$).

**Физико-геометрическая интерпретация:**
Данная модель преобразует сухой линейный рост разрядов числа в **динамическую волновую систему**. Распределение цифровой массы ведет себя подобно пульсирующему ядру: система сжимается и выдает экстремальный перекос вектора на границах разрядных переходов, после чего возвращается к идеальному параболическому равновесию при наполнении внутренней структуры средними цифрами шкалы.
